# Cat Client v1.6.0 / Cat Panel v5.6.0 — هویت اختصاصی، مسیر زنده و لوکیشن

## 📱 تغییرات برنامه

### رابط کاربری اختصاصی Cat Client
- هویت متنی و رنگی برنامه یک‌دست شد: **Cat Client**، بنفش/مشکی/سفید؛ نام‌ها و resourceهای قدیمی برند قبلی از رابط برنامه حذف شدند.
- دکمه‌ها و کارت‌های اصلی به سبک شیشه‌ای با حاشیهٔ بنفش، گوشه‌های نرم و ripple سبک درآمدند.
- دکمهٔ اتصال از داخل گوی قدیمی جدا شد و زیر یک **کرهٔ نقطه‌ای مسیر** قرار گرفت؛ نقطه‌های قاره‌ها، ایران به‌عنوان مبدأ، مقصد، پرچم و مسیر متحرک بین آن‌ها را نشان می‌دهد.
- وضعیت اتصال، لوکیشن مقصد، IP مسیر، پینگ و مدت اتصال در همان صفحهٔ خانه قابل مشاهده‌اند. پینگ از همان delay موفق شروع تونل نمایش داده می‌شود، نه با تأخیر جداگانه.

### نام‌گذاری کانفیگ‌ها
- نام نمایشی دیگر IP را لو نمی‌دهد و به شکل زیر است:
  - `🐱 Cat · 🇩🇪 Germany · VLESS · 443 · #01`
- `tag` داخلی Mihomo عمداً دست‌نخورده می‌ماند تا سوییچ و runtime خراب نشود؛ فقط label نمایشی تغییر می‌کند.
- سابسکریپشن جدید Cat Panel هم remarkهای بدون IP می‌سازد. برای چند IP هم شمارهٔ کوتاه اضافه می‌شود تا نام‌ها در کلاینت‌ها یکتا بمانند.

### اسکنر مرتب‌تر
- نتیجهٔ اسکنر کنار هر IP شهر/کشور/پرچم edge پاسخ‌دهنده را نشان می‌دهد.
- سریع‌ترین نتیجه با «پیشنهاد اتصال» مشخص است.
- انتخاب «از نتیجهٔ اسکنر» موقعیت هر IP را همراه آن به سازندهٔ کانفیگ می‌برد؛ آدرس واقعی همچنان فقط در URL/ستون IP می‌ماند، نه اسم کانفیگ.

## ☁️ تب Cloud
- آخرین پنل‌های Cat ساخته‌شده روی دستگاه در کارت **پنل‌های Cat ساخته‌شدهٔ من** ذخیره می‌شوند؛ با یک دکمه مستقیماً وارد پنل می‌شوید.
- تاریخچه تا ۸ نصب نگه داشته می‌شود؛ KV و اطلاعات پنل تغییر نمی‌کند.
- کارت‌های سازنده‌های بیرونی عمداً دست‌نخورده ماندند: کارت‌های Worker مستقیماً به صفحهٔ رسمی سازنده/سازندهٔ نصب خودشان می‌روند و Cat Client کد آن‌ها را تغییر نمی‌دهد. فقط Cat Panel از داخل برنامه deploy و مدیریت می‌شود.

## 🧹 متن و توضیحات
- توضیحات Cat Client و Cat Panel فقط دربارهٔ قابلیت‌های خود برنامه و پنل نوشته شدند؛ مقایسه و نام‌بردن از پروژه‌های دیگر از توضیحات داخلی حذف شد.
- نام چند کلاینت مقصد مثل v2rayNG / sing-box فقط در بخش import/share باقی است، چون برای باز کردن لینک در برنامهٔ مقصد لازم است.
