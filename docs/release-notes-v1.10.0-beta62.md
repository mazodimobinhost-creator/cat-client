# Cat Client 1.10.0-beta62 (versionCode 129) — پنل 6.42.0 (بدون تغییر)

## 🚑 فیکس کرش استارتاپ — ریشه با سند

### چی شد؟
- صفحهٔ اسکنر همان اولِ باز شدن اپ ساخته می‌شود (حتی قبل از کلیک روی تبش)
- در همین ساخت، خطِ «🕘 اسکن قبلی…» رندر می‌شود
- اگر آخرین اسکنِ تو **هیچ نتیجهٔ TLS-تأییدشده نداشت** (مثلاً وسط قطعی اسکن گرفتی یا SNI بلاک بود)، تاریخچه `best = -1` ذخیره می‌کرد
- کد قدیمی در این حالت یک رشته («—») را به‌جای یک عدد (%2$d) می‌فرستاد → `IllegalFormatConversionException` → **کرش کامل، هر بار باز کردن اپ**
- یعنی از لحظه‌ای که چنین اسکنی ثبت شده بود، اپ دیگر بالا نمی‌آمد — دقیقاً همان چیزی که دیدی

### فیکس (بتا۶۲)
1. شاخهٔ «بدون بهترین» حالا رشتهٔ درست خودش را دارد (`اسکن قبلی: … · N سالم`)
2. کل رندر تاریخچه داخل محافظ است — **دیگر هیچ داده‌ای از تاریخچه نمی‌تواند اپ را بیندازد** (بدترین حالت: «هنوز اسکنی ثبت نشده»)
3. ممیزی کل اپ برای همین کلاس باگ: فقط همین یکی بود

### نصب
APK بتا۶۲ را از رلیز نصب کن — روبه‌رویش همون نصبِ معمولی (بدون پاک‌کردن داده). تاریخچهٔ خراب هم می‌ماند هم دیگر آسیبی نمی‌زند.
