# نسخه v1.10.0-beta25 — ECH (تیکه‌های ECH/SIIT-سبک) — پنل 6.18.0

## ECH (Encrypted ClientHello)
همان چیزی که در پنل‌های دیگر «مستر تیقه SIIT-Hex64»، «تیکه‌های همزاد ECH» و «ECH + 443» نام دارد — نسخهٔ واقعی و استانداردش:

- **کارساز**: ورکر رکورد DNS HTTPS (TYPE=65) دامنهٔ SNI را با DoH می‌خواند، `ECHConfigList` را درمی‌آورد، ۲۴ ساعت در KV کش می‌کند و روی لینک‌های TLS به‌شکل `&ech=<ECHConfigList>` می‌نشیند
- **کانفیگ‌ساز (🛠️)**: انتخابگر «ECH» — روشن که بزنی، لینک ساب با `?ech=1` ساخته می‌شود + چیپ وضعیت («⚡ ECH ✓ (دامنه)» یا «ندارد»)
- روی لینک هم می‌شود مستقیم زد: `?ech=1`
- فقط روی کانفیگ‌های TLS می‌نشیند (کانفیگ بدون TLS معنا ندارد)؛ اگر SNI یا DNS ECH نداشت، بی‌صدا رد می‌شود و لینک سالم می‌ماند
- پشتیبانی سمت کلاینت: Xray-core ≥ 1.8.x / v2rayNG و کلاینت‌های جدید (ECH کلادفلر)

## صادقانه
- ECH فقط وقتی واقعاً ساخته می‌شود که دامنهٔ SNI در رکورد ۶۵ش ECH داشته باشد (skk.moe و اکثر دامنه‌های پشت کلادفلر دارند)؛ در سندباکس تست بدون شبکه، «ندارد» نشان می‌دهد و لینک بدون ech سالم می‌ماند
- WARP/MASQUE/F&F و «تیکه‌های» اختصاصی پنل‌های دیگر پروتکل‌های اختصاصی کلاینت Aether/PattNG هستند — در ساب استاندارد جایی ندارند؛ اگر WARP-in-WARP خواستی، بگو تا به خروجی Xray اضافه‌اش کنم

## تست
۴ تست جدید ECH (تزریق فقط روی TLS، پیش‌فرض بدون ech، پارس ?ech=) + کل مجموعه‌ها پایدار. تست زنده: /api/ech پاس سالم، UI رندر، لینک با echList دستی.
