# Cat Client v1.10.0-beta8

## پنل ۶.۹.۱ — ساختار واقعی SpiderPanel 🕷️
این بار نه فقط رنگ، **خود ساختار** از سورس SpiderPanel کپی شد:
- سایدبار با **آکاردئون «مدیریت»**: کاربران، اینباندها، اسکنر IP، **نودها**، SNI/ProxyIP، تنظیمات
- آیتم مستقل **«نودها» 🕸️**: جای اختصاصی آی‌پی‌های ثابت — وارد کن / ببین / حذف کن (از صفحهٔ اسکنر جدا شد)
- **فوتر سایدبار**: نقطهٔ سبز چشمک‌زن + «Cat Panel v6.9.1» (مثل Spider Panel v8.0)
- لوگوی 🕷️، آیتم خروج قرمز، آیتم فعال با کادر فیروزه‌ای
- **هشدار داشبورد**: اگر هیچ نود تمیزی نداشته باشی، خودش می‌گوید و دکمهٔ «نودها» می‌دهد — دیگر کانفیگ‌ها بی‌خبر روی آدرس ورکر نمی‌مانند

## یادآوری: آی‌پی ثابت + SNI + اسپوف کجاست؟
- **نودها (آی‌پی ثابت)**: پنل → نودها (یا اسکنر اپ → «ارسال به پنل» با رمز پنل)
- **SNI**: پنل → تنظیمات → SNI/Host (پیش‌فرض skk.moe) + SNIهای اضافه: پنل → 🎭
- **اسپوف (ProxyIP)**: پنل → 🎭 SNI/ProxyIP
