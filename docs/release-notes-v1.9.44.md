# Cat Client v1.9.44 — دکمهٔ «ساخت سریع» ⚡

مثل پنل‌های حرفه‌ای (BPB و…) که همه‌چیز را یک‌جا می‌چینند، حالا پنل تو هم یک‌کلیکی ریکامندشده می‌سازد:

## یک کلیک، یک ریکامهٔ کامل
دکمهٔ **«⚡ ساخت سریع — ریکامند شده»** در بالای سازنده:
- **IPها:** بهترین‌های استخر تأییدشدهٔ اسکنر (و اگر کم بود، کتابخانهٔ پیش‌فرض) — حداکثر ۱۰ تا
- **پورت‌ها:** اگر SNI تمیز فعاله → ریکامهٔ TLS (443/2053/2083/8443)؛ وگرنه → ریکامهٔ امن (80/8080 بدون رمز) با یادآوری تب Spoof
- **بدون ورودی مرده:** host و IPv6 خودکار حذف می‌شوند
- و در همان کلیک **ذخیره** هم می‌شود — لینک ساب فوراً به‌روز است.

جمع‌بندی مسیر پیشنهادی: اسکن (80+443) → Spoof (اگر 443 بسته بود) → **ساخت سریع** → تمام.
