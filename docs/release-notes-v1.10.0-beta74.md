# Cat Client 1.10.0-beta74 (versionCode 141) — پنل 6.52.0

## ⚡ ECH حرفه‌ای — با مقدار مشترک کلادفلر
طبق راهنمایی درخواستی، مقدار `cloudflare-ech.com+udp://1.1.1.1` در ECH پنل نشست. این فرمِ «کوئریِ زنده»ی Xray است: کلاینت خودش رکورد HTTPS دامنهٔ `cloudflare-ech.com` را می‌خواند — و چون کلادفلر کلید ECH را برای **همهٔ** سایت‌های پشت شبکه‌اش مشترک منتشر می‌کند، هر SNI (مثل `skk.moe` یا `icook.tw`) که خودش رکورد ECH ندارد هم SNI واقعی‌اش روی سیم رمز می‌شود. مزیت کوئری زنده: چرخش کلیدهای کلادفلر هیچ‌وقت مقدار را کهنه نمی‌کند.

**کجا اعمال می‌شود (با `?ech=1` — سوییچ ECH در کارت سازنده):**
- لینک‌های vless/trojan: پارامتر `ech=` با انکود کامل (`+` → `%2B`)
- خروجی **Xray** (JSON): `tlsSettings.echConfigList` مطابق داکیومنت رسمی
- خروجی **Clash/mihomo** (شامل خود اپ ما): `ech-opts: {enable: true, query-server-name: cloudflare-ech.com}` — با تشخیص درست فرم کوئری و base64 (فایل ECH که خودش `+` دارد قاطی نمی‌شود)
- خروجی **sing-box**: عمداً بدون ECH — طبق باگ مستند (سپتامبر ۲۰۲۶) اگر DNS رکورد ECH را ندهد، sing-box به‌جای fallback **FATAL** می‌کند و کل کانفیگ می‌میرد

**فیلد تنظیمات جدید (SNI و اثر انگشت ← ECH):** خالی = پیش‌فرض مشترک کلادفلر · `auto` = فقط رکورد خود SNI (روش قبلی، از DoH با کش ۲۴ساعته) · `off` = خاموش (حتی با `?ech=1`) · هر چیز دیگر = عیناً همان مقدار (base64 یا فرم کوئری). چپ‌چسب «echState» حالا مقدار مؤثر را نشان می‌دهد.

**تست دائمی:** `ech.test.mjs` — ۱۸ بند روی سورس **و** آرتیفکت مبهم (پیش‌فرض، opt-in، مقدار دلخواه، auto+کش، off، Clash/Xray/sing-box، گزارش API). به `npm test` و گیت CI اضافه شد.
