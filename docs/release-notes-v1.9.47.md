# Cat Client v1.9.47 — آپدیت پنل دیگر هیچ‌وقت گیر نمی‌کند 🔓

## چرا دفعهٔ قبل نتونستی؟
جریان آپدیتِ پنل، قبل از هر کاری «رمز پنل» را از خودِ پنل می‌پرسید — و پنلِ از کار افتاده جواب نمی‌داد. به‌علاوه اگر توکن ذخیره‌شده هم باطل شده باشد، وسط راه «توکن نامعتبر» می‌خورد و تمام.

## حالا
- **رمز پنل کاملاً از مسیر آپدیت حذف شد** — آپلود کد با توکن کلادفلر خودت مجاز می‌شود (مالکیت واقعی همان توکن است). پنل زنده یا مرده فرقی نمی‌کند؛ آپدیت همیشه انجام می‌شود.
- اگر توکن ذخیره‌شده باطل باشد، به‌جای بن‌بست، همان‌جا کادر «توکن جدید» باز می‌شود و ادامه می‌دهی.
- دکمهٔ «گرفتن توکن» هم داخل همان کادر هست.
