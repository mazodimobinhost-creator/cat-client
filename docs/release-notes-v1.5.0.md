# Cat Client v1.5.0 — Cat Wizard (نصب یک‌کلیکی مثل BPB / Matix)

## چی اضافه شد

### 🧙 Cat Wizard — یک ورکر که برای بقیه پنل می‌سازد
- فایل جدید `catclient.wizard.js` (به ریلیز هم ضمیمه می‌شود). روی حساب کلودفلر خودت دیپلویش می‌کنی → لینکش را می‌دهی → هر کسی:
  1. «دریافت توکن کلودفلر» را می‌زند → صفحهٔ API Token کلودفلر با دسترسی‌های **از قبل انتخاب‌شده** باز می‌شود (Workers Scripts: Edit، Workers KV: Edit، Account Settings: Read، User Details: Read) → فقط Continue to summary → Create Token → Copy.
  2. توکن را در ویزارد می‌چسباند → Install.
  3. ویزارد روی **حساب خودش**: ساب‌دامین workers.dev (اگر نداشت می‌سازد)، فضای KV، ورکر Cat Panel با UUID و رمز، فعال‌کردن مسیر، انتظار برای `/health` → آدرس پنل + رمز + لینک ساب + QR + دکمهٔ «افزودن به Cat Client».
- گزارش زنده مرحله‌به‌مرحله (NDJSON streaming)، نوار پیشرفت، فارسی/انگلیسی.
- نصب مجدد روی همان اسم، UUID و KV قبلی را نگه می‌دارد. رمز دلخواه به‌صورت `secret_text` بایند می‌شود.
- اگر توکن دسترسی KV نداشت، پنل باز هم نصب می‌شود (هشدار در لاگ).
- `WIZARD_PASSWORD` → کد دعوت (صفحه خصوصی می‌شود). دکمهٔ «ساخت ویزارد خصوصی خودم» یک کپی از ویزارد را روی حساب بازدیدکننده می‌سازد (کد دعوت به ارث می‌رسد).
- توکن فقط در همان درخواست استفاده می‌شود؛ هیچ‌جا ذخیره نمی‌شود. محدودیت ۲۰ تلاش/ساعت به ازای هر IP.

### 📱 اپ — تب Cloud
- دکمهٔ **🔑 دریافت توکن کلودفلر**: همان لینک template را باز می‌کند؛ راهنمای ۳ خطی زیرش.
- کارت **Cat Wizard**: «ساخت صفحهٔ ویزارد من» با همان توکن → لینک ویزارد ذخیره و نمایش داده می‌شود.

### 🐱 Cat Panel v5.1.0
- مسیر `/token` (ریدایرکت به صفحهٔ توکن آماده) و `/api/token-url`.
- راهنمای پنل: «راه سریع (ویزارد)» با همان لینک.
