# Cat Client 1.10.0-beta50 (versionCode 117) — پنل 6.32.0

## 🌐 تست خروجی — نیمه‌ای که فقط از خط تو دیده می‌شود
با معرفی IPCheck.ing (jason5ng32/MyIP) حالا داخل پنل، کنار «🩺 سلامت و تست»، لینک **🌐 IPCheck.ing** هست با این راهنما:
- به کانفیگ وصل شو → IPCheck.ing را باز کن
- می‌بینی: آی‌پی/کشورِ **خروجی واقعی**، **نشت DNS** (نباید DNS ایرانی ببینی)، **نشت WebRTC**، **پینگ جهانی** و **تست قوانین/سرویس‌ها** (جمنای، چت‌جی‌پی‌تی، استریم…)
- این دقیقاً نیمهٔ «خط خودت» است که تست سمت ورکر (🩺) عمداً پوشش نمی‌دهد — این دو با هم کل ماجرا را می‌پوشانند
- نکته: برای خروجیِ 🧦 socks شخصی، کشوری که IPCheck می‌بیند باید کشورِ socks باشد؛ اگر ایران بود آن socks برای جمنای فایده ندارد

## 🔍 چطور با این دو، هر مشکل را تک‌ریشه کنی
| علامت | 🩺 سمت ورکر | 🌐 IPCheck از خط تو | ریشه |
|---|---|---|---|
| 🩺 سبز، ولی اپ پینگ نمی‌دهد | ✓ | ✗/باز نشد | اپراتور (SNI/پورت) → اسکنر اپ + پورت‌های 2053/2083/2087/2096/8443 |
| هر دو سبز، ولی جمنای باز نمی‌شود | ✓ | خروجی CF | خروجی کلادفلری جمنای را نمی‌پسندد → 🧦 socks خارجی |
| IPCheck نشت DNS نشان داد | — | نشت | DNS خط تو → در کلاینت DNS سرور پاک بگذار (مثلاً 1.1.1.1 از داخل تونل) |

+ محافظت رگرسیون نو در تست‌ها: اسکریپتِ داخل صفحهٔ پنل حالا خودکار parse می‌شود (همان نوع خرابی که CI بتا۴۹ را انداخت، دیگر هرگز لوکال هم نمی‌گذرد).
