# Cat Client v1.9.3 — پنل ۵.۱۰: کشور برای هر کاربر + اسکنری که واقعاً کانفیگ می‌سازد

## چه چیزی جدید است
- 🔒 **قفل کشور برای هر کاربر:** تا کاربر نسازی و کشورش را انتخاب نکنی، هیچ کانفیگی نمی‌گیرد! در تب «کاربران» موقع ساخت/ویرایش، کشورها را با کاما می‌گذاری (مثلاً `NL,DE,FR`) و کاربر فقط از همان‌ها می‌گیرد.
- 🧭 **صفحهٔ انتخاب برای گیرنده:** لینک `/u/...` را در مرورگر باز کنی، خودش به صفحهٔ انتخاب می‌رود — **تعداد کانفیگ** (۳ تا ۸۰) و **کشور** را خودِ طرف انتخاب می‌کند. دکمهٔ ساخت کاربر هم همان لینک صفحه را کپی می‌کند.
- 📥 **اسکنر واقعاً به کانفیگ‌ها وصل است:** با «اسکن از ورکر»، IPهای موفق **خودکار** داخل کانفیگ‌ها می‌روند (با کولو و کشورشان) و لینک ساب همان لحظه تازه می‌شود؛ چیپ‌های کشور و بخش «IPها به تفکیک کشور» هم زنده به‌روز می‌شوند.
- 🌍 **IPv4 + IPv6 مثل حرفه‌ای‌ها:** رنج‌های کامل کلودفلر (لیست `ipv6.txt` همان ابزار محبوب) به اسکنر اضافه شد؛ نمونه‌برداری تصادفی از هر پیشوند IPv6 و تست با `/cdn-cgi/trace` تا کولو و کشور واقعی هر IP معلوم شود.
- 🔌 **پروکسی‌آی‌پی به سبک BPB:** مسیرهای `/proxy-ip` و `/proxy-ip/get` (خروجی JSON با همان قرارداد) + دکمه/API برای کشیدن تازه‌ترین لیست پروکسی-آی‌پی از هر منبعی (`PROXY_IP_SOURCE`).

## مسیر استفاده
1. **درست را بردار:** اکثر گوشی‌ها → `CatClient-V1.9.3-arm64-v8a.apk`؛ مطمئن نیستی؟ `universal`. دانلود کند؟ ابتدای لینک: `https://ghproxy.net/`.
2. پنل را از داخل اپ «بروزرسانی» بزن (پنل ۵.۱۰).
3. در تب «کاربران» برای هر نفر کشور بگذار (`NL,DE,...`) — تا این کار را نکنی، کانفیگی نمی‌گیرد.
4. لینک صفحهٔ کاربر (`/info/...`) را بفرست؛ طرف خودش تعداد و کشور را انتخاب می‌کند.
5. برای IPهای بهتر: تب اسکنر → «اسکن از ورکر» → نتیجه خودکار در کانفیگ‌ها می‌نشیند.

همهٔ APKها با `apksigner verify` و `zipalign` تست شده‌اند؛ `SHA256SUMS` و `CatClient-Windows.zip` نیز روی همین نسخه است.
