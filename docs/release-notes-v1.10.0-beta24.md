# نسخه v1.10.0-beta24 — دکمهٔ «ایپی ثابت» + پین آی‌پی — پنل 6.17.0

## دکمهٔ سریع 📌
- **نوار بالای پنل**: دکمهٔ پین — یک لمس: چرخش خاموش (ایپی‌ها ثابت) / روشن (هر آپدیت ست تازه). وضعیتش با رنگ معلوم است
- **بالای لیست آی‌پی‌ها (تب 📥)**: همان دکمه با متن «📌 ایپی ثابت» / «⚡ چرخش» — برای موبایل همیشه در دسترس

## پین کردن آی‌پی ثابت 📍
- در لیست آی‌پی‌ها، هر آی‌پی حالا دکمهٔ 📍 دارد: «پین به‌عنوان ایپی ثابت»
- آی‌پی پین‌شده **همیشه اول ساب می‌ماند** — حتی وقتی چرخش «هر بروزرسانی» روشن است (بقیهٔ لیست می‌چرخد، پین سر جایش)
- تا ۵ آی‌پی قابل پین است؛ پین با 📌 آبی روی چیپ مشخص می‌شود؛ برداشن پین با کلیک دوباره
- پورت پین خودکار تمیز می‌شود (`1.2.3.4:443` → ذخیرهٔ `1.2.3.4`)
