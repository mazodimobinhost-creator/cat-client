# Cat Client v1.9.0 — پرچم‌های واقعی، چرخش خودکار IP، نسخهٔ ویندوز

## چه چیزی جدید است

- **پرچم واقعی کشورها**: جدول موقعیت لبه‌های Cloudflare از چند شهر محدود به **۳۸۱ شهر** در سراسر دنیا گسترش پیدا کرد؛ حالا هر کانفیگ/آی‌پی که لوکیشنش مشخص باشد پرچم واقعی همان کشور را می‌گیرد. برای موقعیت‌های ناشناخته همان «☁️ Cloudflare edge» صادقانه می‌ماند — هیچ کشوری جعل نمی‌شود.
- **به‌روزرسانی و جایگزینی زندهٔ IPها**: بخش اسکنر یک کارت «سلامت زندهٔ IP» دارد؛ هر IP خراب یا کند به‌طور خودکار حذف و یک جایگزین سالم از کتابخانهٔ اسکنر جای آن گذاشته می‌شود (چرخش خودکار با باهٔ ۵/۱۵/۳۰ دقیقه + دکمهٔ «همین حالا بررسی و جایگزینی»).
- **کتابخانهٔ IPهای عمومی**: فهرست‌های عمومی اشتراک‌گذاری‌شده (شامل کتابخانهٔ Vodiwalker با ۱۲۵۸ IP) حالا هم داخل پنل (مسیر `/api/ir-ips`) و هم داخل اپ زیرنویس اسکنر آمده‌اند — مجموعهٔ بزرگ‌تری از IP تمیز برای هر دو.
- **نسخهٔ ویندوز**: `windows/CatClientWin` با همان هویت بنفش/مشکی/سفید — اشتراک‌ها (همهٔ فرمت‌ها + اشتراک با چند نفر)، اسکنر IP تمیز با پرچم کشور، کانفیگ‌های رایگان و تست تاخیر لینک. بدون هیچ وابستگی (فقط پایتون استاندارد) و خروجی exe آماده از GitHub Actions.
- **گرافیک تازه با سفید بیشتر**: متن‌های اصلی سفید خالص، کنتراست بهتر کارت‌های شیشه‌ای و لبهٔ سفید ملایم روی پس‌زمینهٔ مشکی؛ صفحهٔ لاگین گرادیان بنفشِ دوست‌داشتنی‌اش را نگه داشت و اسکرول همهٔ صفحه‌ها حالا به‌اندازهٔ کافی از نوار پایین فاصله دارد تا هیچ بخشی پنهان نماند.

## مسیر استفاده

1. از صفحهٔ «ساخت کانفیگ» یا اسکنر یا اشتراک‌ها، لینک‌ها را بسازید و به v2rayNG / V2Box / Clash / sing-box بدهید.
2. برای تازه نگه داشتن IPها، «جایگزینی خودکار IPها» را در اسکنر روشن بگذارید.
3. نسخهٔ ویندوز را از فایل ضمیمهٔ همین نسخه دانلود و `run.bat` را اجرا کنید.
