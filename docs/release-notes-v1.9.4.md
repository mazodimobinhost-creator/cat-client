# Cat Client v1.9.4 — پنل ۵.۱۱: ورود با نام کاربری + رمز، بروزرسانی بدون توکن، قیافهٔ مدیریتی

## چه چیزی جدید است
- 🔑 **پنل حالا یوزرنیم و پسورد دارد:** صفحهٔ ورود جدید «ورود مخصوص مدیر» است — نام کاربری + رمز با هم. رمز درست با یوزرنیم اشتباه = رد می‌شود. ضدحملهٔ_brute-force_ هم سر جایش است.
- 🚪 **هیچ‌کس ناشناس وارد نمی‌شود:** موقع ساخت پنل از داخل اپ، نام کاربری (پیش‌فرض `admin`) و یک رمز قوی پیشنهادی بهت داده می‌شود؛ از دقیقهٔ اول پنل مدیریتیِ قفل‌شده است، نه درِ باز. لینک‌های `?p=` قدیمی فقط وقتی کار می‌کنند که یوزرنیم نگذاشته باشی.
- 🙅 **بروزرسانی پنل دیگر توکن کلودفلر نمی‌خواهد:** توکن از لحظهٔ ساخت ذخیره می‌شود؛ برای بروزرسانی فقط **رمز پنل** (و یوزرنیم) ازت پرسیده می‌شود، درست بودنش همان لحظه چک می‌شود و بعد آپدیت نصب می‌شود.
- 🖥️ **قیافهٔ کاملاً نو — سایدبار مدیریتی:** در دسکتاپ/تبلت، منوی کناری با آیکون + عنوان + توضیح برای هر بخش (خانه، کانفیگ‌ها، اسکنر، کاربران، DNS، ابزارها، راهنما) با حالت فعال گرادیانی. هر بخش هم **تیتر و زیرتیتر واضح** دارد تا معلوم باشد کجایی و چه کاری آنجاست. گوشی همان نوار پایین را دارد.
- 🧙 ویزارد هم فیلد نام کاربری پنل گرفت؛ از تب «ابزارها»ی خود پنل هم می‌شود یوزرنیم/رمز را عوض کرد.

## مسیر استفاده
1. اکثر گوشی‌ها → `CatClient-V1.9.4-arm64-v8a.apk` (مطمئن نیستی؟ `universal`؛ دانلود کند؟ پیشوند `https://ghproxy.net/`).
2. پنل را از داخل اپ **بروزرسانی** کن (پنل ۵.۱۱) — فقط رمز پنل ازت پرسیده می‌شود.
3. اگر پنل را از نو می‌سازی: در کارت نصب، یوزرنیم و رمز پیشنهادی را تأیید کن؛ همان‌ها کلید ورود مدیر است.
4. آدرس پنل را در دسکتاپ باز کن تا سایدبار جدید را ببینی.

APKها با `apksigner verify` و `zipalign` تست شده‌اند؛ `SHA256SUMS` و `CatClient-Windows.zip` روی همین نسخه هستند.
