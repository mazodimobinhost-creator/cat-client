# Cat Client 1.10.0-beta51 (versionCode 118) — پنل 6.33.0

## 🌌 «جمنای باز شه» — الان تک‌تک می‌شود فهمید و باز کرد

### ۱) 🧪 دکمهٔ «تست سرویس‌ها» در پنل (کنار 🩺)
- یک‌ضربه: **جمنای، چت‌جی‌پی‌تی، X، یوتیوب** از دلِ **زنجیرهٔ خروجی واقعی** (شامل 🧦 socks و 🎯 proxyip — دقیقاً همان مسیری که کانفیگ‌ها می‌روند) تست می‌شوند
- نتیجه: ✓ سبز = باز می‌شود • ⚠ با کد (مثل 403/429) = گوگل آن خروجی را نمی‌پسندد • ✗ = مسیر مرده
- اگر جمنای ⚠ خورد خودِ پنل می‌گوید: «یک socks5 خارجی در بخش 🎭 اضافه کن (🧦) و دوباره تست بزن»

### ۲) حقیقتِ جمنای (صادقانه)
جمنای خروجیِ Cloudflare را (و هر IP دیتاسنتریِ پرچم‌شده) با 403/429 می‌راند. پس:
- **با خروجی CF: نمی‌شود** — هیچ اپ/ورکری نمی‌تواند (هر کس گفت می‌شود، دروغ است)
- **با 🧦 socks خارجی: می‌شود** — مسیر تمیز: کلاینت → ورکر → socks خارجی → جمنای
- راه دوم: بخش ⛓ زنجیره → `socks5://user:pass@ip:port`

### ۳) سمت اپ: سرویس‌های AI همیشه از تونل
- قواعد DOMAIN-SUFFIX دائمی برای gemini.google.com، aistudio، chatgpt، openai و ملزوماتش — تزریق بالای همهٔ رول‌ها؛ هیچ رول سابی دیگرشان را مستقیم (خروجی ایران) نمی‌برد
