# Cat Client 1.10.0-beta31 (versionCode 98)

## «حداقل از داخل اپ بتونم آپدیتش کنم» — دقیقاً همین شد

### 🎯 مسیر تضمینی آپدیت پنل از داخل اپ (بدون هیچ پیش‌نیازی)
اپ حالا **همیشه** در بخش Cloud → «My Panels»، ردیف پنل را با این دکمه‌ها نشان می‌دهد:
- **⬆ Update Panel** — بدون توکن، بدون رمز، بدون پیش‌نیاز:
  1. نسخهٔ تازهٔ پنل را از رلیز گیت‌هاب می‌کشد (با زنجیرهٔ آینه‌های ایران: ghproxy و…؛ اگر گیت‌هاب بود، jsDelivr)
  2. کد را در **کلیپ‌بورد** می‌گذارد
  3. مستقیم صفحهٔ Workers کلادفلر را باز می‌کند
  4. می‌گویی: Quick edit → Ctrl+V → Deploy
- **نشان نسخهٔ زنده** روی هر ردیف: `v6.22.0 · up to date` یا `v6.20.0 → v6.22.0 available`

### 🐛 ریشهٔ «ورژن نشون نمیده» (همان فیکس بتا۳۰ — اینجا جمع‌بندی می‌شود)
اپ `/api/version` پنل را با قرارداد `panel:"cat-panel"` می‌سنجید؛ ورکر این فیلد را هرگز نمی‌فرستاد → «Version unknown» و آپدیت کور. فیکس در بتا۳۰ (پنل) + تست رگرسیون + حالا در بتا۳۱ تضمین سمت اپ: حتی اگر پنل شناخته نشد، **دکمهٔ آپدیت و آینه‌ها همیشه در دسترس‌اند**.

### برای تو که الان گیر کرده‌ای — مسیر ۵۰ ثانیه‌ای:
1. اپ را به **beta31** آپدیت کن (رلیز گیت‌هاب — APK `CatClient-V1.10.0-beta31-universal.apk`)
2. اپ → Cloud → پنلت در لیست → **⬆ Update Panel** → کد در کلیپ‌بورد + صفحهٔ کلادفلر باز می‌شود
3. Quick edit → paste → Deploy → پنل `6.22.0` شد ✓ حالا دکمهٔ 📥 استخر ProxyIP و همهٔ فیچرهای بتا۲۶+ را داری
