# Cat Client 1.10.0-beta45 (versionCode 112) — پنل 6.27.0

## 🔬 ساب جدیدت را دوباره باز کردم — خبر خوب + دو ریشهٔ باقی‌مانده

**خبر خوب:** ۱۱ آی‌پی غیرکلادفلر (VPSهای خام) از سابت رفته‌اند — لیست الان **تمامش کلادفلر است** ✅ (همه را با رنج رسمی CF چک کردم، حتی دامنه‌ها را تا رکورد A).

### پس چرا هنوز «یسریا پینگ نمی‌دهند»؟ دو ریشه:
1. **کانفیگ‌های دامنه‌ای به DNS خط تو گروگان‌اند** — `www.speedtest.net` در ایران **فیلتر است**؛ DNS مسموم → آن کانفیگ مرده، هرچند IP پشتش سالم است. همین سرنوشت `www.wto.org` و `ip.sb` هم ممکن است روی اپراتورت بیفتد. (آی‌پی‌های خام مثل 104.17.148.22 این مشکل را ندارند — برای همین کار می‌کنند.)
2. **کانفیگ‌های :80 (بدون TLS)** — روی خیلی از اپراتورهای ایران پورت 80 به کلادفلر بسته/خراب است. طبیعی است که پینگ ندهند.
3. و همچنان: **sni=skk.moe** — تا عوضش نکنی، همهٔ TLS-ها رهگیرندِ یک SNIاند.

## 🩹 فیکس بتا۴۵ (پنل 6.27.0): سابِ بدون DNS
- پنل حالا **هر ورودی دامنه‌ای را (حتی خود دامنهٔ ورکر!) موقع سروِ ساب به آی‌پی خام کلادفلر تبدیل می‌کند** (رزولوشن DoH + تأیید رنج CF + کش ۱۲ ساعته در KV)
- یعنی: دیگر هیچ کانفیگی منتظر DNS خط تو نمی‌ماند — حتی WorkerOnly که تا الان روی DNS‌های مسموم می‌مرد
- کلاینت فقط یک TCP به یک آی‌پیِ تأییدشده می‌زند + SNI + Host — هیچ کوئری DNS‌ای در مسیر نیست
- خواستی دامنه‌ای بماند: `?dom=1` در لینک ساب، یا سوییچ جدید در تنظیمات پنل
- تست‌ها: تبدیل دامنه→IP از کش، نگه‌داشتن دامنه با domToIp=false، ردِ کشِ مسموم (غیرCF)

### بعد از آپدیت پنل به 6.27.0 ساب را رفرش کن — کانفیگ‌های دامنه‌ای حالا مثل آی‌پی‌ها پایدارند. برای :80 ها اگر پینگ ندادند طبیعی است (اپراتور)؛ برای SNI همچنان اسکن→⚡ را بزن.
