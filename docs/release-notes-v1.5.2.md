# Cat Client v1.5.2 — کانفیگ‌ها دقیقاً به سبک BPB + سازگار با v2rayNG / v2box

## مرجع: یک کانفیگ BPB که واقعاً وصل می‌شود
کاربر یک ساب BPB کارکرده (از ایران) داد. خروجی‌اش خط‌به‌خط با Cat Panel مقایسه شد؛ فرق‌های مؤثر:

| BPB (کار می‌کند) | Cat Panel 5.2 (قبلی) | Cat Panel 5.3 (الان) |
|---|---|---|
| پورت‌ها: **80**, 8080, 443, 8443, 2053 — پورت 80 اول | فقط 443 | **80, 443, 2053, 8443, 8080** — 80 اول |
| آدرس‌ها: دامنه + IPv4 تمیز + **IPv6 تمیز** + CDN | IPv4 + دامنه | + ۴ آدرس IPv6 کلودفلر (قابل خاموش‌کردن) |
| fingerprint: `ios` / `chrome` | `randomized` (فقط Xray می‌فهمد) | **`chrome`** (Xray, sing-box, mihomo, v2box) + انتخاب در پنل |
| اسم: `💦 3. VLESS - IPv4 : 80` | `🐱 VLESS · 1.2.3.4` | `🐱 3. VLESS - IPv4 : 80 · 1.2.3.4` |
| هیچ `warp://` در ساب | `warp://` انتهای لیست ⇒ v2rayNG/v2box کل ساب را رد می‌کردند | فقط برای Cat Client (UA) یا `?warp=1` |
| ترتیب: هر پورت → دامنه، IPv4، IPv6، CDN؛ VLESS بعد Trojan | آدرس‌محور | همان ترتیب BPB |

اولین کانفیگ لیست حالا `VLESS - IPv4 : 80` است — بدون TLS یعنی اصلاً SNI روی خط نمی‌رود و همان چیزی است که در BPB زودتر از همه وصل می‌شود.

تونل دوباره روی رانتایم واقعی workerd تست شد: VLESS (`ed=2048`) و Trojan ✅.

## چی عوض شد

### 🐱 Cat Panel v5.3.0
- پورت‌های پیش‌فرض BPB (`DEFAULT_PORTS`)، متغیر `PORTS` برای سرور.
- آدرس‌های IPv6 کلودفلر (`+ IPv6` در سازندهٔ کانفیگ، `?v6=0` برای حذف).
- انتخاب Fingerprint (`chrome` پیش‌فرض، `ios` مثل BPB…)، `?fp=`؛ Clash/sing-box هم همان را می‌گیرند؛ sing-box حالا `alpn: http/1.1` دارد.
- `warp://` اختیاری شد (`?warp=1` یا User-Agent شامل `CatClient`) — **دلیل اصلی وصل‌نشدن ساب در v2rayNG / v2box**.
- نام‌گذاری و ترتیب BPB؛ سقف ۲۰۰ کانفیگ در هر ساب (لیست‌های خیلی بزرگ همهٔ کلاینت‌ها را کند می‌کند).
- تونل: با قطع کلاینت، سوکت TCP هم بلافاصله بسته می‌شود.
- تست‌ها: ۱۰ چک جدید BPB-parity در `cat-panel.test.mjs` + به‌روزرسانی `panel-dom.test.mjs`.

### 📱 اپ 1.5.2
- ساب‌ها با User-Agent `CatClient/…` دانلود می‌شوند (تا warp را بگیرد؛ بقیهٔ کلاینت‌ها لیست تمیز می‌گیرند).
- «ساخت ساب از نتیجهٔ اسکنر» حالا برای هر آی‌پی سه کانفیگ می‌سازد: **80 (بدون TLS)**, 443, 2053 — مثل BPB.
- **اتصال سریع‌تر:** ترتیب health-check عوض شد — اول `generate_204` (سبک‌ترین)، بعد Cloudflare trace، آخر letsencrypt. قبلاً اولین پروب یک صفحهٔ HTML از letsencrypt بود که از ایران کند یا مسدود است و باعث می‌شد اتصال چند ثانیه «در انتظار» بماند.

## نحوهٔ استفاده در کلاینت‌های دیگر
- **v2rayNG / v2box / Streisand / NekoBox:** همان لینک `https://<worker>/sub/<uuid>` را به‌عنوان Subscription اضافه کن (Base64 استاندارد). اگر Fragment داری: `tlshello`, `100-200`, `1-1`.
- **Clash / Mihomo / Stash:** `/sub/<uuid>/clash`
- **sing-box / Hiddify:** `/sub/<uuid>/singbox`
- ساب قدیمی را در اپ یک بار «بروزرسانی» کن تا کانفیگ‌های پورت 80 و IPv6 اضافه شوند.
