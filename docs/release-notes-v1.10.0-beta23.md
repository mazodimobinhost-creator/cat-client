# نسخه v1.10.0-beta23 — چرخش خودکار کانفیگ‌ها (ست تازه با هر آپدیت ساب) — پنل 6.16.0

## چی خواسته بودی؟
«خودکار کانفیگ بسازه و با هر آپدیت ساب، کانفیگ جدید بگیرم» — انجام شد:

## چرخش خودکار (تنظیمات پنل → «چرخش خودکار کانفیگ‌ها»)
- **هر بروزرسانی** (پیش‌فرض روشن!): هر بار که کلاینت ساب را آپدیت می‌زند، چیدمان آی‌پی‌ها و شمارهٔ کانفیگ‌ها عوض می‌شود — لیست کلاینت هر بار ستِ تازه نشان می‌دهد
- **روزانه**: در طول روز ثابت، فردا چیدمان جدید
- **ثابت (مثل BPB)**: ترتیب همیشگی، بدون تغییر

## نکته‌های فنی
- پورت‌ها دست نمی‌خورند — اولین کانفیگ همیشه TLS :443 است (کیفیت اول لیست حفظ می‌شود)
- با هر آی‌پی تازه‌ای که از مخزن‌ها/اسکنر بیاید، خودش وارد چرخش می‌شود — یعنی «خودکار کانفیگ ساختن» کامل شد: مخزن‌ها آی‌پی می‌آورند + چرخش هر بار ترتیب را نو می‌کند
- لینک هم قابل قفل است: `?rotate=off|fetch|daily` روی هر لینک ساب (کانفیگ‌ساز و تست‌ها از همین استفاده می‌کنند)
- کانفیگ‌های 🎯 ProxyIP و 💦 Clean IP هر دو در چرخش شرکت می‌کنند

## مدرک زنده (۶ بار آپدیت ساب پشت‌هم)
```
@108.162.192.67 → @worker → @www.shopify.com → @141.101.114.7 → …  (هر بار متفاوت)
rotate=daily:  دو بار یکی ✓   rotate=off:  دو بار یکی ✓
```

## بگ‌سوییپ
- ۵ مجموعه تست + ۵ تست جدید چرخش — پایدار در اجراهای متوالی
- فلیک قدیمی تست «KV writes» ریشه‌یابی شد (نوشتنِ آخرین-آنلاین هر ۵ دقیقه) و تست تحمل‌پذیر شد
