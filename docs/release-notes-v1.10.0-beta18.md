# نسخه v1.10.0-beta18 — رفع باگ «ارسال به پنل» (آی‌پی اسکنر داخل کانفیگ‌ها می‌نشیند)

پنل 6.11.1 — باگ ریشه‌ای که باعث می‌شد آی‌پی‌های ارسالی از اسکنرِ اپ به پنل، در کانفیگ‌های ساب **خراب** بنشینند، رفع شد.

## مشکل چه بود؟
- اپ آی‌پی را با پورتِ تست‌شده می‌فرستد: `104.17.71.10:443#DE`
- پنل آن را درست ذخیره می‌کرد، اما موقع ساخت کانفیگ، کل رشته `ip:port` را به‌عنوان «آدرس» می‌گرفت و دوباره پورت می‌چسباند:
  `vless://…@[104.17.71.10:443]:443` ← این لینک هیچ‌وقت وصل نمی‌شد.

## الان
- آدرس لخت می‌شود، پورتِ اسکن‌شده فقط یک‌بار به‌عنوان پورت اتصال می‌نشیند:
  `vless://…@104.17.71.10:443?…#🇩🇪 💦 1. VLESS - Clean IP TLS : 443`
- پرچم کشور (`#DE`) هم سر جایش است؛ IPv6 پین‌شده (`[2001:db8::1]:8443`) هم درست.
- تست رگرسیون به تست‌ها اضافه شد (هم v4 هم v6) و تست زندهٔ end-to-end (لاگین → POST /api/ips → ساب) پاس شد.

## بدون تغییر
- قالب جدید پنل (6.11.0)، مسیرهای BPB، پورت‌ها، آپدیت بدون توکن.
