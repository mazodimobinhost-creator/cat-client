# Cat Client 1.10.0-beta30 (versionCode 97)

## پنل ۶.۲۲.۰ (+فیکس) — رفع آپدیت پنل از داخل اپ

### 🐛 ریشه‌یابی: چرا «ورژن نشون نمی‌ده» و آپدیت پنل از داخل اپ کار نمی‌کرد
- اپ برای شناختن پنل، `/api/version` را صدا می‌زند و فیلد `panel:"cat-panel"` را لازم دارد
- ورکر این فیلد را **هرگز برنمی‌گرداند** → اپ پنل را «ناشناس» می‌دید → نسخهٔ خالی، آپدیت از داخل اپ بی‌اثر
- **فیکس:** `/api/version` حالا `{ok, panel:"cat-panel", version, repo}` می‌دهد (درست طبق قرارداد `PanelUpdate.kt`)
- تست رگرسیون اضافه شد تا این قرارداد دیگر نشکند
- **دکمهٔ ⬆️ آپدیت پنل و دکمهٔ آپدیت داخل اپ حالا کار می‌کنند** (نسخهٔ جدیدتر از رلیز گیت‌هاب کشیده می‌شود)
