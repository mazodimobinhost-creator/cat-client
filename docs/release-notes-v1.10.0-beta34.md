# Cat Client 1.10.0-beta34 (versionCode 101)

## «هر پروکسی‌آی‌پی خودش پورت دارد» — حق با تو بود، حالا پورت سراسر زنجیره جاریست

### 🐛 ریشه: پورت در سه لایه دور ریخته می‌شد
فید xgonce ستون **PORT** دارد ولی:
1. پارسر CSV فقط IP را می‌خواند و پورت را دور می‌ریخت
2. کش استخر، آی‌پی را **لخت** (بدون پورت) ذخیره می‌کرد
3. استخر سالم، پین پورت را هم حذف می‌کرد

نتیجه: هر آی‌پی استخر روی **همهٔ** پورت‌های پنل (443/2053/2083/80/8080…) کانفیگ می‌شد و چون رله فقط روی پورت خودش جواب می‌دهد، بیشترِ کانفیگ‌ها مرده بودند — همان «کار نمی‌کنن».

### ✅ فیکس — پورت از فید تا کانفیگ:
- **CSV:** ستون پورت خوانده می‌شود؛ پورت واقعی فید برنده است، نبود → **443**
- **کش/استخر سالم:** هر آی‌پی حالا `ip:port#کشور` است — دقیقاً **یک** پورت برای هر آی‌پی
- **📥 استخر → لیست اتصال (toAddrs):** آی‌پی‌ها با پین پورت وارد می‌شوند → فقط **یک** کانفیگ 💦 برای هر آی‌پی روی پورتِ خودش (نه شش‌تای مرده)
- **🎯 کانفیگ‌های رله:** رله حالا صریحاً روی `ip:port` خودش dial می‌شود (فیکس دابل‌انکود `%253A` که دیالِ رله پورت‌دار را می‌شکست)

### یادآوری: باز هم، فقط آی‌پی‌های اسکن‌شده روی خط خودت تضمین‌اند
مخزن‌های عمومی حالا حداقل روی پورتِ درستِ خودشان امتحان می‌شوند — اما مرجعِ تو همچنان خروجی اسکنر اپ (TLS-OK) است.
