# Cat Client v1.10.0-beta13

## آپدیت اپ از داخل اپ — همه‌چیز سر جایش، حالا پیدا شدنی
این امکان‌ها از قبل در اپ بود ولی پنهان بود؛ حالا برجسته شد:
- **انتهای صفحهٔ اصلی** خط «کپی‌رایت Cat Client · v1.10.0-beta13» را می‌بینی:
  - ورژن نصب‌شده همیشه آنجا نوشته شده
  - **لمسش کن** → «بررسی نسخهٔ جدید» اجرا می‌شود؛ نتیجه در کارت «بروزرسانی برنامه» (همان صفحه، بالای فوتر) نمایش داده می‌شود: «نسخه نصب‌شده / آخرین نسخه»
- اگر آپدیت باشد: دیالوگ می‌آید → **دانلود با نوار پیشرفت داخل اپ** → نصب داخل اپ (بدون خروج به سایت)
- دانلود از گیت‌هاب + **۴ میرور ضدفیلتر** (ghproxy و…) — برای ایران
- قبل از نصب: امضای APK و SHA-256 بررسی می‌شود
- **هیچ توکنی در این مسیر نیست** — آپدیت اپ فقط از ریلیز گیت‌هاب خودت می‌آید

## یادآوری: فقط این یک‌بار دستی نصب کن (beta12/13 از لینک یا میرور)، بعدش آپدیت‌ها داخل خود اپ می‌آیند.
