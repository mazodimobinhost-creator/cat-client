# Cat Client 1.10.0-beta93 (versionCode 160) — Clean-IP خودکار و ارسال نتیجهٔ اسکن به پنل

## ۱) افزودن خودکار IPهای فید به ساب
- Auto-append فیدهای عمومی Clean-IP پیش‌فرض روشن است؛ حداکثر ۸ IP کش‌شده بعد از IPهای خود مالک به ساب اضافه می‌شود. این IPها به فهرست ذخیره‌شدهٔ مالک کپی نمی‌شوند و جای IPهای خودش را نمی‌گیرند.
- فیدها هر ۱۲ ساعت با Cron یا بازشدن پنل/دریافت ساب به‌روزرسانی می‌شوند. اگر کش هنوز برای اولین ساب آماده نشده، از Nodes دکمهٔ «بروزرسانی» را بزن یا ساب را دوباره دریافت کن.
- کنترل Nodes وضعیت روشن/خاموش را واضح نشان می‌دهد؛ با یک لمس می‌توان افزودن خودکار را خاموش کرد. تنظیم قدیمی `repoAuto:false` که نسخه‌های قبل حتی بدون انتخاب مالک ذخیره می‌کردند، به پیش‌فرض تازهٔ روشن مهاجرت می‌کند؛ خاموش‌کردن پس از این نسخه به‌عنوان انتخاب صریح مالک ذخیره می‌شود.
- این IPهای ورودی Clean-IP هستند، نه ProxyIP. فید عمومی تضمین نمی‌کند هر IP روی شبکه و کلاینت تو کار کند؛ IPهای دریافتی را از همان شبکه‌ای که قرار است استفاده شوند تست کن. `?norepo=1` همچنان راه حذف فید از یک لینک خاص است.

## ۲) اسکنر Cat Client و ورود دستی
- در Nodes دکمهٔ بازکردن اسکنر Cat Client کنار بخش ورود نتیجه اضافه شد. اپ می‌تواند نتیجه‌ها را مستقیم به `/api/ips` بفرستد؛ فقط IPهایی که TLS handshake آن‌ها روی همان دستگاه/شبکه موفق شده، ارسال می‌شوند.
- افزودن، رفتار عادی است؛ جایگزینی کل فهرست فقط با انتخاب صریح گزینهٔ جداگانه انجام می‌شود. چسباندن نتیجه نیز country tagهایی مثل `#DE` را نگه می‌دارد.
- افزودن دستی همچنان در دسترس است و گزینهٔ «اول تست» دارد. اگر سرویس تست پنل خطا بدهد، IPهای تست‌نشده دیگر بی‌صدا اضافه نمی‌شوند.
- نگاشت country و latency ارسالی از اسکنر اکنون با آدرس نهایی ذخیره‌شده هماهنگ است و badge منبع/سرعت درست نمایش داده می‌شود.
