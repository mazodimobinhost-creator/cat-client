# Cat Client 1.10.0-beta28 (versionCode 95)

## پنل ۶.۲۱.۰ — هویت گربه 🐱 + منوی موبایل

### 🐱 لوگوی گربهٔ فیروزه‌ای (طبق اسکرین‌شات شما)
- نشان برند در همه‌جا عوض شد: 🕷️ عنکبوتِ قدیمی → **گربهٔ فیروزه‌ای SVG** (گرادیان امضای پنل)
- جایگاه‌ها: نوار بالا، نوار کناری دسکتاپ، صفحهٔ ورود، صفحهٔ اطلاعات کاربر، **فاوآیکن تب مرورگر**
- بدون مربع پس‌زمینه — دقیقاً مثل عکس، گربه روی زمینهٔ تیره با هالهٔ فیروزه‌ای

### ☰ منوی همبرگری موبایل
- روی موبایل/تبلت (زیر ۱۰۸۰px) ردیف ۱۳تایی دکمه‌های آیکنی جمع می‌شود → یک دکمهٔ گرد ☰
- لمسش کنی، منوی کشویی ۴ستونه با همان همهٔ دکمه‌ها باز می‌شود (داشبورد، کاربران، آی‌پی، اسکن، کانفیگ‌ساز، SNI/ProxyIP، تنظیمات، بکاپ، آپدیت، ایپی ثابت، زبان، درباره، خروج)
- با باز کردن هر بخش، منو خودکار بسته می‌شود؛ دسکتاپ بدون تغییر (نوار کناری)

### ✅ بقیهٔ چیدمان همان عکس است
- کاشی‌های آمار (👥 ✅ ⏳ 📡 🧩)، قرص‌های KV/میزبان/لینک‌ها، کارت 🖥 با ردیف نسخه و KV — دقیقاً همان طرح
- یادآوری: در فایل HTML آفلاین، برچسب‌ها و اعداد خالی‌اند (–) چون به ورکر وصل نیست؛ روی پنل زنده همان‌جا با دادهٔ واقعی پر می‌شوند
