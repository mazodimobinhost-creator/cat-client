# 🚀 ربات دیپلوی مستقل (Cat Deploy Bot)

این ربات **چیزی به پنل کاری ندارد** — فقط یک کار دارد: با یک پیام، آخرین نسخهٔ پنل را روی کلادفلرِ خودت بالا بیاورد یا آپدیت کند. برخلاف ربات داخل پنل (که مدیریت کاربران/لینک‌هاست) این یکی **مستقیم با API Token کلادفلر** دیپلوی می‌کند:

```
تلگرام: /deploy  →  ربات: آخرین رلیز پنل را از گیت‌هاب می‌کشد
                 →  با CF_API_TOKEN مستقیم به Workers API آپلود می‌کند
                 →  KV (cat-panel-kv) را می‌سازد/وصل می‌کند + کران ۱۲ساعته
                 →  ✅ «Cat Panel 6.22.0 deployed → https://cat-panel.<شما>.workers.dev»
```

> 🔒 توکن کلادفلر فقط در **Secrets خود ربات** (روی کلادفلر، رمزنگاری‌شده) می‌ماند — نه در چت، نه در ریپو، نه در پنل.

---

## قدم ۱ — دیپلوی خودِ ربات (یک‌بار، ۲ دقیقه)

**راه راحت — دکمه:**

> [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/mazodimobinhost-creator/cat-client/tree/main/deploy-bot)

**یا دستی:** کلادفلر → Workers → Create → Worker را بساز (`cat-deploy-bot`) → Quick edit → کل `deploy-bot/worker.js` را paste → Deploy.

## قدم ۲ — ۴ secret (همان‌جا، یک‌بار)

Workers → `cat-deploy-bot` → **Settings → Variables & Secrets** → برای هرکدام «+ Add» و نوع **Secret**:

| نام | مقدار | از کجا |
|---|---|---|
| `TG_TOKEN` | توکن ربات (`123456:ABC…`) | @BotFather |
| `CF_API_TOKEN` | توکن با دسترسی **Workers Scripts: Edit** و **Workers KV Storage: Edit** | My Profile → API Tokens → Create → Custom |
| `CF_ACCOUNT_ID` | آیدی اکانت کلادفلر | داشبورد Workers → سمت راست |
| `TG_ADMIN_ID` | آیدی عددی تلگرام تو | @userinfobot |

اختیاری: `WORKER_NAME` (پیش‌فرض `cat-panel`) و `GH_REPO` (پیش‌فرض `mazodimobinhost-creator/cat-client`).

## قدم ۳ — وصل‌کردن وب‌هوک

آدرس ربات را باز کن (مثلاً `https://cat-deploy-bot.<شما>.workers.dev`) → مسیر:

```
/register?key=...
```

کلید `key` = ۱۶ کاراکتر اولِ sha256 توکن ربات — راحت‌ترین راه: بعد از Secrets، در تلگرام `/start` بزن؛ اگر وب‌هوک وصل نباشد ربات خودش راهنمایی می‌کند؛ یا در مرورگر `/register?key=<کلید>` را بساز (می‌توانی هش را از ربات نپرسیده با ابزار آنلاین sha256 بگیری). ساده‌تر از همه: به ربات پیام بده — پاسخ `/start` لینک دقیق را توضیح می‌دهد.

## قدم ۴ — دیپلوی! 🚀

در تلگرام:
- **`/deploy`** — آخرین رلیز پنل را دیپلوی/آپدیت می‌کند
- **`/deploy arena/01a0ebed-cat-client`** — دیپلوی مستقیم از یک برنچ خاص
- **`/status`** — سلامت توکن کلادفلر + لیست ورکرها
- **`/setup`** — چک‌لیست Secrets (چه چیزهایی کم است)

دکمه‌های بزرگ `/deploy` و `/status` با `/start` زیر ربات می‌نشینند.

## نکته‌ها

- **آپدیت پنل، بدون از دست رفتن تنظیمات:** ربات فقط کد ورکر را عوض می‌کند؛ KV نام `cat-panel-kv` را اگر بود وصل می‌کند، اگر نبود می‌سازد. کاربران/تنظیمات پنل می‌مانند.
- **پنلِ تازه نصب‌شده** با `OPEN_PANEL=true` بالا می‌آید (مثل دکمهٔ Deploy) — بعداً در پنل رمز بگذار.
- **این ربات و ربات پنل فرق دارند:** اگر همان توکن را داخل پنل هم بگذاری، وب‌هوک فقط یکی می‌شود (یک ربات = یک وب‌هوک). پیشنهاد: توکن فعلی را برای این ربات نگه دار و ربات پنل را جدا بساز (BotFather → /newbot).
- **کجا می‌تواند خراب شود؟** اگر توکن CF دسترسی KV نداشته باشد پیام خطای شماره‌دار می‌گیری (`upload 403 — 10000 …`) → توکن را با هر دو دسترسی بساز.
- **توکن لو رفت؟** BotFather → `/revoke` → توکن جدید → Secrets را آپدیت کن.
