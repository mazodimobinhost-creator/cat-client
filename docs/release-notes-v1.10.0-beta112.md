# نسخهٔ ۱٫۱۰٫۰-beta112 — نسخهٔ آزمایشی اتصال هوشمند

این نسخه برای تست عملی قابلیت‌های اتصال هوشمند منتشر شده است.

## موارد قابل آزمایش
- پیشنهاد امن میان Direct، Orbot و پروفایل‌های موجود
- اعمال پیشنهاد فقط پس از تأیید کاربر
- قطع واقعی VPN هنگام انتخاب Direct
- فعال‌سازی Orbot/DNSTT و اتصال مجدد
- اجرای تست تمام پروفایل‌ها بدون فیلتر قدیمی کشور یا نوع
- دسترسی به اسکن IP تمیز و مرکز سلامت/ترمیم پنل
- حافظهٔ جداگانه برای هر شبکه و مسیر، با حداکثر ۲۰ نمونه
- محاسبهٔ نرخ موفقیت، median، p95، jitter، throughput و failure streak

## نکتهٔ صداقت فنی
سلامت control-plane ورکر و بازبودن پورت به‌تنهایی موفقیت تونل محسوب نمی‌شود. تست مستقل UDP/QUIC و failover عمومی میان تمام مسیرها هنوز در این نسخه نهایی نشده‌اند.
