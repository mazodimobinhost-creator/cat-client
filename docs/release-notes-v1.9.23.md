# Cat Client v1.9.23 — کانفیگ گیمینگ، مرتب‌سازی بر اساس پینگ و تب Spoof

## چه چیزی اضافه شد

- **کانفیگ گیمینگ 🎮** — در سازندهٔ کانفیگ پنل، چیپ «🎮 گیمینگ» اضافه شد: فقط پورت‌های کم‌تأخیر (۸۰ و ۴۴۳) را می‌سازد و کانفیگ **WARP را هم اجباری اضافه می‌کند** — WARP تنها مسیر دارای UDP واقعی از کلادفلر است (WireGuard)، پس بازی‌هایی که UDP می‌خواهند راه دارند. صادقانه: کانفیگ‌های VLESS/Trojan روی WebSocket ذاتاً TCP هستند (محدودیت Workers کلادفلر).
- **همهٔ ساب‌ها کم‌پینگ اول** ⚡ — پینگ اندازه‌گرفته‌شدهٔ هر IP حالا ذخیره می‌شود و کانفیگ‌ها همیشه با **سریع‌ترین IP** شروع می‌شوند؛ SNI برندهٔ هر IP (از v5.15) هم همراهش می‌آید. کانفیگ‌های عادی از همهٔ کشورها با بهترین پینگ ساخته می‌شوند.
- **تب Spoof در منوی همبرگری** 🎭 — آیتم جدید «Spoof» (هم در منوی کنار، هم همبرگر): اثر انگشت ClientHello همهٔ کانفیگ‌ها را با یک کلیک عوض کن (chrome / firefox / safari / ios / android / edge / random / randomized)؛ ذخیره که کنی همهٔ کانفیگ‌های جدید با همان ساخته می‌شوند.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.23` آپدیت کن؛ ورکر را با «بروزرسانی پنل» به **۵.۱۷.۰** برسان.
2. گیمینگ: سازندهٔ کانفیگ → چیپ «🎮 گیمینگ» → اعمال؛ یا به لینک ساب `&gaming=1` اضافه کن.
3. Spoof: منو → Spoof → اثر انگشت را بزن → ذخیره.
