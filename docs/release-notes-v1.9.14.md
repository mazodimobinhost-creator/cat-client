# Cat Client v1.9.14 — IP درست v4+v6، دکمهٔ پینگ، IP ثابت و بهترین SNI

## چه چیزی جدید است

- **IP واقعی IPv4 و IPv6، این بار درست** 🎯 — قبلاً فقط یک trace گرفته می‌شد که هر خانواده‌ای اتفاقی وصل می‌شد را گزارش می‌داد؛ حالا برای IPv4 و IPv6 **دو اتصال جداگانهٔ اجباری‌خانواده** زده می‌شود (سرویس‌هایی که فقط v4 یا فقط v6 جواب می‌دهند): هم از داخل تونل (IP خروجی) و هم از شبکهٔ فیزیکی بیرون تونل (IP واقعی). داشبورد حالا مثل سایت‌های My IP هر دو را نشان می‌دهد: IPv4 خروجی روی نقشه + سطر «IPv6: …» + سطر «IP واقعی: …».
- **دکمهٔ پینگ مثل v2rayNG/V2Box** ⏱ — کارت «پینگ» روی داشبورد حالا کلیک‌پذیر است؛ موقع اتصال روی آن بزن تا پینگ واقعی **از داخل همان کانفیگ متصل** (سه نمونه، بهترین) نمایش داده شود.
- **IP ثابت** 📌 — در تنظیمات پیشرفته اسکنر، چیپ «IP ثابت» اضافه شد: روشن کنید و دیگر هیچ تعویض خودکاری انجام نمی‌شود؛ همان IP می‌ماند. دکمهٔ «تعویض فوری» هم حالا تک‌ضربتی است: اگر IP فیلتر شده بود با یک بار زدن، تست و جایگزین می‌شود.
- **چند SNI، بهترین برنده** 🏆 — اسکنر از قبل چند SNI را روی هر IP تست می‌کرد؛ حالا **سریع‌ترین SNI موفق هر IP** داخل خود کانفیگ ذخیره و در سابسکریپشن هم همین بهترین نوشته می‌شود (نه چرخش کورکورانه). این هم در «ذخیرهٔ اسکن ورکر» و هم در بررسی سلامت اپ اعمال شد.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.14` آپدیت کن؛ ورکر را با «بروزرسانی پنل» به نسخهٔ **۵.۱۵.۰** برسان.
2. پینگ: وصل شو → روی کارت پینگ بزن.
3. IP ثابت: تنظیمات اسکنر → چیپ «IP ثابت»؛ اگر روزی فیلتر شد، «تعویض فوری».
4. IP/کشور: وصل که شدی IPv4 و IPv6 خروجی + IP واقعی هر دو روی داشبورد است.
