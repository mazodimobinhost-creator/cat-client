# نسخهٔ ۱٫۱۰٫۰-beta111 — خودترمیم محافظه‌کارانهٔ Worker

نسخه‌کد: **۱۷۸** · پنل همراه: **۶٫۶۷٫۶** · Deploy Bot: **۲٫۳٫۰**

این نسخه فایل دقیق `cat-deploy-bot.worker.js` را کنار APKها در Release قرار می‌دهد تا قابلیت رفع 1101 را بتوان بدون گرفتن سورس نامشخص آزمایش کرد.

## رفتار ترمیم

- `/repair` یا `/heal` ابتدا health را بررسی می‌کند و به Worker سالم دست نمی‌زند.
- پیش‌فرض: فقط بعد از **دو شکست متوالی** ترمیم می‌کند؛ `HEAL_FAILURE_THRESHOLD=3` آن را محتاط‌تر می‌کند.
- UUID، KV، D1 (از جمله `IOT_DB`)، bindingهای سفارشی و Secretهای موجود حفظ می‌شوند؛ مقدار Secret خوانده یا چاپ نمی‌شود.
- نسخهٔ جایگزین دوباره health-check می‌شود و در صورت شکست، rollback اجرا می‌شود.
- cron هر ده دقیقه فعال است و با `AUTO_HEAL=0` خاموش می‌شود.
- `SAFE_REF` می‌تواند شاخهٔ محافظت‌شدهٔ بازیابی را پین کند؛ بدون آن آخرین Release استفاده می‌شود.
- `/save` نسخهٔ ثبت‌شده در تاریخچهٔ Cloudflare و نام bindingهای قابل‌بازیابی را گزارش می‌کند، نه محتوای D1/KV را.

## وضعیت تأیید

`node scripts/deploy-bot.test.mjs` سبز است و سناریوهای عدم deploy روی Worker سالم، دو شکست متوالی، redeploy، حفظ D1/KV/Secret، منبع بازیابی پین‌شده، health پس از نصب و rollback را با APIهای mock اجرا می‌کند.

**تأییدنشده:** هنوز خرابی عمدی 1101 روی حساب واقعی Cloudflare اجرا نشده است. این قابلیت خطای runtime/deployment را با redeploy درمان می‌کند؛ محدودیت حساب، توکن ناقص، 1102 CPU و قطعی خود Cloudflare را رفع نمی‌کند.
