# نسخه v1.10.0-beta20 — مخزن‌های زندهٔ آی‌پی تمیز (۱۲ساعته + جایگزینی خراب‌ها) — پنل 6.13.0

## مخزن‌ها (تب 📥 آی‌پی‌ها، کارت بالای صفحه)
دو مخزن عمومی و زنده پیدا و وصل شد:
- **Arista Clean IPs** — لیست متنی، آپدیت هر ساعت (GitHub Action)
- **Matix Scanner** — ~۲۰۰۰ آی‌پی آنلاین با سرعت و کولو، اسکن هر ۱۰ دقیقه (مرتب‌شده بر اساس سریع‌ترین)

قابلیت‌ها:
- **بروزرسانی خودکار هر ۱۲ ساعت** — با cron واقعی کلادفلر (`0 */12 * * *` در wrangler، برای دیپلوی یک‌کلیکی) + بروزرسانی تنبل وقتی پنل باز می‌شود + دکمهٔ «⟳ بروزرسانی» دستی
- **جایگزینی خراب‌ها** — هر آی‌پی که ۳ بار مرده گزارش شود فوراً از استخر حذف می‌شود و در بروزرسانی بعدی، فید تازه جایگزینش را می‌آورد (گزارش: `POST /api/repos {action:"health", dead:[…]}`)
- **چیپ کشورهای استخر** با تعداد — دکمهٔ «+» کنار هر کشور، ۱۶ آی‌پی همان کشور را به لیست اصلی پنل اضافه می‌کند
- **افزودن خودکار به ساب** (اختیاری، پیش‌فرض خاموش): ۸ آی‌پی تازهٔ استخر، پین‌شده روی 443، بعد از لیست خودت — با `?norepo=1` هم می‌توانی در لینک ساب خاموشش کنی
- **مخزن دلخواه خودت** — دکمهٔ «➕ مخزن جدید»: هر URL خام (txt یا JSON ماتکسی) را بده؛ پارسرش هوشمند است (`ip`، `ip:port`، `ip#CC`، کامنت، JSON-speed)

## صادقانه
- استخر مخزن به KV نیاز دارد؛ بدون KV فقط در حافظهٔ همان اجرا است (پنل خودش می‌گوید)
- در سندباکس تست، فیدهای واقعی شبکه ندارند — کل زنجیره با فیکسچر (txt + JSON) تست شده: merge، uniq، مرتب‌سازی سرعت، حذف ۳-مرده، import کشور، auto-append ساب، `?norepo=1` — همه پاس
