# Cat Client v1.9.26 — دریافت IP تازهٔ انجمن با یک دکمه 🔄

## چه چیزی اضافه شد

- **دکمهٔ «دریافت IP تازهٔ انجمن» در تب اسکنر** — ورکر خودش (از لبهٔ کلادفلر، نه از اینترنت فیلترشدهٔ تو) لیست‌های IP تمیز انجمن را می‌کشد و به استخر اسکن اضافه می‌کند.
- منابع: **XIU2/CloudflareSpeedTest** (پایدارترین لیست IP کلادفلر از ۲۰۲۰ — نسخهٔ v4 و v6) از مسیر jsDelivr/ghproxy/raw؛ اگر یکی بسته بود، بعدی امتحان می‌شود.
- **فیلتر سفت:** هر IP فقط اگر داخل رنج رسمی کلادفلر باشد قبول می‌شود — آدرس‌های خراب، CIDR، دامنه و IP غیر CF دور ریخته می‌شوند (سقف ۴۰۰۰ IP).
- **صددرصد بی‌خطر:** این IPها فقط وارد «استخر اسکن» می‌شوند؛ فقط آن‌هایی که اسکن تو را پاس کنند به کانفیگ می‌رسند. اگر همهٔ منابع هم از دسترس خارج شوند، دکمه پیام خطا می‌دهد و استخر قبلی دست‌نخورده می‌ماند.

## مسیر استفاده

1. اپ → `CatClient-V1.9.26`؛ ورکر → «بروزرسانی پنل» به **۵.۱۹.۰**.
2. پنل → اسکنر → «🔄 دریافت IP تازهٔ انجمن» → بعد «شروع اسکن از مرورگر» — تمام.
