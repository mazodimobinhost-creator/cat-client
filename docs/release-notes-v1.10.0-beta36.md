# Cat Client 1.10.0-beta36 (versionCode 103)

## انتخاب پنل دیگر «الکی» نیست — خودت انتخاب می‌کنی 🎯

### 🐛 ریشهٔ «آی‌پی‌ها به پنل نمیرسن»
اپ برای «ارسال به پنل»، پنل را از بین دامنه‌های داخل ساب‌ها **حدس** می‌زد و گاهی اشتباه می‌زد — یا رمز را غلط می‌گذاشت. الان:
- **اگر چند پنل شناخته شود، دیالوگ «کدام پنل؟» باز می‌شود و خودت انتخاب می‌کنی**
- پنل‌های شناخته‌شده = همان‌هایی که با این اپ ساختی/وصل کردی (اولویت اول) + پنل‌های داخل ساب‌ها
- رمز پنل در دیالوگ از قبل با UUID همان پنل پُر است
- همین برای «افزودن SNI به پنل» هم اعمال شد

### آی‌پی‌های سفید هنوز به پنل نمی‌رسند؟ ترتیب درست:
1. اپ → اسکنر → اسکن → فقط سبزها (TLS-OK)
2. «ارسال به Cat Panel» → «کدام پنل؟» → پنلت را انتخاب کن → OK
3. پیام «اضافه شد — پنل الان N آی‌پی دارد»
4. ساب را رفرش کن

## جایگزینی آی‌پی و SNI
- نشان نسخهٔ زنده روی ردیف پنل: `v6.23.0 · up to date` یا `v6.20.0 → v6.22.0 available`
- «⬆ Update Panel» بدون توکن: کد تازه از رلیز (با آینه‌های ایران) → کلیپ‌بورد → کلادفلر
- آی‌پی/پورت جدید از اسکنر = جایگزین مؤثر کانفیگ‌ها؛ SNI هم از اسکنر SNI با گزینهٔ «افزودن به پنل» همان‌جا عوض می‌شود (🧬 SNI configs)
