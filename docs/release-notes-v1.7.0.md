# Cat Client v1.7.0 — اسکنر واقعی، کانفیگ رایگان و به‌روزرسانی داخل برنامه

## چه چیزی جدید است

- نسخهٔ برنامه `1.7.0` با `versionCode 14`.
- تب اسکنر IP با نمونه‌برداری تصادفی از رنج‌های Cloudflare، کتابخانهٔ IPهای رایج ایران و رنج‌های دلخواه.
- تست دو مرحله‌ای هر IP: اتصال TCP و سپس TLS با SNI انتخاب‌شده و `/cdn-cgi/trace` برای تشخیص colo پاسخ‌دهنده.
- نتیجه‌ها بر اساس مسیر قابل استفاده و تأخیر مرتب می‌شوند؛ بهترین IP با برچسب مکان واقعی edge یا fallback شفاف `Cloudflare edge` پیشنهاد می‌شود.
- امکان اعمال سریع‌ترین IP به‌عنوان fronting یا ساخت subscription جدید Cat از IPهای TLS-verified.
- دریافت کانفیگ‌های عمومی از چند منبع HTTPS با mirror، حذف تکراری‌ها، cache آفلاین، افزودن تکی، QR و تست همهٔ کانفیگ‌ها از صفحهٔ تست اتصال.
- داشبورد Cat glass، globe، برچسب‌های کشور/پورت/flag و آیکون جدید Cat Client حفظ و تکمیل شده‌اند.
- updater داخل برنامه آخرین release رسمی Cat Client را از GitHub پیدا می‌کند، APK مناسب ABI را می‌گیرد، SHA-256 و package/signature/variant را بررسی می‌کند و سپس نصب Android را باز می‌کند.
- گزارش diagnostics محلی برای خطاهای startup، Mihomo و تست اتصال قابل کپی/اشتراک‌گذاری است؛ اطلاعات حساس قبل از خروجی redact می‌شود.

## مسیر استفاده

1. از تب **اسکنر IP** دامنهٔ پنل را به‌عنوان SNI وارد کنید یا SNI پیشنهادی را انتخاب کنید.
2. اسکن را اجرا کنید؛ نتیجهٔ `TLS ✓` برای اعمال به کانفیگ قابل استفاده است.
3. روی **اعمال سریع‌ترین IP** بزنید، یا **ساخت کانفیگ Cat** را انتخاب کنید تا کانفیگ‌های VLESS/Trojan با SNI پنل ساخته شوند.
4. در تب **رایگان** روی دریافت، تست پینگ و افزودن بزنید. منابع عمومی ممکن است ناپایدار باشند؛ قبل از استفاده، نتیجهٔ تست را بررسی کنید.
5. از تنظیمات → **به‌روزرسانی برنامه** نسخهٔ جدید را بررسی و داخل خود برنامه دانلود/نصب کنید.

## نکتهٔ امضای Android

برای اینکه update بدون حذف نسخهٔ قبلی نصب شود، همهٔ releaseها باید با یک keystore ثابت ساخته شوند. متغیرهای secrets زیر باید در GitHub Actions تنظیم باشند:

- `CATCLIENT_RELEASE_KEYSTORE_B64`
- `CATCLIENT_RELEASE_STORE_PASSWORD`
- `CATCLIENT_RELEASE_KEY_ALIAS`
- `CATCLIENT_RELEASE_KEY_PASSWORD`

اگر APKهای قدیمی با کلید موقت CI نصب شده باشند، Android اجازهٔ upgrade مستقیم نمی‌دهد؛ آن نصب قدیمی فقط یک‌بار نیاز به حذف و نصب دوباره دارد. پس از تنظیم کلید ثابت، نسخه‌های بعدی داخل برنامه به‌روزرسانی می‌شوند.
