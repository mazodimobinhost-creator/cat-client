# Cat Client 1.10.0-beta32 (versionCode 99)

## «ایپی سفیدا از اپم وارد پنلم نمیشن» — ریشه‌یابی و رفع

### 🐛 چرا «ارسال به پنل» برایت جواب نمی‌داد
- اپ موقع ارسال، **رمز پنل را دستی می‌پرسید** — و رمز پیش‌فرض پنل همان UUID است که اپ موقع ساختش روی آن گذاشته و کاربر معمولاً بلد نیست → لاگین رد می‌شد → آی‌پی‌ها وارد نمی‌شدند
- **فیکس:** رمز حالا **خودکار با UUID ذخیره‌شدهٔ پنل پر می‌شود** — «ارسال به Cat Panel» یک‌ضربه‌ای است (اگر رمز را عوض کرده‌ای، همان را بنویس)
- همزمان همهٔ آی‌پی‌های تاییدشده **کلیپ‌بورد** می‌شوند + پیام راهنما: اگر ارسال خودکار نشد، در پنل ← جعبه‌ابزار ← «وارد کردن نتیجهٔ اسکن» بچسبان

### 📡 مسیر درست آی‌پی: اسکن روی شبکهٔ خودت
- آی‌پی‌هایی که الان در سابت هست (#۱ تا #۱۲ با پرچم DE/US/CA) از **مخزن‌های عمومی** آمده‌اند (واسط ProxyIP/دیفالت‌ها) — این‌ها عمومی‌اند، ساعت‌ها کهنه می‌شوند و روی خیلی از اپراتورها جواب نمی‌دهند؛ «کار نمی‌کنن» طبیعی است
- **تنها آی‌پی معتبر، آی‌پیزیه که روی شبکهٔ خودت تایید شود:** اپ → اسکنر آی‌پی تمیز → اسکن → فقط سبزها (tlsOk) → **ارسال به Cat Panel** → پنل همان‌ها را با پورتِ تاییدشده پین می‌کند و کانفیگ 💦 می‌سازد — این‌ها روی خط خودت کار می‌کنند
