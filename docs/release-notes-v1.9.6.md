# Cat Client v1.9.6 — پنل ۵.۱۲.۱: رفع کامل خرابی دکمه‌های پنل

## چه چیزی رفع شد
- 🖱️ **دکمه‌های پنل دوباره کار می‌کنند — همه‌شان:** یک خطای ساخت رشته در کد سمت مرورگرِ پنل (از نسخهٔ ۵.۱۰) باعث می‌شد کل اسکریپت پنل قبل از اجرا بشکند؛ نتیجه‌اش این بود که اسکنر، کانفیگ‌ها، اعمال، ذخیره… هیچ‌کدام پاسخ نمی‌دادند. ریشه پیدا شد، اصلاح شد و **تست رگرسیون جدید** اضافه شد که دیگر اجازه نمی‌دهد چنین خرابی‌ای انتشار پیدا کند.
- 🩺 کارت «چک سلامت آی‌پی‌ها» (اضافه‌شده در ۵.۱۲) هم اکنون واقعاً کار می‌کند: پینگ همهٔ آی‌پی‌ها، شناسایی کشور/کلو/پرچم، حذف خودکار مرده‌ها.
- 🔗 اتحاد لینک ساب (انتخاب دستی + استخر کشورها + نتیجهٔ اسکن) و کانفیگ مولتی‌لوکیشن از ۵.۱۲ سر جایشان هستند — حالا با دکمه‌های کارا.

## مسیر استفاده
1. `CatClient-V1.9.6-arm64-v8a.apk` (یا `universal`) را نصب کن؛ دانلود کند؟ پیشوند `https://ghproxy.net/`.
2. از داخل اپ **بروزرسانی پنل** را بزن (پنل ۵.۱۲.۱ — فقط رمز پنل پرسیده می‌شود).
3. پنل را باز کن: تب‌ها، اسکنر، کانفیگ‌ها و چک سلامت باید همه پاسخ بدهند.

`SHA256SUMS` و `CatClient-Windows.zip` روی همین نسخه هستند.
