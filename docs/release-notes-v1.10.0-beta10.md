# Cat Client v1.10.0-beta10

## آپدیت پنل بدون توکن 🎫⛔
دیگر هیچ‌وقت توکن Cloudflare پرسیده نمی‌شود (مگر خودت «آپدیت خودکار» را انتخاب کنی):
- دکمهٔ «بروزرسانی پنل» → به‌جای درخواست توکن، **«کپی کد و باز کردن کلادفلر»**:
  کد جدید (از ریلیز، یا از خود APK اگر گیت‌هاب نبود) کپی می‌شود و داشبورد کلادفلر باز می‌شود
- فقط: Workers → پنلت → Edit code → Ctrl+A، Ctrl+V → Deploy (راهنمای فارسی خودش نمایش داده می‌شود)
- گزینهٔ «آپدیت خودکار (با توکن)» هم سر جایش است برای کسی که توکن ذخیره کرده
