# Cat Client 1.10.0-beta27 (versionCode 94)

## پنل ۶.۲۰.۰ — استفاده از ProxyIPها به‌عنوان آی‌پی اتصال

### 📥 استخر ProxyIP → لیست اتصال (یک‌ضربه‌ای)
- دکمهٔ جدید «افزودن استخر سالم به لیست اتصال» روی کارت مخزن‌های ProxyIP
- تا ۶۴ IP سالم استخر با **تگ کشورشان** (`ip#CC`) به لیست آی‌پی‌های اتصال اضافه می‌شوند → برای هرکدام کانفیگ 💦 ساخته می‌شود (VLESS+TROJAN، پورت‌های خودت، پرچم و نام کشوری)
- ادغام هوشمند: تکراری‌ها حذف، IPهای خراب فیلتر، سقف ۴۰۰ آی‌پی حفظ می‌شود
- API: `POST /api/prepos {action:"toAddrs", limit}` — تست‌شده با KV مصنوعی (import + tag + dedupe + ساخت کانفیگ در ساب)

### ⚠️ صداقت فنی (مهم)
- ProxyIP اول از همه «واسط سمت ورکر» است — کانفیگ‌های 🎯 ساب همان کار را می‌کنند
- هر ProxyIP لزوماً به‌عنوان آدرس اتصال جواب نمی‌دهد؛ بعد از ایمپورت، با تست اتصال اپ یا اسکنر فیلترشان کن. آی‌پی‌های مرده را دستی پاک کن یا ۳ بار health بده

### قبلی (beta26): WARP-in-WARP با کلیدهای خودت، ساب‌های خارجی `/ext` + پیش‌تنظیم Serverless، کانفیگ‌ساز Aether، مخزن‌های کشوری US/TR/FR/NL
