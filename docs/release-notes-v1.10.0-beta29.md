# Cat Client 1.10.0-beta29 (versionCode 96)

## پنل ۶.۲۲.۰ — ربات تلگرام برای دیپلوی خودکار 🤖

### `/deploy` در تلگرام = پنل جدید روی کلادفلر
```
تلگرام: /deploy  →  پنل: دستور به GitHub Actions  →  گیت‌هاب: wrangler deploy  →  تلگرام: «✅ deployed»
```
- **`/deploy [برنچ]`** — دیپلوی برنچ پیش‌فرض یا برنچ دلخواه
- **`/deploys`** — وضعیت ۳ دیپلوی آخر (✅❌⏳ + لینک لاگ)
- علاوه بر دستور، **هر push روی کد ورکر هم خودکار دیپلوی می‌شود** (ورک‌فلو جدید `deploy-worker.yml`)

### 🔒 امنیت — بدون توکن کلادفلر در پنل (قانون همیشگی)
- پنل فقط یک توکن **گیت‌هاب** محدود می‌خواهد (fine-grained، فقط همین ریپو، فقط Actions) تا دستور بدهد
- توکن کلادفلر فقط یک‌بار در **GitHub Secrets** ذخیره می‌شود (CLOUDFLARE_API_TOKEN + CLOUDFLARE_ACCOUNT_ID) — در پنل، در KV، در تلگرام: هرگز
- دستورهای دیپلوی فقط برای ادمین‌های تأییدشدهٔ ربات (گیت از قبل ✓)
- توکن گیت‌هاب در API ماسک می‌شود (`••••xxxx`) و فرستادن مقدار ماسک‌شده پاکش نمی‌کند
- بدون Secrets: ورک‌فلو سبز رد می‌شود با پیام «Deploy skipped» — هیچ‌چیز قرمز نمی‌شود
