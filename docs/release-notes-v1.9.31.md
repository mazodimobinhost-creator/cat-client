# Cat Client v1.9.31 — رفع خرابی اسکنر و دکمه‌های اپراتور 🔧

## مشکل چه بود؟

در نسخهٔ قبل، خطِnew هندلر کلیکِ چیپ‌های اپراتور اشتباهی داخل تابع رندرِ جدول اسکنر قرار گرفت — اولین اجرا با خطای مرجع تعریف‌نشده کل اسکریپت پنل را از همان‌جا به بعد می‌کشت: اسکنر شروع نمی‌شد و دکمه‌های اپراتور هم بی‌پاسخ بودند.

## چه شد؟

- هندلر به جای درستش (لِیسنر کلیک سراسری) منتقل شد؛ تابع رندر اسکنر تمیز شد.
- **تست DOM واقعی فعال شد** (jsdom): ۴۹ چک در DOM واقعی اجرا می‌شود — از جمله رندر چیپ‌های اپراتور در اسکنر و سازنده و بازسازیِ لینک ساب بعد از اسکن. این تست دقیقاً همین باگ را می‌گیرد.
- هیچ چیز دیگری عوض نشد — همهٔ قابلیت‌های ۵.۲۱.۰ (باکت جدا برای همراه اول/ایرانسل/رایتل/سامانتل/شاتل/مخابرات) سر جایشان هستند.

## مسیر استفاده

1. ورکر → «بروزرسانی پنل» به **۵.۲۱.۱** (اگر روی ۵.۲۱.۰ گیر کرده بودی، همین آپدیت مشکل را حل می‌کند).
2. اسکنر → انتخاب اپراتور → اسکن — الان کار می‌کند.
