# Cat Client v1.9.21 — پریست فرگمنت اپراتوری (الهام از ZEUS)

## چه چیزی اضافه شد

- **پریست فرگمنت بر اساس اپراتور** 📶 — زیر کلید «فرگمنت TLS» شش دکمهٔ یک‌ضرب اضافه شد: **پیش‌فرض / همراه اول / ایرانسل / رایتل / مخابرات / گیمینگ**. هر اپراتور DPI متفاوتی دارد؛ هر پریست الگوی تکه‌کردن ClientHello مخصوص همان شبکه را روی هستهٔ ByeDPI اعمال می‌کند. امتحان کن، هرکدام جواب داد همان بماند (برای اعمال، اتصال را دوباره برقرار کن).
- این تنها قابلیت کلیدی ZEUS بود که نداشتیم — بقیه از قبل در Cat بود: مسیریابی چندلوکیشن برای هر کاربر، جعل ClientHello (fingerprint)، مسدودسازی تبلیغات/اتحادچگان با DoH، قفل ضد بروت‌فورس لاگین (429 + زمان انتظار)، بکاپ کامل، آپدیت OTA پنل، چرخش خودکار IP و سقف دستگاه.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.21` آپدیت کن.
2. تنظیمات → «فرگمنت TLS» را روشن کن → پریست اپراتورت را بزن → وصل شو. اگر یک پریست جواب نداد، بعدی را امتحان کن.
