# Cat Client v1.6.1 — نصب مطمئن‌تر و بازیابی به‌روزرسانی

## 📱 برنامه

- نسخهٔ نصب `1.6.1` با `versionCode 13` منتشر می‌شود.
- همهٔ APKهای release قبل از انتشار با `apksigner`، `zipalign` و manifest برنامه بررسی می‌شوند.
- نام فایل‌های release با updater برنامه هماهنگ شد:
  - `CatClient-V1.6.1-arm64-v8a.apk` برای گوشی‌های ۶۴بیتی
  - `CatClient-V1.6.1-universal.apk` برای دستگاه‌های پشتیبانی‌شده
- فایل `SHA256SUMS` همراه release منتشر می‌شود.
- آدرس واقعی مخزن Cat Client در updater اصلاح شد؛ updater دیگر به مسیر قدیمی برند قبلی اشاره نمی‌کند.

## ☁️ بازیابی Cat Panel

- اصلاح حفظ UUID قدیمی هنگام Deploy دوبارهٔ همان Worker در این release وجود دارد.
- Worker و KV قبلی را حذف نکنید؛ همان نام Worker و همان KV binding را استفاده کنید.
- اگر Android پیام تعارض امضا نشان داد، آن APK از یک build قدیمی با کلید موقت نصب شده است. حذف آن برنامه دادهٔ محلی را پاک می‌کند؛ پیش از حذف، UUID قدیمی را از پنل/Cloudflare نگه دارید.

## نسخه

- برنامه: `1.6.1` — versionCode `13`
- پنل داخلی: `5.6.0`
