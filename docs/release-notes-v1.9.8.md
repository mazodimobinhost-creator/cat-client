# Cat Client v1.9.8 — پنل ۵.۱۳: انتخاب کشور با کلیک، کشور واقعی روی کانفیگ‌ها، چند SNI

## چه چیزی جدید است
- 🖱️ **انتخاب کشور دیگر تایپ ندارد:** در تب «کاربران»، کشورها با **چیپ‌های پرچم‌دار** انتخاب می‌شوند (یک کلیک = انتخاب/حذف). ویرایش کاربر هم به‌جای پنجرهٔ تایپ، **مودال چیپ‌دار** دارد.
- 🇺🇸 **اسم کانفیگ = کشور واقعی آی‌پی:** هر آی‌پی که اسکن می‌شود، ورکر کشور/کلو/پرچمش را مشخص می‌کند و نتیجه در جدول اسکن (پرچم + شهر + کشور) و **داخل اسم کانفیگ‌ها** می‌نشیند — اگر آی‌پی متعلق به آمریکا باشد، کانفیگ «Cat · United States · … · 🇺🇸» می‌گیری. انتخابی‌های بدون داده هم خودکار از ورکر راستی‌آزمایی می‌شوند.
- 🔀 **چند SNI داخل کانفیگ‌ها:** در تب «کانفیگ‌ها» فیلد «SNIهای بیشتر» اضافه شد (با کاما). کانفیگ‌ها بین این SNIها **می‌چرخند** — دسترسی در شرایط فیلترینگ مختلف بهتر می‌شود؛ در KV هم ذخیره می‌شود.
- 🛰️ **اسکن با SNIهای مختلف:** در اسکنر فیلد «SNIهای اضافی» — ورکر هر SNI را جداگانه روی هر آی‌پی تست می‌کند و جدول نشان می‌دهد کدام SNI روی کدام آی‌پی جواب داد.
- ⚡ **کیفیت و سرعت:** باگ آی‌پی‌های IPv6 در اسکن مرورگر (براکت‌گذاری) رفع شد + دکمهٔ «⭐ انتخاب بهترین‌ها» — ۸ تندترین آی‌پی یک‌جا انتخاب می‌شوند. اسکن v4+v6 مثل قبل هر دو.

## مسیر استفاده
1. `CatClient-V1.9.8-arm64-v8a.apk` (یا `universal`)؛ دانلود کند؟ پیشوند `https://ghproxy.net/`.
2. از داخل اپ **بروزرسانی پنل** بزن (پنل ۵.۱۳ — فقط رمز پنل پرسیده می‌شود).
3. اسکنر → «اسکن از ورکر» (SNIهای اضافی را هم بنویس) → «⭐ انتخاب بهترین‌ها» → «📥 گذاشتن داخل کانفیگ‌ها»؛ اسم کانفیگ‌ها با کشور واقعی ساخته می‌شوند.

`SHA256SUMS` و `CatClient-Windows.zip` روی همین نسخه هستند.
