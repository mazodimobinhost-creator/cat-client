# Cat Client v1.10.0-beta3

## پنل ۶.۶.۰ — بخش 🎭 SNI و ProxyIP (اسپوف)
- بخش مجزا در پنل برای افزودن **SNIهای اضافه** و **ProxyIPها**.
- هر SNI اضافه → یک کانفیگ با نام `🧬 SNI <دامنه>` در ساب (servername همان دامنه — دامنه باید پشت کلادفلر باشد).
- هر ProxyIP → یک کانفیگ با نام `🎯 PX <پرچم> <آیپی>` و مسیر `/?proxyip=` — خروجی همان رله می‌شود (مثل BPB).
- این کانفیگ‌ها **جدا از کانفیگ‌های ایپی تمیز** و با نام متفاوت نمایش داده می‌شوند.
- ورکر مسیر تونل حالا `?proxyip=` را از خود WS می‌خواند — رله‌ی هر اتصال قابل تعیین است.

## پیش‌تنظیم PattN
- در پنل (تنظیمات → Cipher suites): دکمه‌ی **PattN ✨** — cipher suites سیزده‌گانه + ALPN http/1.1 + fingerprint `unsafe` + Fragment تهاجمی را یک‌جا پر می‌کند.
- در اپ: پریست جدید **PattN** در Fragment (شکستن ClientHello از بایت ۱۰۴).

## مدیریت پنل داخل اپ
- کارت «📡 وضعیت و بازیابی پنل» حالا وقتی پنل سالم باشد **مدیریت پنل** را نشان می‌دهد: نسخه‌ی نصب‌شده، جدیدترین نسخه، **⬆ آپدیت پنل** و **🗑 حذف پنل** (ورکر + KV با تأیید حذف می‌شوند).

## اسکنر SNI → پنل
- منوی هر ردیف سبز اسکنر SNI، گزینه‌ی جدید **«افزودن به پنل»** دارد: SNI با رمز پنل به لیست 🧬 اضافه می‌شود.

## قبلی (beta2 → beta3)
- قالب توکن API مثل BPB-Wizard (پر شدن خودکار مجوزها در داشبورد کلادفلر).
- بازیابی پنل بعد از خطای ۱۱۰۱: ورکر جدید با اسم خنثی + برگرداندن تنظیمات و کاربران از پشتیبان محلی.
- اسکنر ProxyIP: دکمه‌ی «⚡ ورودی» (اتصال با IP تمیز، SNI همان دامنه‌ی پنل).
- مسیر مخفی پنل + ۴۰۴ خنثی (ضد اسکنر workers.dev).
