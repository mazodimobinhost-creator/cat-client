# Cat Client v1.10.0-beta12

## 🎫⛔ آپدیت پنل: صفر پرسش، صفر توکن — نهایی
- **پیش‌بررسی سکرت‌ها حذف شد**: قبلاً اگر ورکرت سکرت داشت (مثل UUID که موقع ساخت دستی داده بودی)، آپدیت دیالوگ «مقادیر سکرت» می‌آورد — دیگر نمی‌آید
- با `keep_secrets` کلادفلر، سکرت‌ها موقع آپلود نسخهٔ جدید **دست‌نخورده حفظ می‌شوند** بدون هیچ سوالی
- اگر توکن ذخیره‌شده خراب/منقضی شده باشد هم توکن نمی‌پرسد — مستقیم مسیر بدون‌توکن (کپی کد + باز کردن کلادفلر)
- دکمهٔ «آپدیت خودکار (با توکن)» از دیالوگ حذف شد؛ فقط: **«کپی کد و باز کردن کلادفلر»** → ۴ کلیک

## یعنی
| وضعیت توکن | تجربهٔ آپدیت پنل |
|---|---|
| توکن سالم ذخیره شده | یک تپ — تمام‌خودکار، بدون هیچ سؤالی |
| بدون توکن / توکن خراب | کپی کد + ۴ کلیک در داشبورد — بدون هیچ سؤالی |
