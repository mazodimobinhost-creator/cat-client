# Cat Client 1.10.0-beta91 (versionCode 158) — بررسی دسترسی سرویس‌های خارجی

## چه چیزی اضافه شده؟
در تب اسکنر، دکمهٔ «🌍 تست سرویس‌های خارجی» شش مقصد انتخاب‌شده را مستقیماً از اتصال همین دستگاه بررسی می‌کند:

- Google و YouTube؛
- Google Play Store؛
- Telegram؛
- WhatsApp؛
- Instagram.

اگر VPN کت وصل باشد، درخواست از مسیر فعلی دستگاه و تونل فعال عبور می‌کند؛ اگر وصل نباشد، اتصال عادی گوشی آزمایش می‌شود. برای هر مقصد کد HTTP، زمان پاسخ و یکی از نتیجه‌های واضح نمایش داده می‌شود: پاسخ موفق، پاسخ HTTP/محدود، محدودیت درخواست، خطای سرور، DNS، TLS، مهلت پاسخ یا خطای اتصال. درخواست‌ها موازی ولی محدود اجرا می‌شوند و محتوای صفحه ذخیره نمی‌شود.

## بررسی‌های AI حفظ شده‌اند
دکمهٔ جداگانهٔ «تست سرویس‌های AI» همچنان ChatGPT، Claude، Gemini API، Gemini Web و AI Studio را از اتصال فعلی بررسی می‌کند. پاسخ HTTP به‌تنهایی دیگر با «سرویس حتماً قابل استفاده است» اشتباه گرفته نمی‌شود.

## گزارش و حریم خصوصی
- نتیجه‌ها فقط روی دستگاه می‌مانند؛ اپ آن‌ها را خودکار به پنل یا سرور دیگری نمی‌فرستد.
- دکمهٔ «هم‌رسانی گزارش تشخیصی» اختیاری است و فقط وقتی نتیجه‌ای وجود دارد نمایش داده می‌شود.
- گزارشِ قابل هم‌رسانی شامل نام سرویس، کد HTTP یا دستهٔ کلی خطا و زمان پاسخ است؛ IP، UUID، لینک اشتراک، کانفیگ و رمز در آن قرار نمی‌گیرد.

## محدودیت مهم
کد 2xx فقط ثابت می‌کند **همان نشانی آزمایشی** از آن اتصال پاسخ داده است. این نتیجه دسترسی به ورود، APIها، CDNها، تماس/پیام‌رسانی یا تمام محتوای اپ را تضمین نمی‌کند. صفحهٔ ورود اپراتور، اختلال موقت یا محدودیت خود سرویس هم می‌تواند روی نتیجه اثر بگذارد. این نسخه ابزار تشخیص اضافه می‌کند؛ مسیر انتقال تازه، پروکسی رایگان مستقل یا تضمین عبور از فیلترینگ اضافه نمی‌کند و دسترسی ۱۰۰٪ را وعده نمی‌دهد.

## تست
- تست واحد `ForeignServiceProbeTest`: فهرست شش سرویس، طبقه‌بندی پاسخ‌های HTTP و تفکیک خطاهای DNS/TLS/timeout.
- اعتبارسنجی اندروید: `:app:testDebugUnitTest` و کامپایل/ساخت Debug APK.
