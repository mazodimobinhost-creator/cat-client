# نسخه v1.10.0-beta17 — بازطراحی کامل قالب پنل (هم‌سطح SpiderPanel)

پنل 6.11.0 — قالب از صفر روی CSS دقیق SpiderPanel خودت بازنویسی شد؛ نه تقریب، نه حالت قبلی.

## چیزهایی که عوض شد
- **دکمه‌ها:** سیستم نهایی خنثی — همه دکمه‌ها (اصلی/سبز/قرمز/شیشه‌ای/…) یک‌شکل: پس‌زمینه `#121216`، حاشیه ۱پیکسل، هاور ته‌رنگ فیروزه‌ای + حاشیه درخشان. دیگه رنگ‌ورنگی و پرریخت‌وپاش نیست.
- **کارت‌ها و جدول‌ها:** تخت `#0a0a0d` با حاشیه ۵٪ سفید، گوشه ۱۶px، سایه عمیق — دقیقاً مثل پنل اسپایدر.
- **آمار:** کارت‌های وسط‌چین با عدد فیروزه‌ای ۲۶px و هاور بالا-پرش ۳px.
- **سایدبار ۲۶۰px (RTL):** برند بالا، آکاردئون مدیریت با ردیف‌های فلت `#000` و نوار سفید ۳px روی آیتم فعال، دکمه خروج قرمز.
- **آیکون‌ها:** همه ایموجی‌های سایدبار و نوار بالا با SVG واقعی (Home/Users/Server/Search/Gear/Logout/…) عوض شد.
- **بج‌ها:** قرصیِ ۴px×۱۰px با پس‌زمینه ۱۵٪ رنگی (سبز/قرمز/آبی/بنفش) مثل `.badge` اسپایدر.
- **ورودی‌ها:** ۱۱×۱۴px، گوشه ۱۲، فوکوس با هاله فیروزه‌ای؛ لیبل‌ها UPPERCASE ریز.
- **نوار بالا:** چسبان و تخت (بدون بلور)، دکمه‌های مربعی ۳۶px خنثی.
- **موبایل:** نوار پایین شیشه‌ای تخت + topbar؛ همان رفتار قبلی.
- **فونت:** Vazirmatn حذف شد؛ استک سیستمی `-apple-system/Segoe UI` مثل خود SpiderPanel (فارسی هم تمیز رندر می‌شود).
- **صفحه لاگین:** لوگوی ۵۶px، عنوان ۱۷px، لیبل‌های ریز — هم‌سبک بقیه.
