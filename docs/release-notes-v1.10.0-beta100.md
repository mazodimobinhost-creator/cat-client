# Cat Client v1.10.0-beta100 (versionCode 167)

«کشورو ولی نشون نمیده» — درست بود، و علتش را پیدا کردم: **کشور فقط یک بار و فقط بعد از
پایانِ اسکن** پرسیده می‌شد، و از مسیری که روی خطِ فیلترشده جواب نمی‌دهد.

## ۱) کشور حالا *از خودِ پروکسی* اندازه‌گیری می‌شود (بدونِ هیچ سرویسِ بیرونی)

همهٔ راه‌های قبلی (ipwho.is / api.country.is / ipapi.co / حتی `/api/geo` ورکر) از
**شبکهٔ خودِ گوشی** صدا زده می‌شوند. روی خطی که این کلاسِ دامنه‌ها را می‌بندد، هیچ‌کدام
جواب نمی‌دهند — عوض‌کردنِ ترتیبِ سرویس‌ها (کارِ beta99) این را حل نمی‌کند، چون مسئله
خودِ «مسیر» است نه انتخابِ مقصد.

ولی یک پروکسیِ سالم، خودش یک راهِ بیرون است. الان این کار انجام می‌شود
(`ProxyEgressCountry.kt`):

```
سوکت → پروکسی (SOCKS5 / SOCKS4a / HTTP CONNECT) → www.cloudflare.com:443
      → TLS با SNI → GET /cdn-cgi/trace → loc=XX
```

`loc=` کشورِ همان شبکه‌ای است که پروکسی از آن بیرون می‌آید؛ پاسخ را خودِ لبهٔ کلودفلر
می‌دهد، پس **هیچ سرویس جغرافیایی واسطی لازم نیست** و روی خطِ بسته هم کار می‌کند.
نامِ میزبان را هم پروکسی حل می‌کند (DNS محلیِ مسموم مانع نیست). این همان ترِیسی است که
اپ از قبل برای لبه‌های کلودفلر استفاده می‌کند، پس چیزِ ناشناخته‌ای به اپ اضافه نشده.

## ۲) کشور *در حینِ* اسکن می‌آید، نه بعد از آن

این باگِ اصلی بود که در اسکرین‌شات دیده می‌شد: نوارِ «در حال اسکن… ۷۳۷ / ۱۳۰۳» بالای
لیستی که ۲۲ ردیفش همه «🌐 نامشخص» بود. `geolocate()` فقط **پس از پایانِ همهٔ ۱۳۰۳
کاندیدا** صدا زده می‌شد، پس در میانهٔ کار هیچ کشوری وجود نداشت — و اگر ⏹ را می‌زدی،
هرگز گرفته نمی‌شد. حالا:

- هر ~۴ ثانیه یک پاس کوتاه فقط برای **میزبان‌های تازه** اجرا می‌شود (هر میزبان یک بار
  پرسیده می‌شود، یک پاس هم‌زمان)، پس کشورها همان‌طور که پروکسی‌ها پیدا می‌شوند ظاهر می‌شوند،
- و **بعد از ⏹** هم یک پاس نهایی اجرا می‌شود، چون ردیف‌ها روی صفحه می‌مانند و نباید
  «نامشخص» بمانند (همین در صفحهٔ ProxyIP هم اضافه شد).

## ۳) خطِ «کشور: …» روی کارتِ اسکن

دیگر لازم نیست حدس بزنی چرا «نامشخص» است؛ خودِ صفحه عددها را می‌نویسد:

```
کشور: ۱۴ اندازه‌گیری‌شده از خودِ پروکسی · ۶ از دیتابیس · ۲ نامشخص
```

در لاگِ عیب‌یابی هم `proxy.country` برای هر پاس و `proxy.country.done` برای پایان
نوشته می‌شود. اگر «اندازه‌گیری‌شده» بالا باشد یعنی مسیرِ پروکسی جواب داده و مشکلِ شبکه
دور زده شده؛ اگر همه «نامشخص» بماند، یعنی آن پروکسی‌ها ۴۴۳ را عبور نمی‌دهند.

## ۴) بندِ دوم زنجیره (beta99) سرِ جایش است

اگر ورکرِ خودت را مستقر کرده باشی، `/api/geo?ip=` هنوز **دومین** مسیر است (بعد از
اندازه‌گیری)، و بعد از آن HTTPSهای عمومی و `ip-api` batch. سقفِ قطع‌کنندهٔ مدار هم ۴
خطا ماند (باگِ beta98 که با دو خطای گذرا همهٔ دسته را «نامشخص» می‌کرد).

## ۵) آنچه هنوز از تو لازم است

- **متنِ کرش**: در نسخهٔ قبل «📄 کپیِ متنِ کرش» را در تنظیمات → عیب‌یابی اضافه کردم؛
  فایلِ کرش به دستم نرسید، پس کرش را **تشخیص نداده‌ام** و روی آن کد نزده‌ام. یک‌ضربه
  دکمه، بعد بچسبان در چت.
- اگر بعد از این نسخه هم روی بعضی ردیف‌ها «🌐» ماند، همان خطِ «کشور: …» بگو چند تا
  «اندازه‌گیری‌شده» بود — با آن عدد می‌فهمم پروکسی‌ها ۴۴۳ را می‌بندند یا چیزِ دیگری است.
