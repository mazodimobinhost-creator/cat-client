# Cat Client 1.10.0-beta47 (versionCode 114) — پنل 6.29.0

## 🩺 «سلامت و تست» واقعی شد — قالب‌به‌قالب، نه TCP کورکورانه

حق با تو بود و در کد هم دیدیم: دکمهٔ قبلی فقط «TCP بزن و ببند» بود و 🎯ها را اصلاً تست نمی‌کرد — در حالی که قالب 🎯 با 💦 زمین تا آسمان فرق دارد. از این نسخه:

| قالب | تست واقعی که انجام می‌شود |
|---|---|
| 💦 Clean IP (TLS) | TCP → **TLS واقعی** → درخواست HTTP با **همان Host پنل و همان مسیر کانفیگ** روی همان IP+پورت → هر جواب HTTP یعنی تمام مسیر سرورِ کانفیگ سالم است |
| 💦 Clean IP (:80) | همان، بدون TLS |
| 🎯 ProxyIP (رله) | TCP → TLS → درخواست `trace` کلادفلر **از دل رله** (ورکر→ProxyIP→سایت CF) → فقط جواب ۲۰۰ یعنی رله واقعاً سالم است |

- دکمه حالا **«🩺 سلامت و تست»** است (همان کارت «لیست آی‌پی‌های پنل») و **هر دو لیست را با هم** تست می‌کند: نتیجهٔ 💦ها سبز/قرمز کنار هر آی‌پی، نتیجهٔ 🎯ها به شکل چیپ «relay✓/relay✗» زیرش
- صادقانه: این تست، **نیمهٔ سرور** را می‌سنجد (IP/پورت/TLS/Host/رله). نیمهٔ دیگر — رفتار SNI روی خط خودت — فقط با اسکنر اپ دیده می‌شود؛ این جدا ناپذیر است
- بدون `cloudflare:sockets` (پیش‌نمایش) همان 501 قبلی؛ {ips} قدیمی هم کار می‌کند
- ۷ تست جدید + همهٔ رگرسیون‌ها سبز

## ⚠️ یادآوری: بعد از دیپلوی این ورکر، دکمه را در «پنل وب» بزن (نه در اپ) — پنل → کارت لیست آی‌پی‌ها → «🩺 سلامت و تست». `/health` باید 6.29.0 بگوید.
