# Cat Client v1.9.29 — برگشت اسکنر به حالت بهتر (رفع پسرفت)

## مشکل چه بود؟

حس تو درست بود: بعد از دکمهٔ «دریافت IP تازهٔ انجمن»، تا ۴۰۰۰ آی‌پی خام انجمن با استخر دستچین قاطی شده بود و اسکنر تصادفی از کل قاطی برمی‌داشت — یعنی بیشترِ هر اسکن از لیست خام می‌آمد که روی اپراتورهای ایران معمولاً تمیز نیست؛ نتیجه: از هر ۴۰ تا فقط ۲-۳ تا پینگ می‌داد.

## چه شد؟

- **اسکن همیشه اول سراغ استخر دستچین‌شده می‌رود** (همان که قبلاً خوب جواب می‌داد).
- IP های انجمن فقط **مکمل**اند: وقتی تعداد اسکن را بیشتر از ظرفیت استخر دستچین بخواهی، باقی را از انجمن پر می‌کند.
- لیست دستی خودت هنوز اولویت اول است.

## مسیر استفاده

1. ورکر → «بروزرسانی پنل» به **۵.۲۰.۲**.
2. اسکن از مرورگر با همان تنظیمات قبلی (۶۰-۸۰ آی‌پی) — کیفیت مثل قبل (و بهتر: IP های غیرکلادفلری هم دیگر در لیست نیستند).
3. اگر خواستی گسترده‌تر بگردی، تعداد را ببر بالا (مثلاً ۲۰۰) — آن‌وقت انجمن هم وارد می‌شود.
