# Cat Client v1.5.3 — ایده‌های Vodiwalker وارد شد + صفحهٔ کاربر + افزودن یک‌ضرب به v2rayNG / V2Box

## مرجع: ورکر Vodiwalker (v2.3) و ویدیوی آموزشی
کد `Vodiwalker/vodiwalker-worker` خط‌به‌خط خوانده شد. از نظر **تونل** همان چیزی است که Cat Panel از v5 دارد (VLESS/Trojan روی WS، early-data در `sec-websocket-protocol`، `[version,0]`، DNS از DoH، fallback به ProxyIP، `allowHalfOpen:false`). فرق‌های مؤثر که وارد شد:

| Vodiwalker | Cat Panel 5.3 (قبلی) | Cat Panel 5.4 (الان) |
|---|---|---|
| مصرف هر کاربر با بستن اتصال **بدون شرط** در KV نوشته می‌شود («باگ مصرف بالا نمی‌رود») | فقط اگر ۱۵ ثانیه از آخرین نوشتن گذشته باشد ⇒ اتصال‌های کوتاه گم می‌شدند | flush اجباری در پایان هر اتصال + `ctx.waitUntil` |
| بایت‌های بافرشده هم در سقف حجم حساب می‌شوند | فقط مقدار نوشته‌شده در KV | `userLiveUsed` = KV + بافر |
| هدر `Subscription-Userinfo` + `Profile-Title` + `Profile-Web-Page-Url` روی ساب کاربر | فقط `subscription-userinfo` | هر سه + `profile-update-interval` ⇒ v2rayNG/V2Box/Hiddify حجم و انقضا را نشان می‌دهند |
| صفحهٔ گرافیکی **فقط** با `/info/TOKEN` یا `?web=1` (نه با حدس User-Agent؛ اپ‌های WebView خراب می‌شوند) | صفحهٔ کاربر نداشت | `/info/<token>` و `/u/<token>?web=1`؛ لینک خام همیشه Base64 |
| `?stats=1` JSON زنده برای صفحهٔ کاربر | — | همان |
| `regenerate` (UUID و توکن جدید) | — | `POST /api/users/<id>/regenerate` + دکمه در پنل |
| `?sync=1` روی لیست کلاینت‌ها (اول flush، بعد لیست) | — | `GET /api/users?sync=1` + تازه‌سازی خودکار هر ۲۰ ثانیه |

چیزهایی که **عمداً** وارد نشد: ذخیرهٔ رمز در KV (Cat Panel `PANEL_PASSWORD`/UUID دارد)، صفحهٔ ۴۰۴ جعلی، PROXYIP تکی (Cat Panel لیست + پیش‌فرض دارد).

## باگ‌هایی که در همین بررسی پیدا و رفع شد
- **Trojan گیت حجم/انقضا نداشت**: کاربر منقضی یا پرحجم با VLESS رد می‌شد ولی با Trojan وصل می‌شد. حالا هر دو یک گیت دارند (`userReasonBlocked`).
- **«Worker's code had hung» در workerd**: وقتی کلاینت فریم Close می‌فرستاد، ما Close متقابل نمی‌فرستادیم (readyState=2) و درخواست باز می‌ماند. حالا `websocketReadable` روی `close` جواب Close می‌دهد و `safeCloseWs` حالت CLOSING را هم می‌بندد. روی رانتایم واقعی تأیید شد (close 1000 «client closed»).
- **زنجیرهٔ Promise مشترک بین درخواست‌ها**: در Workers، Promise ساخته‌شده داخل یک درخواستِ لغوشده ممکن است هرگز settle نشود؛ زنجیرهٔ flush مشترک (الگوی Vodiwalker) باعث می‌شد `/u/<token>` بعدی ۴۰–۹۰ ثانیه گیر کند. جایگزین: flag مشغول با تایم‌اوت ۵ ثانیه؛ flush هم‌پوشان رد می‌شود و بایت‌ها در بافر می‌مانند (و همچنان در سقف حساب می‌شوند).

## چی عوض شد

### 🐱 Cat Panel v5.4.0
- **صفحهٔ کاربر** `/info/<token>`: حلقهٔ مصرف، باقی‌مانده، سقف، انقضا، تعداد اتصال زنده، لینک/QR ساب، و دکمه‌های «افزودن خودکار» به **v2rayNG، V2Box، Hiddify، Streisand، v2rayTun، sing-box، Clash/Mihomo، Shadowrocket** (همان اسکیم‌هایی که Marzban استفاده می‌کند: `v2rayng://install-sub?url=…`، `v2box://install-sub?url=…`، `hiddify://import/…`، `sing-box://import-remote-profile?url=…/singbox`).
- همان دکمه‌ها برای **ساب اصلی** در تب خانه و تب کانفیگ‌ها (با تغییر پورت/آی‌پی در سازنده، لینک‌ها به‌روز می‌شوند).
- تب کاربران: کارت آمار (تعداد کاربران، اتصال‌های زنده، مصرف کل)، نوار مصرف رنگی، وضعیت (فعال/منقضی/حجم تمام/غیرفعال)، دکمه‌های **ویرایش**، **فعال/غیرفعال**، **UUID جدید**، **صفحهٔ کاربر**؛ بعد از ساخت کاربر لینک ساب خودکار کپی می‌شود.
- `GET /api/users` حالا `state` (مصرف زنده، روز باقی‌مانده، وضعیت، آنلاین) و `infoPath` می‌دهد؛ `PUT` فقط فیلدهای مجاز را می‌پذیرد و با ریست مصرف بافر را هم پاک می‌کند.
- حسابداری ترافیک: flush اجباری در پایان اتصال، آستانهٔ ۵MB/۱۵s، بازگرداندن بایت‌ها به بافر اگر KV خطا داد (سقف روزانهٔ پلن رایگان)، `lastSeenAt`.

### 📱 اپ 1.5.3
- کارت هر سابسکریپشن: **نوار حجم** (سبز → کهربایی → قرمز) از `subscription-userinfo`.
- منوی گزینه‌های ساب: **کپی لینک**، **کد QR**، **اشتراک‌گذاری…**، **باز کردن در v2rayNG**، **باز کردن در V2Box**، **صفحهٔ مصرف** (برای Cat Panel `/info/<token>`، برای بقیه `?web=1`). اگر برنامه نصب نباشد، لینک کپی می‌شود.
- `versionCode 9`.

### 🧪 تست
- `cat-panel.test.mjs`: ۲۲ چک جدید (ساخت کاربر با KV حافظه‌ای، هدرهای userinfo با مصرف زنده، `/info`، `?stats=1`، عدم تشخیص UA، ۴۰۳ بعد از اتمام حجم، regenerate، `?sync=1`، deep linkها، گیت Trojan).
- روی workerd واقعی: VLESS (ed و بدون ed)، Trojan، بسته‌شدن تمیز، و ثبت مصرف بعد از هر اتصال (۴۵ بایت × تعداد اتصال) ✅.

## نحوهٔ استفاده
1. پنل را از تب Cloud (Cat Wizard) به نسخهٔ 5.4.0 به‌روز کن (یا فایل ورکر را دوباره Deploy کن).
2. تب **کاربران** → کاربر بساز → «صفحهٔ کاربر» را برایش بفرست؛ خودش با یک ضربه به v2rayNG/V2Box اضافه می‌کند.
3. در Cat Client → سابسکریپشن → «گزینه‌ها» → «باز کردن در v2rayNG / V2Box» برای انتقال همان ساب به برنامهٔ دیگر.
