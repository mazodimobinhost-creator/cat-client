# Cat Client v1.10.0-beta5

## پنل ۶.۸.۰ — انتخاب آزاد پورت + پین‌شدن IP:Port
- در تنظیمات پنل کنار پورت‌های TLS و HTTP دکمهٔ **➕** اضافه شد: **هر پورتی از ۱ تا ۶۵۵۳۵** را اضافه کن (دیگر محدود به پورت‌های پیش‌فرض نیستی)
- پورت‌های سفارشی بعد از ذخیره به‌صورت چیپ باقی می‌مانند
- **پین‌پورت:** اگر آی‌پی را با پورت وارد کنی (`104.16.1.1:2053#DE`)، پنل آن IP را **فقط و فقط روی همان پورتِ تأییدشده** می‌سازد — نه هیچ پورت دیگری
- جعبهٔ «وارد کردن نتیجهٔ اسکن» فرم `ip:port` و `[IPv6]:port` را می‌فهمد
- API پنل (`/api/ips`) هم همان فرمت را ذخیره می‌کند و IP خراب را رد می‌کند

## اسکنر — پورت دلخواه
- چیپ جدید **«✏️ پورت دلخواه»**: هر پورتی (۱ تا ۶۵۵۳۵) را اسکن کن؛ انتخابت ذخیره می‌ماند
- پورت‌های HTTP معمولی (۸۰، ۸۰۸۰، ۲۰۵۲ و…) خودکار بدون-TLS پروب می‌شوند
- **«ارسال به پنل»** حالا `ip:port#کشور` می‌فرستد — یعنی نتیجهٔ اسکن دقیقاً با همان ترکیب تأییدشده داخل پنل ساخته می‌شود

## ارث‌بری از beta4
- پنل ۶.۷.۰ با ظاهر VPN-UI (تم سرمه‌ای/سبز + وزیرمتن)، سایدبار دسکتاپ، Overview/Inbounds/Clients، Add Bulk، ستون آخرین آنلاین
- تست سرعت دانلود اسکنر (۸ تای برتر)، NAT64، مسیر /pyip=، بنر آپدیت پنل

## نصب
APK را نصب کن؛ پنل‌های دیپلویشده هم با بنر آپدیت یا دکمهٔ «⬆ آپدیت پنل» به ۶.۸.۰ می‌رسند.
