# نقشه‌ی بازطراحیِ پنل — مرحله‌ی ۱ (ساختار + خانه)

هدف: پنلِ موبایل‌محور، فارسیِ راست‌به‌چپ، تمیز و سریع. **همه‌ی قابلیت‌های فعلی حفظ می‌شوند**؛ فقط
ساختار، سلسله‌مراتب و ظاهر عوض می‌شود. این سند نقشه است، نه کدِ نهایی.

## اندازه‌گیریِ مبنا (قبل از شروع)

| چیز | عددِ امروز |
|---|---|
| gzip فایلِ دیپلوی (`dist-panel/catpanel.min.js`) | **۱۲۲٬۸۱۴ بایت** |
| gzip سورسِ خوانا (`app/src/main/assets/panels/catclient.worker.js`) | ۱۶۲٬۳۳۷ بایت |
| gzip snapshot ابفسکیت (دیپلوی نمی‌شود) | ۵۶۸٬۵۹۸ بایت |
| سقفِ شما | **۱۵۰٬۰۰۰ بایت** ⇒ حدود ۲۷KB جا داریم |

عددِ مبنا را اینجا نگه می‌دارم و بعد از هر مرحله دوباره اندازه می‌گیرم و در همین جدول می‌نویسم.

## ناوبری: منوی ثابت پایین (۵ بخش)

نُه نمای فعلی (`v-clients`, `v-inbounds`, `v-scan`, `v-build`, `v-nodes`, `v-spoof`,
`v-settings`, `v-backup`, `v-about`) در پنج بخش بازچینی می‌شوند:

```
پایینِ صفحه (ثابت، ۵ آیتم، حداقل ۴۴px ارتفاع، آیکن SVG + برچسب)
┌─────────┬──────────┬──────────┬──────────┬─────────┐
│ ۱ خانه  │ ۲ کاربران│ ۳ آدرس‌ها│ ۴ خروجی │ ۵ تنظیمات│
│   🏠    │   👥     │   🌐     │   📍     │    ⚙    │
└─────────┴──────────┴──────────┴──────────┴─────────┘
```

### ۱. خانه — وضعیتِ یک‌نگاه
| کارت | محتوا | از کجای فعلی |
|---|---|---|
| وضعیت پنل | آنلاین/خطا، نسخه، دکمه‌ی اصلی «بروزرسانی» | hero + `/api/version` |
| ذخیره‌سازی (KV) | وصل / وصل نیست + راهنمای رفع | `kv_warn_title`, `renderKvWarn()` |
| خروجی فعلی | کشور، IP، تأخیر + «تست خروجی» | `loc_now`, `exit_hint` |
| مصرف درخواست | درخواست امروز، نوشتنِ لاگ، مانده در صف | `/api/errors` (جدید) |
| آخرین خطاها | ۵ تای آخر از ۵۰، با زمان و شمارنده | `/api/errors` (جدید) |

### ۲. کاربران و ساب
- لیست کاربران (جستجو، فیلتر فعال/منقضی/غیرفعال، مرتب‌سازی) ← `v-clients`
- لینک ساب + فرمت‌ها در یک **آکاردئون**: URI · Base64 · QR · Clash · sing-box · JSON
- «کپی همه» (دکمه‌ی اصلی کارت) ← `b_copy`
- نمای خالی: «هنوز کاربری نساختی» + دکمه‌ی ساخت ← `no_users`

### ۳. آدرس‌ها — سه تب
| تب | محتوا | از کجای فعلی |
|---|---|---|
| IP تمیز | لیست، تستِ سلامت، حذف، پین | `v-scan` بخش آی‌پی |
| ProxyIP | لیست، کشور، تستِ هر کشور | `v-spoof` (`cc_proxy`) |
| SOCKS5 | لیستِ `socks5://`، تست با handshake واقعی | `v-spoof` بخش 🎭/🧦 |

هر سه تب: **ورود دستی با اعتبارسنجی** (قالب `ip:port` یا `domain:port`؛ socks5 حتماً با
`socks5://`) + پیامِ دقیقِ خطا، و **اسکنر** با دسته‌ها.

### ۴. لوکیشن و خروجی
- مولتی‌لوکیشن: انتخاب کشور، رفتارِ سقوط (`cc_fb_auto` / `cc_fb_none`)
- ایپی ثابت (پین) ← `ip_pin`
- کیفیت هر کشور ← `/api/cc-quality`
- اثباتِ سرویس‌ها (گرفتن/نمایش وضعیت هر سرویس) ← `svc_btn`, `svc_gemini_hint`
- کانفیگ‌ساز ← `v-build` *(پیشنهاد: اینجا)*

### ۵. تنظیمات — آکاردئون، پیش‌فرض بسته
SNI و میزبان · فینگرپرینت · فرگمنت · ECH · پروفایل اپراتور · امنیت (رمز، مسیر مخفی) ·
تلگرام · بکاپ · درباره ← `v-settings`, `v-backup`, `v-about` و بخش‌های `v-inbounds`/`v-nodes`

## موجودیِ کامپوننت (همه بدون کتابخونه‌ی خارجی)

- **کارت**: یک دکمه‌ی اصلی، بقیه ثانویه؛ سایه‌ی ملایمِ یک‌لایه (سایه‌های سنگین فعلی حذف می‌شود)
- **آکاردئون**: `<details>` بومی یا JS؛ گزینه‌های پیشرفته پیش‌فرض بسته
- **آمار**: برچسبِ کوچکِ خاکستری + عددِ بزرگ + زیرنویسِ توضیحی
- **دکمه**: ۳ حالت اصلی/ثانویه/بی‌اثر؛ ارتفاع ≥۴۴px؛ hover و focus قابل‌دیدن
- **Toast**: کوتاه، پایینِ صفحه، ۳ حالت موفق/خطا/درحال‌انجام
- **نمای خالی**: پیامِ راهنما + یک دکمه‌ی عمل
- **نمای درحال‌بار**: skeleton کوتاه (بدون اسپینرِ سنگین)
- **کانتینرِ اسکرول**: جدول و کد فقط داخل خودشان اسکرول می‌خورند، نه کل صفحه

## تم و تایپوگرافی

- **فقط یک تم**، روشن/تیره با `prefers-color-scheme` (دیگر ۱۰ تمِ فعلی نیست)
- فونتِ سیستم (`system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans Arabic", sans-serif`)؛
  **هیچ فونت خارجی لود نمی‌شود**
- آیکن‌ها SVGِ درون‌خطی
- حاشیه‌ها ۱ پیکسلِ کم‌رنگ، شعاع ۱۲ تا ۱۶ پیکسل، بدون گرادیانِ سنگین

## دسترسی‌پذیری

- کنتراست متن/زمینه ≥ ۴.۵:۱ (متنِ کوچک) و ≥ ۳:۱ (آیکن و عددِ بزرگ)
- هر ورودی یک `<label>` واقعی دارد؛ `aria-expanded` روی آکاردئون‌ها؛ `aria-current` روی تب فعال
- `:focus-visible` با outlineِ ۲ پیکسلی
- ترتیبِ فوکوس با DOM یکی است (ناوبری آخرِ DOM)

## مرحله‌بندی

1. **این مرحله (برای تأیید شما)**: ساختار + منوی ۵ بخشی + بخش خانه → پیش‌نمایش در
   `preview.html`
2. بعد از تأیید: بخش ۲ (کاربران و ساب) → ۳ (آدرس‌ها) → ۴ (خروجی) → ۵ (تنظیمات)
3. هر مرحله: `node --check` + ممیزی کلیک (۰ خطای Console) + `npm test` + گزارشِ gzip

## سؤال‌هایی که جوابشان را از شما می‌خواهم

1. `v-build` (کانفیگ‌ساز) را در بخش ۴ (خروجی) بگذارم یا در بخش ۲ کنار لینک ساب؟
2. `v-inbounds` و `v-nodes` را در تنظیماتِ پیشرفته ادغام کنم (پیش‌فرض بسته) یا برایشان
   تبِ جدا در بخش ۵ بگذارم؟
3. آیکنِ هر بخش را همین‌طور ساده (SVG خطی) می‌خواهید یا با رنگِ متمایز؟
