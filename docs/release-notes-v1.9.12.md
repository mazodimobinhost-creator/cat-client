# Cat Client v1.9.12 — شفافیت کامل: IP واقعی و IP تونل، هر دو روی داشبورد

## چه چیزی جدید است

- **دیگر گیج نمی‌شوید** 🎯 — آن آی‌پی‌ای که سایت‌های «My IP» نشان می‌دهند و آن آی‌پی‌ای که اپ نشان می‌داد، دو چیز متفاوت‌اند: یکی IP واقعی اینترنت شما (ورودی تونل) و یکی IP خروجی تونل (که سایت‌ها موقع اتصال می‌بینند). حالا اپ **هر دو را با برچسب واضح** نشان می‌دهد: زیر نقشه موقع اتصال سطر «IP واقعی: … » اضافه شده و IP بزرگ روی نقشه همان است که سایت‌ها می‌بینند.
- **کشور/IP خروجی حالا از دیتابیس واقعی جغرافیا** می‌آید (همان منبعی که سایت‌ها استفاده می‌کنند) نه از برچسب داخلی کلادفلر — دیگر کشور اپ با سایت اختلاف ندارد.
- **بعد از قطع اتصال**، نقشه فوراً به‌روز می‌شود و با برچسب «بدون فیلترشکن» IP واقعی اینترنت‌تان را نشان می‌دهد؛ موقع اتصال هم فقط IP تونل.
- مسیر جدید ورکر `/api/geo` یک‌جا هر دو IP را با جغرافیای دقیق برمی‌گرداند (با کش ۱۰ دقیقه‌ای تا به سقف مصرف نخورد).
- اصلاح تستی: جمع‌بندی تست‌ها وسط فایل بود و بخش‌های ۳۱ به بعد هرگز اجرا نمی‌شدند — منتقل شد به انتهای فایل و حالا واقعاً همه اجرا و پاس می‌شوند.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.12` آپدیت کن (یا آپدیت خودکار داخل اپ).
2. ورکر را با «بروزرسانی پنل» به نسخهٔ ۵.۱۴.۳ برسان.
3. موقع اتصال: IP بزرگ = چیزی که سایت‌ها می‌بینند + سطر «IP واقعی» = اینترنت خام شما. موقع قطع: همان IP واقعی با برچسب «بدون فیلترشکن».
