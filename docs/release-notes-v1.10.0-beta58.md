### ۱) ✍️ افزودن دستی IP — خرابِ کامل بود، حالا درست (ریشه: باگ escape)
- **بازتولید:** ورودی «198.51.100.9 + 2606:4700:4700::1111 + www.visa.com» فقط یک آیپی خراب `a.com:443` می‌ساخت! ریشه: اسکریپت پنل داخل template literal است و `\s` تک‌اسکپ در خروجی به حرف `s` تبدیل می‌شد → رجِکس به‌جای فاصله روی حرف s اسپلیت می‌کرد
- **فیکس + اثبات:** حالا هر سه فرمت درست ذخیره می‌شوند — تستِ کلیکِ واقعی در jsdom ماندگار شد
- **UX تازه:** «اول تست» حالا پیش‌فرض خاموش است (تست کارگر فقط اختیاری)؛ اگر بعضی مرده باشند می‌گوید «‏۳ ✓ / ۲ ✗» و فقط سالم‌ها را می‌گذارد

### ۲) مخزن‌ها و ProxyIPها بروز نمی‌شدند (ریشه: استتار جلوی تپشِ استخرها را گرفت)
- قبلاً استخرها فقط با بازدیدِ پنلِ ادمین تازه می‌شدند؛ با استتار، `/` دیگر پنل نیست → استخر بی‌تپش می‌ماند
- **فیکس:** حالا همه‌جا بی‌صدا تپش دارد: صفحات استتار، صفحهٔ ورود، و مهم‌تر از همه **هر بار که کلاینت‌ها ساب را می‌خوانند** (`/sub`) — حتی بدون cron استخرها زنده می‌مانند (تست‌شده)

### ۳) عبورِ handoffها از استتار
- `/?ips=…` و `/?p=رمز` حالا خودکار به مسیر واقعی پنل (`/panel/…`) می‌پرند — قبلاً صفحهٔ استتار نشان می‌دادند و هیچ
- **«یهویی میاد» حذف شد:** نتیجهٔ اسکن که با لینک بیاید دیگر خودکار ایمپورت نمی‌شود — فقط پیش‌پر می‌شود، دکمهٔ «افزودن» سبزِ گوشه‌دار می‌درخشد و پیام می‌دهد؛ خودت اضافه می‌کنی

### ۴) اپ: مخزن IPv6 + افزودن تک IP
- **کتابخانهٔ v6** به اسکنر اپ اضافه شد: ۷ آدرس Cloudflare همیشه‌پیمایش (2606:4700:4700::1111 و …) — هر شبکه‌ای که v6 واقعی داشته باشد اینها را هم تست می‌کند
- **افزودن تک IP/دامنه داخل اپ:** فیلد «افزودن تک IP یا دامنه» + دکمهٔ افزودن — همان لحظه با SNI/پورت خودت تست می‌شود و فقط اگر جواب داد به نتایج می‌نشیند (v4 / v6 / دامنه)
