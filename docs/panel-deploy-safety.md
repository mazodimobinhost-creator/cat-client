# 🛡️ پنل هیچ‌وقت 1101 نگیرد — راهنمای دیپلوی امن

## چرا 1101 می‌گیری؟
ارور 1101 یعنی «ورکر بالا آمد ولی اسکریپتِ رویش خراب است». در ۹۹٪ موارد علت: **paste ناقص فایل ۳۶۰KB در مرورگر موبایل** (نصف کد نرفته) یا پیست در جای اشتباه. این خرابی با آپدیتِ بعدیِ درست کاملاً پاک می‌شود — تنظیماتت (KV) دست‌نخورده می‌ماند.

## قانون طلایی
> **هیچ‌وقت catclient.worker.js را در مرورگر paste نکن.** آپدیت فقط از این سه راه:

### راه ۱ (بهترین): GitHub Actions — هر پوش، خودش دیپلوی شود
1. GitHub → مخزن → Settings → Secrets and variables → Actions → New secret:
   - `CLOUDFLARE_API_TOKEN` — توکن با دسترسی Workers Scripts: Edit + Workers KV Storage: Edit
   - `CLOUDFLARE_ACCOUNT_ID`
2. تمام. از این به بعد هر نسخهٔ نو (هر بتا) **خودکار** دیپلوی می‌شود + ورک‌فلو بعد از دیپلوی `/health` را چک می‌کند و اگر نسخه ننشسته بود، رد را قرمز می‌کند.

### راه ۲: ربات تلگرام دیپلوی
- `/deploy` — می‌گیرد از آخرین رلیز، آپلود می‌کند، و حالا **بعدش خودش /health را می‌پرسد**: «🫀 health OK» یعنی واقعاً نشسته
- `/doctor` — چک کامل: توکن، ورکر، KV، health
- `/rollback` — برگشت فوری به نسخهٔ قبلی اگر چیزی خراب نشست

### راه ۳: دکمهٔ Deploy to Cloudflare (در README مخزن)
از مرورگر (ترجیحاً PC) دکمهٔ آبی README را بزن — خودش مخزن را می‌گیرد و با wrangler و KV خودکار دیپلوی می‌کند.

## اگر الان 1101 داری (نجات ۳قدمی)
1. `/deploy` در ربات (یا راه ۱/۳)
2. `/health` را باز کن → باید `{"ok":true,"version":"6.34.0",...}` ببینی
3. نشد؟ `/rollback` بزن → `/doctor` بزن و خروجی را بفرست

## کارهای انجام‌شده در همین نسخه برای ضد-1101 شدن
- ربات: health-gate بعد از هر دیپلوی + `/doctor` + `/rollback` (نسخهٔ ربات 2.0.0)
- Actions: گام «Verify deployed health» — اگر /health نسخهٔ نو را نگفت، رد قرمز می‌شود (دیگر سبزِ دروغین نیست) + هشدار بلند وقتی Secrets نیست
