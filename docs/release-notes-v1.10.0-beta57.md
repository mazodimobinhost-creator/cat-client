## 🫥 مبهم‌سازی پنل — کلادفلر/غریبه‌ها بفهمند پنل چیست، نمی‌فهمند
### ۱) استتار پیش‌فرض روشن شد (یک‌بار برای همیشه)
- پنل‌های موجود بعد از دیپلوی خودکار **استتار می‌شوند**: آدرس اصلی (`/`) و حتی `/login` یک «وبلاگ شخصی بی‌خطرباز» نشان می‌دهد — بدون فرم ورود، بدون هیچ کلمه‌ای از panel/config/proxy/vless/uuid
- UI واقعی پنل حالا فقط روی **`/panel`** بالا می‌آید (بقیهٔ مسیرها: 404 خنثی nginx-سبک + robots.txt آرام)
- اگر خواستی خاموشش کنی: تنظیمات → «مسیر مخفی پنل» را خالی بگذار
### ۲) ضد-Error 1101 (دو لایه)
- هر استثنایی که در ورکر رخ بدهد **بیرون نمی‌پرد** — API جواب JSON می‌گیرد، بقیه صفحهٔ خنثی؛ یعنی صفحهٔ «Error 1101» دیگر قابل تولید نیست
- رشتهٔ پروتکل در سورس ورکر دیگر لخت نیست (در زمان اجرا ساخته می‌شود) — چیزی برای انگشت‌نگاری الگو نمانده
