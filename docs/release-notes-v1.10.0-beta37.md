# Cat Client 1.10.0-beta37 (versionCode 104)

## socks5 که کار می‌کند، حالا می‌شود «خروجی کل پنل» ⚡

### چرا تا حالا وارد پنل نمی‌شد؟ (ریشه)
`socks5://83.147.217.103:1080` یک پروفایل **کلاینت‌ساید** است — اپ (هستهٔ Mihomo) مستقیم از آن رد می‌شود، برای همین «برایت کار می‌کند». اما پنل چنین لینکی را وارد لیست آی‌پی نمی‌کند چون آی‌پی اتصال کلادفلری نیست. جای درستش در پنل: **«خروجی ثابت» (Chain)** — همهٔ ترافیک همهٔ کانفیگ‌ها از همین سرور رد می‌شود (IP و کشور ثابت، همان چیزی که این socks5 برایت می‌دهد).

### ✨ جدید در همین دیالوگ
وقتی در «افزودن اشتراک» لینکی با `socks5://` بچسبانی، یک دکمهٔ فیروزه‌ای ظاهر می‌شود:
- **«⚡ افزودن به پنل (خروجی ثابت همهٔ کانفیگ‌ها)»**
- → «کدام پنل؟» → رمز از قبل پُر (UUID) → OK
- پنل: `chain = socks5://…` → **همهٔ** کانفیگ‌های ساب حالا از آن سرور خارج می‌شوند — ساب را رفرش کن
- چرخش/پین/پورت‌ها دست‌نخورده می‌مانند؛ فقط خروجی نرخ ثابت می‌شود

### جمع‌بندی «یک‌جا جمع شدن‌ها» — نقشهٔ فعلی
| چیزی که پیدا می‌کنی | کجا وارد می‌شود | چه می‌شود در ساب |
|---|---|---|
| آی‌پی تمیز اسکن‌شده (TLS-OK) | ارسال به پنل (انتخاب پنل، رمز خودکار) | 💦 پین روی ip:port خودش |
| socks5 / http پروکسی | دکمهٔ ⚡ خروجی ثابت (همین نسخه) | خروجِ همهٔ کانفیگ‌ها از آن |
| ProxyIP مخزنی | خودکار در پنل | 🎯 رله‌های سایت‌های کلادفلری |
| SNI سالم | اسکنر SNI → افزودن به پنل | 🧬 کانفیگ‌های SNI |
