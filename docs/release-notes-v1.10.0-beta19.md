# نسخه v1.10.0-beta19 — کانفیگ‌ساز + اسکنر پیشرفته + گزارش رویدادها (پنل 6.12.0)

سه قابلیت بزرگ جدید داخل پنل — بر اساس عکس‌هایی که فرستادی:

## ۱) کانفیگ‌ساز (تب جدید 🛠️)
- **پروفایل اپراتور** (پیشنهادی): ایرانسل / همراه اول / رایتل-شاتل / مخابرات / مستقیم — هرکدام پورت، فرگمنت پیشنهادی و اثر انگشت را آماده می‌کند
- **پروتکل** (هر دو / VLESS / TROJAN) + **خانوادهٔ آی‌پی** (هر دو / فقط IPv4 / فقط IPv6) + **پورت‌های چندتایی** + **کشور خروجی** با پرچم + **تعداد** + رفتار کشور (سقوط / فقط همین)
- **ساخت ساب زنده**: لینک واقعی می‌سازد، چند خط اول را پیش‌نمایش می‌دهد، «کپی همه» و QR و باز کردن مستقیم در Cat Client / v2rayNG / Hiddify
- فرگمنت داخل لینک نمی‌آید (کار خود کلاینت است) — کادر «فرگمنت پیشنهادی» با پروفایل اپراتور عوض می‌شود تا کپی کنی

## ۲) اسکنر پیشرفته (تب 📡)
- **لوکیشن خروجی فعلی** با پرچم و آی‌پی (از trace واقعی کلادفلر)
- **دستهٔ آی‌پی**: هر دو / فقط IPv4 / فقط IPv6 — روی هم لیست و هم لینک ساب اعمال می‌شود
- **منطقه**: اروپا / خاورمیانه / آسیا / آمریکا / آفریقا + **چیپ کشورهای لیست پنل** با تعداد + **جستجوی کشور** به فارسی («آلمان» یا «DE»)
- هر کشور: دکمهٔ «⚙ ساب فقط این کشور» → می‌پرد به کانفیگ‌ساز با همان کشور
- **افزودن از رنج CIDR** (مثل 104.16.0.0/24 → تا ۱۶ آی‌پی نمونه) یا دامنه، مستقیم به لیست پنل
- صادقانه: مرورگر نمی‌تواند آی‌پی خام را تست کند (محدودیت SNI) — تستِ آی‌پی خام با «اسکن با Cat Client» است که خودش نتیجه را با پرچم به پنل می‌فرستد

## ۳) گزارش رویدادها (داشبورد)
- جدول رویدادهای واقعی: افزودن/تعویض آی‌پی، ساخت/حذف کاربر، تغییر تنظیمات، اجرای اسکنر، ساخت ساب در کانفیگ‌ساز
- در KV ذخیره می‌شود (۵۰ رویداد آخر)، زمان نسبی فارسی

## زیر hood
- پارامترهای جدید ساب: `?fam=v4|v6` و `?ports=` — روی همهٔ خروجی‌ها (URI/Base64/Clash/sing-box/Xray) کار می‌کند
- `GET/POST /api/events` (فقط مالک)
- تست‌های جدید: fam-v4/v6، حلقهٔ رویداد ۵۰تایی، DOM پنل بدون خطا
