# Cat Client v1.9.40 — فیکس باگ پنل + دکمهٔ اتصال اراسی 💊

## رفع باگ پنل (موبایل)
- **نوار تاریکی که بالای صفحه می‌ماند** حذف شد — دراور منو و پس‌زمینهٔ ماتش داخل هدر شیشه‌ای گیر افتاده بودند (محدودیت مرورگرها با المان‌های ثابت داخل backdrop-filter). حالا هر دو در سطح صفحه‌اند: دراور کامل باز/بسته می‌شود و لکهٔ تاریک رفته.
- **دکمهٔ بزرگ «⚡ اتصال فوری در اپ»** بالای پنل — یک لمس، مستقیم داخل اپ + دکمهٔ «کپی لینک ساب» کنارش.

## اپ — سطح اتصال به سبک اراس
- **دکمهٔ اتصال قرصی** (۵۶dp، تمام‌گرد):
  - وصل → **گرادیان بنفش پر** با متن سفید
  - در حال سوییچ → کهربایی · خطا → قرمز · قطع → شیشه‌ای آرام
- کارت‌های کانفیگ با گوشه‌های نرم‌تر (۱۶dp) هماهنگ شدند.
