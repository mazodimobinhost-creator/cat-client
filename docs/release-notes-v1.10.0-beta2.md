# Cat Client v1.10.0-beta2 — بازطراحی Zed، اسکنر پروکسی، تم‌ها، موتور شناختی شبکه (پیش‌انتشار) 🧪

> **بتا**: APK از CI ساخته و با کلید عمومی CI امضا شده (آپدیت درون‌برنامه‌ای از beta1 کار می‌کند). مشکلی دیدی Issue بزن.

## رابط کاربری (به سبک ZedSecure)
- **Home** بازسازی‌شده: blob مرکزی با انیمیشن تنفس/اتصال، برچسب وضعیت، دکمه‌های Map و Speed Test، کاشی‌های ترافیک با موج، Dock پایین؛ گرادیان حالت وصل تا نوار وضعیت و پشت Dock. هر دو حالت وصل/قطع.
- **Map**: نقشهٔ جهان آفلاین با مسیر مبدأ→مقصد، پرچم‌ها (پرچم شیر و خورشید برای ایران)، پینگ/سرور.
- **Speed Test** داخل برنامه.
- **Servers** و شیت «افزودن سرور» (کلیپ‌بورد / QR / دستی / تک‌کانفیگ)، ویرایش، «باز کردن در»، QR کانفیگ.
- **Settings** ردیفی مثل Zed؛ متن فارسی و RTL درست (دکمهٔ گرد نمی‌پرد، برچسب‌های Dock بریده نمی‌شوند).

## تم‌ها
- ۸ پریست: Lavender (پیش‌فرض)، Aurora، Ember، Midnight، Lime، Pink، Amber، Mono — با کارت پیش‌نمایش در Appearance.
- پریست روی **همهٔ** اپ اعمال می‌شود: سطوح، متن، blob، نقشه، دیالوگ‌ها، سوییچ‌ها، فیلدها، نوار وضعیت/ناوبری (ThemeOverlay به‌ازای هر پریست، روشن و تاریک).
- سوییچ **لرزش هنگام اتصال** (پیش‌فرض روشن).

## اسکنر پروکسی عمومی (تب Scanner)
- منابع عمومی (monosans SOCKS5/SOCKS4/HTTP، proxifly) + IP/IP:Port/CIDR دلخواه × لیست پورت؛ Threads و Timeout.
- تست واقعی با handshake: SOCKS5 (greeting + CONNECT)، SOCKS4 (0x5A)، HTTP CONNECT 200 — نه فقط «پورت باز».
- شمارنده‌ها، پرچم کشور، فیلتر پروتکل/کشور، مرتب‌سازی تأخیر، کپی / TXT / JSON، و **افزودن مستقیم SOCKS5 سالم به کانفیگ‌ها**.

## موتور شناختی شبکه (فاز A) — Live IP health
- حافظهٔ زمانی برای هر IP به‌ازای هر شبکه (WiFi / اپراتور): میانه، p95، jitter، نرخ موفقیت، روند، اطمینان.
- طبقه‌بندی خرابی: timeout / tcp / tls / http / slow / latency-excursion / loss-burst.
- Probe تطبیقی (پایدارها کمتر، مشکوک‌ها بیشتر) و رتبه‌بندی چندهدفه به‌جای «کمترین پینگ».
- **خودترمیمی**: افت IP فعال از روی تاریخچهٔ خودش تشخیص داده می‌شود، جایگزین دو بار verify و بعد promote می‌شود — **در همان کشور**؛ کشور دیگر فقط وقتی هیچ IP سالمی در کشور تو نمانده باشد.
- جداسازی لوکیشن‌ها: چیپ هر کشور با پرچم و تعداد، قفل کشور، لیست IPهای همان کشور؛ آمار موتور (مشاهده‌ها، موفقیت probe، failoverها، زمان recovery، دقت پیش‌بینی).
