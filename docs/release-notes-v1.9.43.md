# Cat Client v1.9.43 — اسکنر: همهٔ ۱۳ پورت، به انتخاب خودت 🎛️

## پورت‌های اسکن حالا چیپ‌های قابل انتخاب‌اند
- جای منوی «فقط 80/فقط 443»، یک ردیف **چیپ پورت** آمده: **80، 443، 2053، 2083، 2087، 2096، 8443، 8080، 8880، 2052، 2082، 2086، 2095** — هر کدام را خواستی روشن کن.
- 80 و 443 به‌صورت پیش‌فرض روشن‌اند؛ انتخابت هم **به‌خاطر سپرده می‌شود** (دفعۀ بعد همان‌جا ادامه می‌دهی).
- همهٔ پورت‌های انتخابی در **یک پاس و از خط خودت** تست می‌شوند؛ TLS بودن یا نبودن هر پورت خودکار تشخیص داده می‌شود.
- ستون نتیجه برای هر IP حالا همهٔ پورت‌ها را نشان می‌دهد: `80: 165 ms · 443: ✗ · 2053: 180 ms · …`
- «گذاشتن داخل کانفیگ‌ها» مجموعهٔ کامل پورت‌های زنده را اعمال می‌کند — مثلاً اگر 2053 زنده بود، خودش به کانفیگ‌ها اضافه می‌شود.
