# Cat Client v1.8.0 — بروزرسانی پنل از داخل اپ

## چه چیزی جدید است

- نسخهٔ برنامه `1.8.0` با `versionCode 15` و Cat Panel `v5.7.0`.
- **بروزرسانی پنل از داخل اپ:** در تب Cloud بخش «پنل‌های Cat ساخته‌شدهٔ من» حالا نسخهٔ زندهٔ هر نصب را نشان می‌دهد. دکمهٔ «بروزرسانی پنل» جدیدترین نسخهٔ رسمی پنل را از releaseهای GitHub می‌گیرد (در آفلاین از داخل خود APK) و روی همان ورکر نصب می‌کند.
- رمز UUID، لینک‌های اشتراک، کاربران، کتای‌ها و تنظیمات ذخیره‌شدهٔ پنل بدون تغییر می‌مانند؛ bindingهای قابل‌خواندن حفظ می‌شوند و اگر رمز مخفی دستی (مثل `PANEL_PASSWORD`) روی ورکر باشد که اپ هرگز نمی‌تواند بخواند، بروزرسانی ایمن متوقف و راهنمایی لازم نمایش داده می‌شود.
- نصب دوباره / ترمیم: حتی وقتی پنل به‌روز است، می‌توان ورکر خراب را دوباره از داخل اپ نصب کرد.
- Cat Panel `v5.7.0`: صفحات پنل همیشه `no-store` می‌شوند تا بعد از هر بروزرسانی، UI جدید همان لحظه دیده شود و مرورگر نسخهٔ کهنه را نشان ندهد.
- سه مورد جدید در کاتالوگ پنل‌های خارجی: یک درگاه VLESS مبتنی بر FastAPI با استقرار یک‌کلیکی، یک پنل وب خودمیزبان ساخت کانفیگ با رمزنگاری مشتق از رمز هر کاربر، و یک پروکسی fetch سبک سرورلس — هر کدام دکمهٔ اختصاصی که منبع خودش را باز می‌کند.

## مسیر استفاده

1. به تب **Cloud** برو؛ زیر «پنل‌های Cat ساخته‌شدهٔ من» نسخهٔ فعلی هر پنل کنار آدرسش دیده می‌شود.
2. اگر نسخهٔ جدیدتری آماده باشد برچسب `v فعلی → v جدید` با رنگ برجسته نشان داده می‌شود؛ روی **بروزرسانی پنل** بزن.
3. توکن کلادفلر را یک‌بار وارد کن (از دکمهٔ «ساخت توکن» با دسترسی‌های آماده ساخته می‌شود؛ توکن ذخیره نمی‌شود) و بروزرسانی را تأیید کن.
4. پنل روی همان آدرس قبلی به‌روز می‌شود؛ همهٔ لینک‌های اشتراک قبلی همان‌جا کار می‌کنند.

## نکتهٔ امضای Android

برای نصب روی نسخهٔ قبلی بدون حذف، secrets امضای ثابت باید مطابق [docs/release-signing.md](release-signing.md) تنظیم شوند. تا آن زمان APKهای CI با کلید موقت ساخته می‌شوند و مهاجرت به کلید ثابت فقط یک‌بار حذف/نصب لازم دارد.
