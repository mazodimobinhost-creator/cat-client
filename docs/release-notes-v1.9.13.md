# Cat Client v1.9.13 — نمایش IP خروجی از داخل خود تونل

## چه چیزی جدید است

- **ریشهٔ اختلاف IP پیدا و رفع شد** 🩺 — در نسخهٔ قبل، مسیر جدید مسیر `/api/geo` ردیابی را **از خودِ سرور ورکر** انجام می‌داد، نه از تونل گوشی شما؛ به همین دلیل IP و لوکیشنی نمایش داده می‌شد که هرگز مرورگر شما استفاده نمی‌کرد (IP دیتاسنتر). حالا IP خروجی **از داخل خود تونل، روی گوشی** اندازه‌گیری می‌شود — دقیقاً همان چیزی که سایت‌ها می‌بینند.
- مسیر `/api/geo` ورکر حالا فقط یک «مترجم جغرافیا» است: برای هر IP داده‌شده کشور/شهر/ISP را از همان منبع دیتابیسی که سایت‌های «My IP» استفاده می‌کنند برمی‌گرداند (با کش ۱۰ دقیقه‌ای).
- **IP واقعی اینترنت‌تان** حالا با اتصال جداگانه به شبکهٔ فیزیکی (بیرون از تونل) اندازه گرفته می‌شود — موقع اتصال، سطر «IP واقعی» دقیقاً همان IPv4 سایت است؛ وقتی وصل نیستید نقشه با برچسب «بدون فیلترشکن» همان IP را نشان می‌دهد.
- قانون تستی جدید: `/api/geo` دیگر حق ندارد از سمت خودش به بیرون trace بزند — این اشتباه دیگر تکرار نمی‌شود.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.13` آپدیت کن (یا آپدیت خودکار داخل اپ).
2. ورکر را با «بروزرسانی پنل» به نسخهٔ **۵.۱۴.۴** برسان.
3. وصل شو: IP بزرگ روی نقشه = همان IP که سایت‌ها موقع اتصال نشان می‌دهند + سطر «IP واقعی» = اینترنت خام تو.
