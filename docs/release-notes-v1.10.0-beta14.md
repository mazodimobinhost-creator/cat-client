# Cat Client v1.10.0-beta14

## پنل ۶.۱۰.۰ — کانفیگ‌ها دقیقاً مثل BPB 💦
چیزی که موقع «Edit» در v2rayNG می‌بینی، حالا عین BPB است:

**۱) اسم کانفیگ‌ها (remarks) عیناً BPB:**
- `💦 1. VLESS - Clean IP TLS : 443`
- `💦 12. VLESS - Clean IP : 8080` (بدون TLS، مثل نمونهٔ خودت)
- `🔌 n. VLESS - WorkerOnly : 443` (کانفیگ‌های روی آدرس خود ورکر)
- TROJAN هم به همین شکل + پرچم کشور اول اسم (وقتی شناخته باشد)

**۲) مسیرهای WS مثل BPB:**
- VLESS: `/vl/<seed-16کاراکتری>?ed=2560` — seed مخصوص پنل خودت (مثل BPB هر پنل فرق دارد)
- Trojan: `/tr/<seed>?ed=2560`
- مقدار ed از ۲۰۴۸ به **۲۵۶۰** (مثل BPB)
- مسیرهای قبلی (`/ws`، `/trojan`) همچنان پذیرفته می‌شوند — کانفیگ‌های قدیمی‌ات نمی‌شکنند؛ با آپدیت ساب، نسخه‌های جدید BPB-شکل می‌گیرند

**۳) صادقانه — این‌ها از پنل نیستند:**
بخش‌های `dns` (FakeDNS، 8.8.8.8)، `routing` (بلاک تبلیغات، ایران مستقیم، UDP بلاک)، `sockopt` (happyEyeballs) و `policy` در آن JSON، **تنظیمات خود v2rayNG** هستند و به لینک کانفیگ ربطی ندارند — BPB هم آنها را از کلاینت می‌گیرد. اگر در v2rayNG آن تنظیمات را بگذاری، کانفیگ‌های پنل تو هم دقیقاً همان JSON را می‌سازند.
