# Cat Client 1.10.0-beta65 (versionCode 132) — پنل 6.45.0

## 🎨 ردیزاین پنل — منوی همبرگری + هویت بصری هر بخش + فیکس زوم موبایل

### ۱) همهٔ بخش‌ها داخل منوی همبرگری (☰)
- دکمهٔ ☰ بالای صفحه حالا یک **کشوی کامل** باز می‌کند: هر بخش با **آیکن رنگی مخصوص + نام + یک خط توضیح** («این مال چیست»)
- ۱۰ بخش: 📊 داشبورد · 👥 کاربران · 🧩 اینباندها · 📡 اسکن IP · 🛠️ سازندهٔ کانفیگ · 🎯 IPهای تمیز · 🎭 اسپوف · ⚙️ تنظیمات · 💾 بکاپ · ℹ️ درباره
- با انتخاب هر بخش، منو خودش بسته می‌شود؛ Escape هم می‌بندد
- **نوار پایین صفحه حذف شد** — دیگر هیچ دکمه‌ای ته صفحه نیست؛ فقط محتوا

### ۲) هر صفحه حالا شناسنامه دارد
بالای هر بخش یک **سربرگ بزرگ** آمد: آیکن گرادیانی + عنوان + توضیح یک‌خطی کارِ آن بخش. دیگر معلوم است هر صفحه مال چه.

### ۳) فیکس «مجبورم صفحه را کوچک کنم» — ریشه پیدا شد
- **ریشه**: فونت ورودی‌های پنل 12px بود؛ iOS/اندروید وقتی روی input با فونت زیر 16px تپ می‌کنی، **صفحه را خودش زوم می‌کند**
- فیکس: روی موبایل همهٔ inputها 16px — دیگر موقع تایپ، صفحه پرش زوم نمی‌زند
- دکمه‌ها و آیکن‌ها بزرگ‌تر شدند (لمس راحت‌تر)، فاصله‌ها مرتب شد

### ۴) ریزه‌کاری‌ها
- deep-link خراب `?ips=` که بعد از بتا۵۸ مرده بود فیکس شد (سلکتور ناقص)
- دسکتاپ همان نوار کناری مرتب را دارد؛ موبایل منوی همبرگری — هر دو با همان برچسب‌ها
- `cat-panel.html` ریپو هم به 6.45.0 به‌روز شد (رلیز هم نسخهٔ تازه‌اش را می‌گذارد)

### تست‌ها
