# Cat Client v1.9.41 — چرا فقط ۲–۳ کانفیگ پینگ دارد؟ 💡

## تشخیص هوشمند در سازندهٔ پنل
حالا سازندهٔ پنل خودش توضیح می‌دهد که چرا اکثر کانفیگ‌ها پینگ نمی‌گیرند (فارسی/انگلیسی):

- روی خیلی از اپراتورها **SNI دامنهٔ workers.dev فیلتر است** → همهٔ کانفیگ‌های TLS بی‌پینگ می‌شوند و فقط پورت‌های بدون رمز (80/8080) روی IP تمیز زنده می‌مانند.
- **راه:** تب Spoof → یک SNI تمیز یک‌کلیکی؛ IPv6 فقط اگر سیم‌کارت واقعاً IPv6 بدهد؛ اگر DNS دامنه فیلتر است host را حذف کن.
- **راه‌حل ریشه‌ای:** یک دامنهٔ شخصی به ورکر وصل کن (رایگان).
