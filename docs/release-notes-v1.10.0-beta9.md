# Cat Client v1.10.0-beta9

## چرا آپدیت پنل کار نمی‌کرد؟ (دو علت واقعی)
۱. **داخل پنل**: دکمهٔ آپدیت فقط «نسخهٔ جدید هست» را نشان می‌داد و خود فایل را نمی‌داد — و چون گیت‌هاب برایت فیلتر است، عملاً راهی برای گرفتن فایل جدید نداشتی.
۲. **داخل اپ**: فقط پنل‌هایی که از خود اپ دیپلوی شده بودند در لیست «پنل من» بودند؛ پنل دستی‌ات (که در داشبورد کلادفلر ساختی) اصلاً ثبت نبود، پس دکمهٔ بروزرسانی هم نداشتی.

## حل ۱ — پنل ۶.۹.۲
- **دکمهٔ «⬇️ worker.js»** کنار اعلان آپدیت (Overview و About): فایل جدید **از خود پنل دانلود می‌شود** (`/api/update-download` proxy) — گیت‌هاب لازم نیست
- راهنمای کوتاه: کلادفلر → Workers → پنلت → Edit code → کل کد را عوض کن → Deploy

## حل ۲ — اپ
- دکمهٔ جدید **«اتصال پنل موجود»** در لیست پنل‌ها: آدرس ورکر پنل دستی‌ات را بده → ثبت می‌شود
- بعدش کارت پنل با **نسخهٔ زنده** و دکمهٔ **«بروزرسانی پنل»** ظاهر می‌شود (موقع آپدیت، توکن CF API می‌پرسد و خودش دیپلوی می‌کند)

## نکته
- یک‌بار باید دستی به ۶.۹.۲ برسانی (با دانلود از داخل پنل فعلی یا چسباندن فایل beta9)؛ از آن بعد هم آپدیت داخل پنل فایل می‌دهد هم اپ می‌تواند مستقیم آپدیت کند.
