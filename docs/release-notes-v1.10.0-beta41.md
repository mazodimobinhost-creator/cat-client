# Cat Client 1.10.0-beta41 (versionCode 108) — پنل 6.24.1

## 🔬 خودم ساب زندهٔ تو را باز کردم — ریشهٔ «کار نمی‌کنه اصلاً»

آنچه در ساب واقعی تو دیدم (فیلدبه‌فیلد):
1. **sni=skk.moe روی تک‌تک ۲۴ کانفیگ** — پنل تازه (edge-8rvlt) دیپلوی شده و پیش‌فرضِ همان اول برگشته. اگر اپراتورت skk.moe را ببندد/RST کند، همه با هم می‌میرند. همین است که «هیچ‌کدوم کار نمی‌کنه» می‌سازد.
2. **آی‌پی‌هایت اسکن‌شدهٔ خودت نیستند** — ۹۶.۴۴… و بقیه از مخزن/استخر عمومی با پرچم US آمده‌اند (تست‌نشده روی خط خودت) + `www.visa.com` پیش‌فرض. نیمی از این‌ها احتمالاً روی اپراتور تو مرده‌اند.
3. لینکی که فرستادی `&amp;limit=24` داشت — لینک از تلگرام/صفحهٔ HTML کپی شده و `&amp;` همراهش مانده → پارامتر limit بی‌اثر می‌شد.

## 🐛 باگ‌های واقعی که همین جلسه در کد پیدا و بسته شد (اپ + پنل)
- **پنل:** لینک ساب با `&amp;` → پارامترهای ports/limit/strict بی‌صدا نادیده گرفته می‌شدند → حالا پارسر خودش `&amp;` را نرمال می‌کند (هر کلاینتی، هر جای پیست‌شده)
- **پنل:** URL ساب‌های خارجی با `&amp;` هنگام ذخیره/فetch خراب می‌شد → پاک‌سازی در ذخیره + fetch
- **اپ:** پیست لینک از تلگرام در «افزودن اشتراک» → `&amp;` ذخیره می‌شد → حالا موقع ذخیره unescape می‌شود
- تست‌های رگرسیون: پارس `&amp;` • سانیتایز fetch ساب خارجی • نسخه

## ▶️ برای اینکه کانفیگ‌هات واقعاً کار کنند (به ترتیب، روی همان پنل جدید)
1. **اپ → SNI → اسکن** روی خط خودت → روی SNI سبز تپ → **«⚡ SNI اصلی پنل شود»** (پنل: edge-8rvlt را از «کدام پنل؟» انتخاب کن)
2. **اسکنر آیپی تمیز → اسکن → فقط سبزها → «ارسال به Cat Panel» با تیک 🧹 جایگزینی**
3. ساب را دوباره وارد کلاینت کن — اولین خط باید `sni=<SNI خودت>` داشته باشد نه skk.moe
4. چک نهایی: اپ → Cloud → کارت پنل → **«📊 وضعیت کامل»** — اگر SNI قرمز بود یعنی قدم ۱ انجام نشده
