# Cat Client v1.10.0-beta4

## پنل ۶.۷.۰ — چهرهٔ VPN-UI
- تم سرمه‌ای/سبزِ دقیق VPN-UI (توکن‌های واقعی از سورس vpn-ui: پس‌زمینه #0a1222، کارت #151f31، سبز #1bbf9f) + فونت وزیرمتن
- سایدبار چپ در دسکتاپ (Overview/Clients/Inbounds/Clean IP/Spoof/Settings/Backup/About/Log out)
- صفحهٔ **Overview**: اطلاعات پنل (موقعیت دیتاسنتر Cloudflare، آپتایم، نسخه، KV) + سرویس‌ها با چیپ RUNNING/IDLE + دکمهٔ Check for Update
- صفحهٔ **Inbounds**: ردیف هر پروتکل×پورت با بج و کپی لینک ساب همان ترکیب
- صفحهٔ **Clients** جدا شد + **Add Bulk** (ساخت دسته‌ای کاربر)
- ستون **آخرین آنلاین** کاربران — خودکار از اتصال تونل تشخیص داده می‌شود (بدون نیاز به تنظیم)

## اسکنر — تست سرعت دانلود (سبک XIU2)
- دکمهٔ «⬇ تست سرعت (۸ تای برتر)»: دانلود واقعی از هر IP با SNI سرعت‌سنج کلادفلر
- سرعت (MB/s) زیر هر IP + مرتب‌سازی خودکار بر اساس سرعت

## بقیه
- سازندهٔ NAT64 (پیشوندهای BPB: هلند/آمریکا) در کارت Static IP
- سازگاری مسیر «/pyip=» یونگ‌گیک در پنل (کنار «/proxyip=» خودی)
- منبع آپدیت پنل از ریلیز (بنر خودکار آپدیت داخل پنل) + میرورهای بیشتر دانلود
- قالب توکن API مثل BPB-Wizard + بازیابی پنل بعد از ۱۱۰۱ (بター)
