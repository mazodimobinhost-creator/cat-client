```

🎯 SNI: … (اگر پیش‌فرض skk.moe باشد ⚠️ هشدار قرمز می‌دهد)
💦 آی‌پی تمیز: N (📌 پورت‌پین: M)

⛓ خروجی ثابت: socks5://… یا —

🔄 چرخش: هر بروزرسانی
🔗 ساب: https://…/sub/<uuid>
```
رمز از UUID خود پنل پُر است؛ اگر عوضش کرده باشی یک‌بار می‌پرسد.
