# Cat Client 1.10.0-beta64 (versionCode 131) — پنل 6.44.0

## 📱 دور ۱۶ (ادامه) — سه مادهٔ باقی‌مانده از BPB

### ۱) تست زنجیره حالا IP و کشورِ خروجی را نشان می‌دهد
قبلاً دکمهٔ «🧪 تست زنجیره» فقط می‌گفت وصل شد/نشد. حالا یک رفت‌وبرگشت کامل از **داخل همان زنجیره** به ip-api می‌زند و جواب می‌دهد:

> 🟢 وصل شد · ۸۲۳ms · خروجی: 5.6.7.8 (Germany)

یعنی قبل از اعتماد، **عیناً می‌بینی** کانفیگ قولیت از کدام کشور بیرون می‌زند — همان چیزی که «خروجی ثابت» قولش را می‌دهد. اگر echo پاسخ نداد ولی handshake سالم بود، باز هم «وصل شد» می‌بینی (فقط بدون IP).

### ۲) کارت «کلاینت‌های پیشنهادی» در نمای درباره
مثل BPB: شش کلاینت با لینک رسمی دانلود — Cat Client (خودمان)، v2rayNG، Hiddify، FlClash، v2rayN، Streisand. برای وقتی دوستانت ساب پنل را می‌گیرند و نمی‌دانند با چه اپی بازش کنند.

### ۳) خروجی/بازگردانی تنظیمات با فایل
دو دکمهٔ جدید ته تنظیمات (همان ایدهٔ import/export خود BPB):
- **⬇️ خروجی تنظیمات**: همهٔ تنظیمات (عنوان، مسیرها، پورت‌ها، IPها، زنجیره، اسپوف، رول‌ها…) در یک فایل `cat-panel-settings.json`
- **⬆️ بازگردانی**: همان فایل را می‌دهی، روی تنظیمات فعلی merge می‌شود — برای جابه‌جایی بین ورکرها یا بکاپ قبل از تغییر بزرگ

**امنیت:** توکن ربات تلگرام و توکن گیت‌هاب **هرگز داخل فایل نمی‌روند** — در ورکر جدید هم می‌مانند (فایل حتی نسخهٔ ماسک‌شده را هم حذف می‌کند؛ سرور هم نسخهٔ ماسک‌شده را به‌هرحال دور می‌ریزد).

### تست‌ها
- ۲ تست جدید برای `chainProbe` (گرفتن IP/کشور از داخل زنجیره با سوکت تقلبی + شکست دیال) → مجموعه: **۱۳/۱۳ + e2e سبز**
- تست DOM: خروجی واقعاً لینک دانلود می‌سازد؛ بازگردانی با فایل واقعی merge و رندر می‌شود؛ کارت کلاینت‌ها ۶ لینک دارد
- سینتکس پنل خروجی (EMITTED) تأیید شد
