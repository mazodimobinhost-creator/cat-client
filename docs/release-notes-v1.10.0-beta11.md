# Cat Client v1.10.0-beta11

## 🐛 باگ ریشه‌ای که همه‌چیز را توضیح می‌دهد
مقایسه‌گر نسخهٔ اپ، نسخه‌های بتا (`1.10.0-beta10`) را اصلاً نمی‌فهمید — فقط عدد خالص قبول می‌کرد.
نتیجه: `isNewer` همیشه false بود و **اپ هیچ‌وقت آپدیت جدید را نشان نمی‌داد** («بروزرسانی داخل اپ نیومد»).
حالا مقایسهٔ بتا عددی است: beta10 > beta9 > … و نسخهٔ نهایی > بتا. با تست واحد پوشش داده شد.

## 🎫⛔ آپدیت پنل بدون توکن (beta10 + تثبیت)
- «بروزرسانی پنل» → **«کپی کد و باز کردن کلادفلر»**: کد جدید کپی + داشبورد باز؛ ۴ کلیک: Workers → Edit code → Ctrl+A/Ctrl+V → Deploy — **بدون هیچ توکنی**
- صادقانه: کلادفلر دیپلوی خودکارِ ۱۰۰٪-بدون-احراز-هویت را **اصولاً اجازه نمی‌دهد**. اگر یک‌بار توکن ذخیره کنی، از آن به بعد همهٔ آپدیت‌ها **یک‌کلیکی تمام‌خودکار** می‌شوند (توکن دوباره پرسیده نمی‌شود)
- داخل خود پنل (از ۶.۹.۲): دکمهٔ ⬇️ worker.js فایل جدید را از خود پنل می‌دهد (۳ منبع: گیت‌هاب → jsDelivr → raw؛ حتی با فیلتر)

## برای رسیدن به چرخهٔ سالم (یک‌بار)
۱. این beta11 را نصب کن → ۲. «پنل من» → «اتصال پنل موجود» → آدرس پنلت → ۳. «بروزرسانی پنل» → کپی/پیست (بدون توکن) → پنل ۶.۹.۲ → از این به بعد همه‌چیز روال است.
