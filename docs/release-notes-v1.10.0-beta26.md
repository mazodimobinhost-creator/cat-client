# Cat Client 1.10.0-beta26 (versionCode 93)

## پنل ۶.۱۹.۰ — WARP-in-WARP + ساب‌های خارجی + مخزن‌های کشوری

### 🌐 WARP روی خروجی Xray (کلیدهای خودت)
- حالت‌ها: **خاموش / WARP / WARP-در-WARP (زنجیره‌ای)** — دقیقاً مثل گزینهٔ Aether/PattNG
- کانفیگ‌های JSON پنل (`/xray/<uuid>?raw=1`) حالا می‌توانند کل اتصال را داخل تونل WARP خودت بپیچند: اتصال پنل → WARP داخلی → (در حالت زنجیره) WARP بیرونی → اینترنت
- **بدون هیچ ریسک بن:** ورکر هرگز با Cloudflare ثبت‌نام نمی‌کند؛ کلیدهای WireGuard را خودت از wgcf یا خروجی Aether می‌دهی. بدون کلید، فیچر کاملاً خاموش است
- `reserved` واقعاً پاک‌سازی می‌شود (۳ عدد ۰..۲۵۵)، endpoint پیش‌فرض `engage.cloudflareclient.com:2408`، MTU ۱۲۸۰
- با روشن‌بودن WARP، فرگمنت کنار گذاشته می‌شود (تونل UDP است)

### 🔀 ساب‌های خارجی (ترکیب با ساب خودت)
- تا ۵ ساب خارجی با نام دلخواه؛ محتوا **از دامنهٔ خود پنل** سرو می‌شود (`/ext/1/<uuid>`) — راه‌حل بسته‌بودن raw.githubusercontent.com در ایران
- کش ۱۲ ساعته در KV + سقف ۳۸۴KB + تایم‌اوت ۸ ثانیه + سقف ۱۰۰ خط URI
- اگر ساب خارجی «لیست URI» باشد بعد از کانفیگ‌های خودت به ساب اصلی اضافه می‌شود؛ `?noext=1` = بدون آن‌ها
- **پیش‌تنظیم یک‌ضربه‌ای Serverless-for-Iran (patterniha):** لینک `/ext` را می‌سازد تا مستقیم در PattNG/v2rayNG (هستهٔ Xray ≥2.2.6) ایمپورت کنی
- گیت امنیتی: `/ext` فقط با UUID مالک یا توکن کاربرِ ساب باز می‌شود
- کارت راهنمای **MITM + DomainFronting** (روش کلاینت‌ساید patterniha — روی خود دستگاه، بدون سرور)

### 🧬 کانفیگ‌ساز Aether (PattNG)
- ساخت لینک `aether://` برای **WARP تک‌لایه، WARP-in-WARP (Gool) و MASQUE/HTTP-2 با فرگمنت** + انتخاب خانوادهٔ IPv4/IPv6/هر دو + دکمهٔ باز کردن مستقیم در PattNG + QR

### 🛰️ مخزن‌های کشوری ProxyIP
- مخزن‌های پیش‌فرض حالا شامل **US، TR، FR، NL** (علاوه بر DE و GB) از وان‌وو
- چیپ‌های ۱۸ کشوری برای افزودن یک‌ضربه‌ای مخزن هر کشور (CA CH DE FI FR GB HK IN JP KR LV NL PL RU SE SG TW US)

### 🔒 بازبینی کرش/بن
- خروجی clash/singbox (هستهٔ اپ و Hiddify) هرگز wireguard ندارد → کرش اپ منتفی
- همهٔ ورودی‌های WARP/ساب خارجی سقف‌دار و پاک‌سازی‌شده؛ `/ext` مسیر عددی clamp شده؛ schemeهای غیرپروکسی فیلتر می‌شوند
- هیچ توکن CF API در هیچ‌جای این آپدیت نیست
