# نصب Worker ویدیویی تکناموز و جایگزین داخلی

این سند نتیجهٔ بررسی ویدیوی آموزشی و دو مسیری است که در Cat Client پیاده شد:
۱) نصب اختیاریِ همان Worker شخص ثالث با قفل نسخه، و ۲) کنترل‌های معادل در Cat Panel داخلی.

## چرا فایل `worker.js` فقط سه خط است؟

فایل منبع upstream (`technamooz/panel-technamooz-VPN-cloudflare`) واقعاً **سه خط فیزیکی** دارد،
اما حجمش **۴۰۶٬۲۸۵ بایت** است: دو خط اول کامنت (`// Build: …` و `// @ts-nocheck`) و خط سوم
حدود ۴۰۶ کیلوبایت کد bundle/minify‌شده. پس «سه خط» به معنی کوتاه یا ساده‌بودن سورس نیست؛
بلکه یعنی کل برنامه در یک خط فشرده شده است. خواندن انسانیِ آن عملاً بدون بازسازی (format)
و بازگردانی نام‌ها ممکن نیست، و ادعاهای امنیتی را نمی‌توان از روی شمار خط نتیجه گرفت.

## مسیر ۱ — نصب اختیاری Worker بیرونی (قفل‌شده)

- ورودی جدید در تب «ابر»: **TechNamooz Worker (video · third-party)**. نصب فقط با تأیید صریح انجام می‌شود.
- منبع فقط هنگام نصب از GitHub Contents API با `ref` یک commit مشخص گرفته می‌شود و در مخزن یا APK کپی نمی‌شود.
  - commit: `c88d2bfc0a0a123b9da791e8a3f5b398305e78a8`
  - SHA-256: `1c475c36a7cd720c23b5ec236eeb5548e14fbf90ee8f90d449ecb704ec1e7829`
  - اندازهٔ دقیق: ۴۰۶٬۲۸۵ بایت
- ترتیب نصب: ابتدا اندازه/هش/نشانه‌های مورد انتظار بررسی می‌شود؛ **هیچ درخواست نوشتنی به کلادفلر
  پیش از تأیید هش فرستاده نمی‌شود**. عدم تطابق یعنی توقف با پیام روشن و بدون تغییر در حساب.
- نصب‌کننده یک Worker و یک فضای KV (`<worker>-technamooz-kv`) می‌سازد و این bindingها را می‌دهد:
  `UUID` (تصادفی)، `TR_PASS` (رمزی که خودت می‌زنی یا پیشنهاد می‌شود)، `SUB_PATH` (مسیر خصوصی ساب)، `kv`.
- اگر Worker با این نام از قبل وجود داشته باشد، نصب متوقف می‌شود تا چیزی بازنویسی نشود.
- برنامه این مقادیر را **ذخیره نمی‌کند**؛ بعد از نصب باید UUID/رمز/مسیر و لینک ساب را خودت کپی و امن نگه داری.
- ادامهٔ تنظیمات (پروتکل، fingerprint، Proxy IP، Host/SNI، نوع سابسکریپشن) داخل `/panel` همان Worker انجام می‌شود.

### هشدارها (در خود برنامه هم نمایش داده می‌شود)

- این **کد شخص ثالث و اجرا روی حساب کلودفلر خودت** است.
- مخزن بالادستی **مجوز نرم‌افزاری اعلام نکرده** و سورس فشرده/مبهم‌سازی‌شده است؛ بررسی کامل و مستقل انجام نشده.
- بررسی ایستا فقط این ارجاع‌ها را پیدا کرد: `api.cloudflareclient.com` (ثبت WARP) و `ip-api.com` (بررسی IP/موقعیت).
- تطبیق هش فقط **همان نسخه** را تأیید می‌کند، **امنیت** آن را نه.
- هیچ تضمینی برای ضدبن، بازشدن سرویس‌های AI، حریم خصوصی، پایداری، هزینه یا رایگان‌ماندن داده نمی‌شود.
- برنامه اکانت کلادفلر نمی‌سازد و از رمز نمونهٔ منتشرشده در توضیحات ویدیو استفاده نمی‌کند.

## مسیر ۲ — همان کنترل‌ها در Cat Panel داخلی

Cat Panel داخلی نیازی به کد بیرونی ندارد و هم‌اکنون این‌ها را دارد:
VLESS/Trojan، اسکن IP تمیز، Proxy IP، Host/SNI، fingerprint،
و سابسکریپشن‌های معمولی / خام / Fragment / WARP / WARP Pro.
آی‌پی و Host نمونهٔ ویدیو عمداً از پیش تنظیم نشده‌اند، چون روی هر اپراتور ممکن است
قدیمی یا از کار افتاده باشند؛ فقط نتیجهٔ اسکن و تستِ خودت را اعمال کن.
