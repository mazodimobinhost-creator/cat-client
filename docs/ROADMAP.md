# Cat Client Roadmap

## Phase 1 — Foundation (Recommended start)
- Fork ArasClient or WhiteVPN
- Rename package + app name to `cat.client` / Cat Client
- Replace icon with black/white cat + purple lightning
- Apply black/white + deep purple color scheme
- Add language switch (fa / en)

## Phase 2 — UX Polish
- Connection globe animation
- Real country flag from exit IP
- Notification with live speed + server name + ping
- Custom accent color picker

## Phase 3 — Tools
- Clean IP Scanner with SNI/Spoof options
- Free configs tab (external healthy list)
- Subnet input for custom scanning

## Phase 4 — Advanced
- Cloudflare Token → one-click Worker panel deploy (optional)
- Smart routing profiles
- Split tunneling UI improvements

---

**Priority:** Always keep the core connection stable before adding fancy features.
