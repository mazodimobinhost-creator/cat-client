# Cat Client v1.9.35 — لینک سابت حالا صفحهٔ «Clean IP ✅» دارد 🌐

## چی تغییر کرد؟

قبلاً اگر لینک ساب خودت را در مرورگر باز می‌کردی، متن خام base64 می‌دیدی. حالا مثل سرویس‌های تجاری، یک صفحهٔ قشنگ باز می‌شود:

- **Clean IP ✅** — همهٔ آی‌پی‌های تست‌شده، **سریع‌ترین اول**، با پینگ (ms) + پرچم + کشور + SNI برندهٔ هر آی‌پی
- آمار ساب: چند کانفیگ فعال، چه پروتکل‌هایی، چه اپراتوری
- دکمه‌های **افزودن به اپ** (Cat Client / v2rayNG / V2Box / Hiddify / Streisand / v2rayTun / sing-box) + دکمهٔ کپی لینک + QR
- فرمت‌های دیگر: Clash · sing-box · JSON · متن خام

نکته: کلاینت‌ها (v2rayNG و بقیه) همچنان همان دیتای خام را می‌گیرند و هیچ چیزی به‌هم نمی‌ریزد — فقط مرورگر آدم‌ها صفحه می‌بیند. فرار دستی: `?raw=1` (متن خام) و `?web=1` (اجبار صفحه).

## مسیر استفاده

1. ورکر → «بروزرسانی پنل» به **۵.۲۲.۱**؛ اپ → `V1.9.35`.
2. لینک ساب خودت را در مرورگر/تلگرام باز کن — صفحه را می‌بینی.
