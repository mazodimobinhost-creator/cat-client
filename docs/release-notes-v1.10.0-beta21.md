# نسخه v1.10.0-beta21 — مخزن‌های ProxyIP + رفع باگ قدیمی PX — پنل 6.14.0

## ۱) مخزن‌های ProxyIP (تب 🎭 SNI و ProxyIP — کارت 🛰️ جدید)
دو مخزن زندهٔ واقعی پیدا و وصل شد:
- **xgonce/Cloudflare_IP** (⭐۲۳۰) — CSV با سرعت و کشور، آپدیت هر ۶ ساعت → مرتب‌شده بر اساس «سریع‌ترین اول»
- **wanwushequ/ProxyIP** (⭐۱۴) — لیست هر کشور جدا (DE/GB/US/TR/...)، ۳ بار در روز

مکانیزم همان مخزن آی‌پی تمیز: **بروزرسانی خودکار هر ۱۲ ساعت** (cron کلادفلر + باز شدن پنل + دکمهٔ دستی)، **جایگزینی خراب‌ها** بعد از ۳ گزارش (`POST /api/prepos {action:"health",dead:[…]}`)، چیپ کشورهای استخر با «+» برای افزودن ۸ عدد به لیست ProxyIP پنل، «افزودن خودکار ۶ ProxyIP تازه به ساب‌ها» (اختیاری، با `?norepo=1` خاموش)، و **مخزن دلخواه خودت** (txt / CSV / JSON خودکار تشخیص داده می‌شود).

## ۲) رفع یک باگ قدیمی و مهم
`!q.addr` برای آرایهٔ خالی در جاوااسکریپت همیشه false است — نتیجه: **کانفیگ‌های 🎯 PX و 🧬 SNI هرگز در سابِ واقعی ساخته نمی‌شدند** (فقط در تست‌های مستقیم کار می‌کرد). الان درست شد:
- ساب معمولی حالا کانفیگ‌های PX را دارد (مدرک زنده: ۶ عدد از ۳ ProxyIP پیش‌فرض)
- `?limit=` و `?addr=` مثل قبل تک‌خروجی می‌دهند (بدون PX)
- `?country=X&strict=1` هم بدون PX است — «فقط این کشور» یعنی فقط

## ۳) استحکام
- نوشتن رویدادها حالا داخل هندلرها await می‌شود (نوشتنِ معلق بین درخواست‌ها حذف شد)
- cron ورکر هر دو استخر (آی‌پی تمیز + ProxyIP) را با هم بروز می‌کند

## تست
۱۳ تست جدید ProxyIP-مخزن + تراز تست‌های limit (بخش PX از شمارش سقف جدا شد) — کل مجموعه (panel/wizard/multipart/dom/e2e) سبز. تست زنده: کارت مخزن رندر، `/api/prepos` بدون نت هم پاسخ سالم، PX در ساب، strict بدون PX.
