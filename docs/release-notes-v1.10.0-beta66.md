# Cat Client 1.10.0-beta66 (versionCode 133) — پنل 6.46.0

## ✨ دیزاین iOS × devigner — دکمه‌ها، موشن و حرکت

الگو از devigner.cc گرفته شد (دکمه‌های کپسولی، مارکی متحرک، ورودهای پله‌ای) و با مزهٔ iOS (فنر، شیشه، اسکوِرکل) ترکیب شد.

### پنل 6.46.0
- **دکمه‌ها کپسولی iOS شدند**: دکمهٔ اصلی گرادیان بنفش→فیروزه‌ای با هالهٔ نور؛ حالتِ فشردن = فنری کوچک می‌شود و با اورشوت برمی‌گردد؛ هاور = لیفت + هاله
- **منوی ☰ حالا اسلاید فنری** باز می‌شود (نه روشن/خاموش) — پس‌زمینه هم محو‌وشونده
- **مودال‌ها پاپ فنری** گرفتند؛ **توست‌ها از پایین با فنر** بالا می‌آیند
- **تعویض بخش‌ها**: هر نما با fade-up وارد می‌شود و کارت‌هایش پله‌ای (stagger)
- **نوار مارکی devigner** روی داشبورد: 🧦 Cat Panel ✦ خروجی ثابت ✦ IP تمیز ✦ … چرخش بی‌نهایت (در RTL هم جهت درست)
- برای کاربرانِ «motion کم» (prefers-reduced-motion) همهٔ انیمیشن‌ها خاموش
- دکمه‌های آیکنی (☰ کنار) فشردن اسکیلی گرفتند؛ فوکِس‌رینگ iOS روی کیبورد

### اپ (اندروید) — فقط بصری، بدون دست‌زدن به منطق
- کپسول داکِ انتخاب‌شده حالا **گرادیان اکسنت** است (قبلاً تک‌رنگ)
- **فشردن فنری iOS** (اسکیل ۰.۹۴ + برگشت اورشوت) روی: دکمهٔ بزرگ اتصال + دکمه‌های داک پایین
