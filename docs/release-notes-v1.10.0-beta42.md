# Cat Client 1.10.0-beta42 (versionCode 109) — پنل 6.25.0

## 🩺 چک دوطرفه + 🏷 برچسب منبع — همان که خواسته بودی

### «هم از سمت من چک شه هم از ورکر» — دو طرفِ ماجرا
- **از شبکهٔ تو** (اپ): اسکنر هر IP را با TLS واقعی روی خط خودت می‌سنجد — فقط سبزها جایی می‌روند
- **از سمت ورکر** (جدید — پنل → لیست آی‌پی‌ها → «🩺 تست از ورکر»): ورکر خودش به هر `ip:port` از کلادفلر تُنُل می‌زند → هر ردیف حالا نشان می‌دهد: `worker✓ 180ms 🇩🇪` یا `worker✗`
- IP که هر دو جا سبز بود = واقعاً سالم؛ فقط آن‌ وقت کانفیگ 💦 می‌گیرد

### «بگو این آی‌پی از کجا اومده و پینگش چقدره و کشورش»
- هر IP ارسالی از اسکنر حالا **منشأ + پینگ شبکهٔ فرستنده** همراهش می‌رود
- در لیست آی‌پی‌های پنل زیر هر IP: `🏷 از اسکنر · 📶 341ms` + پرچم کشور (از اسکنر یا تشخیص کشور ورکر)
- آی‌پی دستی: «ورود دستی» — آی‌پی مخزنی: از فید مخزن

### جواب سؤال «پروکسی ایپیا از کجان و سالم‌ان؟»
- مخزن‌های ProxyIP = xgonce/Cloudflare_IP + wanwushequ (عمومی، ۱۲ساعته) — **تضمین سلامت ندارند**؛ مرده‌ها بعد از ۳ گزارش از استخر می‌افتند
- استفاده از ProxyIP = فقط برای سایت‌های پشت کلودفلر (رله 🎯)؛ برای همهٔ ترافیک: socks5 خروجی ثابت (بتا۳۷) یا آی‌پی تمیز اسکن‌شده
