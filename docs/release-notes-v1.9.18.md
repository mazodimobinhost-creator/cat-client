# Cat Client v1.9.18 — ریشهٔ واقعی IP اشتباه پیدا شد: قوانین مسیریابی ساب

## ماجرا چه بود؟ 🩺

اسکرین‌شات شما نشان داد اپ برای IPv6 همان پیشوند اپراتور گوشی (`2a09:bac5…`) را نشان می‌دهد — یعنی پروب‌های اپ به‌جای تونل، از **مسیر مستقیم اپراتور** می‌رفتند. علت: وقتی حالت اشتراک فعّال است، **قوانین مسیریابیِ خود سابسکریپشن** تصمیم می‌گیرند کدام دامنه‌ها مستقیم و کدام از تونل بروند؛ دامنه‌های سنجش IP و پینگِ اپ هم قربانی آن قوانین شده بودند. برای همین اپ IP و پینگِ مسیر اشتباه را اندازه می‌گرفت (و V2Box درست نشان می‌داد چون تستش از مسیر خودِ نود بود).

## راه‌حل

- **قوانین اجباری اندازه‌گیری** — دامنه‌های سنجش اپ (ipify، icanhazip، ident.me، ip.sb، trace و تست تأخیر گوگل) حالا به‌عنوان **اولین قوانین** هستهٔ VPN تزریق می‌شوند و همیشه از **داخل تونل** می‌روند؛ هیچ قانونی از ساب نمی‌تواند آن‌ها را مستقیم کند.
- نتیجه: IP خروجیِ روی نقشه، IPv6 و **دکمهٔ پینگ** همه دقیقاً همان مسیری را اندازه می‌گیرند که مرورگر و V2Box می‌بینند.
- خط «IP واقعی» همچنان از شبکهٔ فیزیکی (اپراتور) گرفته می‌شود — جدا از خروجی.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.18` آپدیت کن.
2. وصل شو → «تست پینگ» (باید عددی نزدیک V2Box بدهد) → «بروزرسانی IP» → مقایسه با whatismyipaddress.
