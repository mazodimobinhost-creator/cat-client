# Cat Client v1.1.0 — یادداشت انتشار

نسخهٔ **1.1.0** (versionCode 2) — پنل شخصی + رنگ‌بندی بنفش/مشکی/سفید + تب اسکنر.

## 📱 اپلیکیشن

**ساختار جدید (۵ تب پایین صفحه)**

| تب | کار |
| --- | --- |
| تنظیمات | همان تنظیمات پیشرفته (تونل، DNS، زنجیره، Amnezia، LAN …) |
| VPN | صفحهٔ خانه: دکمهٔ اتصال، آمار زنده، انتخاب سرور/موقعیت |
| سابسکریپشن | سابسکریپشن‌های تو + نمایش مصرف (از هدر `subscription-userinfo` پنل) |
| **اسکنر IP** | اسکنر جدید آی‌پی تمیز کلودفلر با SNI قابل‌تنظیم و رنج دلخواه |
| **پنل من** | دیپلوی پنل Cat Panel روی حساب کلودفلر خودت + لینک به اسکنر |

**رنگ و ظاهر**

- پالت کامل **بنفش / مشکی / سفید**: تم روشن = سفید خالص با بنفش کات، تم تاریک = مشکی OLED با گرادیان بنفش/سرخابی.
- آیکون لانچر، آیکون اعلان، بنر اندروید TV و لوگو از نو ساخته شده‌اند (گربهٔ سفید + آذرخش بنفش روی شب بنفش). اثر «WhiteDNS» کاملاً پاک شد.
- لوگوی نوار کنار، آیکون تب‌ها و حالت‌های تاکیدی همه با پالت جدید هماهنگ شده‌اند.

**اسکنر آی‌پی تمیز (تب جدید)**

1. SNI را برابر دامنهٔ پنل خودت بگذار (مثلاً `mypanel.workers.dev`).
2. رنج‌های داخلی کلودفلر/Gcore/Fastly یا رنج دلخواه خودت را اسکن کن.
3. هر ردیف تأخیر TLS را نشان می‌دهد؛ با «انتخاب» همان آی‌پی به‌عنوان **آی‌پی فرانتینگ** ثبت می‌شود (SNI و Host همان دامنهٔ پنل می‌ماند) و اتصال زنده دوباره برقرار می‌شود.

**دیپ‌لینک‌ها**

- `catclient://add-sub?url=…&name=…` — افزودن ساب از پنل.
- `catclient://scan?sni=<host>&ip=<ip,ip>` — باز کردن اسکنر اپ و اعمال آی‌پی‌های تمیز از داخل پنل.

**مصرف سابسکریپشن** — اگر پنل هدر `subscription-userinfo` بفرستد (Cat Panel می‌فرستد)، در کارت سابسکریپشن «مصرف X از Y (٪Z) · N روز باقی‌مانده» نمایش داده می‌شود.

## 🐱 Cat Panel v3.0.0 («شب بنفش»)

یک فایل، روی هر Worker کلودفلر (یا با یک توکن API از داخل خود اپ).

**لینک سابسکریپشن برای همهٔ کلاینت‌ها**

| مسیر | برای |
| --- | --- |
| `/sub` | لینک‌های معمولی VLESS/Trojan/WARP + واریانت هر آی‌پی تمیز |
| `/sub64` | همان، Base64 (کلاینت‌های v2rayNG-محور) |
| `/clash` | YAML مای‌هومو/کلش متا + DNS + قواعد ایران‌مستقیم |
| `/singbox` | JSON سینگ‌باکس/هیدیفای |
| `/all` | همه‌چیز در یک JSON |

**قابلیت‌ها**

- **QR آفلاین**: `/qr.svg?d=…` — انکودر QR داخل خود Worker پیاده شده؛ نه CDN لازم است نه سرویس بیرونی (برای ایران مهم است).
- **اسکنر آی‌پی تمیز داخل پنل**: تست تأخیر از مرورگر خودت (شبکهٔ اپراتور خودت) به‌علاوهٔ پروب سمت سرور `/api/ping`.
- **DNS رمزنگاری‌شده (DoH)**: `/dns-query` با استاندارد RFC 8484 (GET و POST)، جدول تأخیر زندهٔ رزولورها و راهنمای استفاده در اپ/مرورگر/مای‌هومو.
- **سفیدلیست SNI** (SNI ناشناس → 403)، **آی‌پی‌های تمیز کلودفلر**، حالت `REMOTE` برای تونل کامل TCP، `PANEL_PASSWORD`، لینک `warp://`.
- **رابط دو‌زبانهٔ فارسی/انگلیسی** با تم تاریک و روشن، نوار تب چسبان، FAQ و جدول متغیرها.
- **API**: `/api/config.json`، `/api/scan-targets.json`، `/api/ping`، `/api/dns-probe`، `/health`.

**پیش‌نمایش محلی**

```bash
node scripts/panels/preview-server.mjs 8787   # http://localhost:8787
node scripts/panels/cat-panel.test.mjs        # ۴۴ تست
node scripts/panels/panel-dom.test.mjs        # تست رابط در jsdom (نیاز به jsdom)
```

## 🔐 توکن کلودفلر برای دیپلوی

Cloud → **پنل من** → توکن API با قالب **Edit Cloudflare Workers** → Deploy.
اپ خودش Worker را آپلود می‌کند، `/health` را تست می‌کند و بعد لینک ساب را اضافه می‌کند.
