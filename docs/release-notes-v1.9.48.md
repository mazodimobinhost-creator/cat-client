# Cat Client v1.9.48 — لینک نصب یک‌کلیکی، برای همه 🔗

## چرا؟
دیروز دکمهٔ رسمی «Deploy to Cloudflare» به مخزن اضافه شد — هر کسی بدون اپ و بدون توکن، فقط با یک کلیک، پنل شخصی خودش را روی اکانت کلادفلرش نصب می‌کرد. اما آن لینک فقط داخل گیت‌هاب (README) بود؛ کاربرِ اپ که می‌خواست آن را برای دوستش بفرست، باید لینک مخزن را دستی پیدا می‌کرد.

## حالا
- **دکمهٔ «اشتراک لینک نصب یک‌کلیکی»** داخل تب «پنل من» (کارت Cat Panel): لینک در کلیپ‌بورد کپی می‌شود و صفحهٔ اشتراک سیستم باز می‌شود — برای هر کسی بفرست؛ گیرنده فقط یک اکانت رایگان کلادفلر لازم دارد، نه اپ را، نه توکن.
- **کنسول نصب تمیز شد:** دو کلید تکراری در خروجی ورکر (`allowedSnis` و `SCAN_RANGES`) حذف شد — قبلاً `wrangler deploy` موقع نصبِ یک‌کلیکی دو هشدار زرد چاپ می‌کرد؛ حالا نصب بی‌هشدار و حرفه‌ای است.
- **تست رگرسیون جدید:** سوئیت تست پنل حالا خودش کلید تکراری را پیدا می‌کند تا دیگر برنگردد.
- `npm install` سبک‌تر (jsdom فقط برای تست‌ها نصب می‌شود).

## مسیر استفاده
- **بدون اپ (جدید):** لینک را از دوستت بگیر → باز کن → وارد اکانت کلادفلر شو → نصب.
- **داخل اپ:** تب «پنل من» → «🔗 اشتراک لینک نصب یک‌کلیکی» → بفرست.
- پنل‌های موجود: «بروزرسانی پنل» → **۵.۲۳.۱۱** (بدون تغییر رفتار؛ فقط پاک‌سازی خروجی ورکر).
