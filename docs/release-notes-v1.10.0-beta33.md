# Cat Client 1.10.0-beta33 (versionCode 100)

## چک → بعد پنل → بعد کانفیگ (دقیقاً همان ترتیبی که خواستی)

### 🔒 قانون جدید: فقط آی‌پی «تاییدشده روی شبکهٔ خودت» وارد پنل می‌شود
- «ارسال به Cat Panel» دیگر هیچ آی‌پی چک‌نشده‌ای را نمی‌فرستد — **فقط سبزها (TLS-OK)**، یعنی آن‌هایی که همین الان روی خط تو هندشیک TLS کامل کرده‌اند
- اگر هیچ آی‌پی تاییدشده‌ای نباشد: ارسال **رد می‌شود** با پیام «هیچ آی‌پی تأییدشده‌ای نیست — اسکن را تکرار کن» (قبلاً آی‌پی چک‌نشده هم می‌رفت → کانفیگ مرده ← همان چیزی که شکایت بود)
- قبلاً اگر هیچ سبزی نبود، «fallback به همه» می‌شد — **حذف شد**

### 🔁 جریان کامل (چک → پنل → کانفیگ):
1. اپ → **اسکنر آی‌پی تمیز** → اسکن روی شبکهٔ خودت (کاندیدها از رنج‌های کلادفلر)
2. هر آی‌پی: TCP connect → **TLS با SNI پنل** → فقط پاس‌ها ✅
3. **ارسال به Cat Panel** → رمز خودکار پُر (UUID) → آی‌پی‌های سبز با `ip:port#کشور` وارد پنل
4. پنل: پین روی پورت تاییدشده + کانفیگ 💦 VLESS/TROJAN + پرچم کشور
5. ساب را در کلاینت رفرش کن — کانفیگ‌ها روی آی‌پی‌های تاییدشدهٔ خط خودت

### یادآوری beta32 (همچنان فعال): رمز پنل در دیالوگ ارسال خودکار پُر می‌شود؛ آی‌پی‌ها همیشه در کلیپ‌بورد هم می‌روند (پنل → جعبه‌ابزار → «وارد کردن نتیجهٔ اسکن»)

### مخزن‌های عمومی (🎯/💦 آی‌پی‌های عمومی) — صادقانه:
آی‌پی‌های مخزنی ساعت‌ها کهنه می‌شوند و روی هر اپراتوری جواب نمی‌دهند؛ برای خط تو، فقط خروجی اسکنر تضمین دارد.
