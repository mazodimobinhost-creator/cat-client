# 🤖 دیپلوی خودکار پنل با ربات تلگرام

از این به بعد آپدیت پنل = یک پیام تلگرام: `/deploy` می‌زنی، گیت‌هاب ورکر را روی کلادفلر دیپلوی می‌کند و همان‌جا نتیجه را می‌فرستد. ✅

```
شما (تلگرام): /deploy
   ↓
پنل (ورکر کلادفلر): دستور به GitHub Actions
   ↓
GitHub Actions: wrangler deploy ← ورکر جدید روی کلادفلر
   ↓
تلگرام: «🐱 Cat Panel 6.22.0 ✅ deployed»
```

**نکتهٔ امنیتی مهم:** توکن کلادفلر **هیچ‌وقت** وارد پنل/تلگرام/KV نمی‌شود. فقط یک‌بار به‌عنوان GitHub Secret ذخیره می‌شود و گیت‌هاب خودش موقع دیپلوی استفاده‌اش می‌کند. پنل فقط یک توکن گیت‌هاب محدود (فقط همین ریپو، فقط Actions) می‌خواهد تا دستور دیپلوی بدهد.

---

## قدم ۱ — ربات تلگرام (۳ دقیقه)
1. در تلگرام به **@BotFather** پیام بده → `/newbot` → اسم و یوزرنیم بده → توکن را کپی کن (شکل `123456:ABC-…`)
2. به **@userinfobot** پیام بده → آیدی عددی‌ات را کپی کن (مثلاً `123456789`)

## قدم ۲ — وصل‌کردن ربات به پنل
1. پنل → **تنظیمات** → بخش «ربات تلگرام»: توکن + آیدی عددی → **ذخیره**
2. دکمهٔ **🤖 اتصال ربات (Webhook)** را بزن → «🟢» شود
3. در تلگرام `/help` بفرست — باید لیست دستورها بیاید

## قدم ۳ — GitHub Secrets (یک‌بار برای همیشه)
در گیت‌هاب: **Settings → Secrets and variables → Actions → New repository secret** — این ۴ تا را بساز:

| نام | مقدار | از کجا |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | توکن با دسترسی **Workers Scripts: Edit** | کلادفلر → My Profile → API Tokens → Create Token → قالب «Edit Cloudflare Workers» |
| `CLOUDFLARE_ACCOUNT_ID` | آیدی اکانت | کلادفلر → داشبورد → Overview → سمت راست صفحه |
| `TELEGRAM_BOT_TOKEN` | همان توکن قدم ۱ | BotFather |
| `TELEGRAM_CHAT_ID` | همان آیدی عددی قدم ۱ | @userinfobot |

## قدم ۴ — توکن گیت‌هاب برای پنل
1. گیت‌هاب → Settings → Developer settings → **Fine-grained tokens** → Generate new token
2. **Repository access:** فقط `mazodimobinhost-creator/cat-client`
3. **Permissions → Actions:** *Read and write*
4. توکن (`github_pat_…`) را بردار
5. پنل → تنظیمات → بخش «🚀 دیپلوی خودکار»: مخزن `mazodimobinhost-creator/cat-client` + برنچ (مثلاً `main` یا `arena/01a0ebed-cat-client`) + توکن → **ذخیره**

## قدم ۵ — دیپلوی! 🚀
در تلگرام به رباتت:
- **`/deploy`** — دیپلوی برنچ پیش‌فرض
- **`/deploy arena/01a0ebed-cat-client`** — دیپلوی از یک برنچ خاص
- **`/deploys`** — وضعیت ۳ دیپلوی آخر
- نتیجه بعد از ~۱ تا ۲ دقیقه به‌صورت پیام می‌آید

ضمناً هر بار که کد ورکر روی گیت‌هاب push شود، **خودکار** هم دیپلوی می‌شود (بدون نیاز به پیام).

---

## عیب‌یابی
| پیام | معنی | راه‌حل |
|---|---|---|
| `⚠️ Deploy bot is not configured` | مخزن/توکن در پنل خالی است | قدم ۴ |
| `🔴 401` | توکن گیت‌هاب نامعتبر | توکن تازه بساز، در پنل ذخیره کن |
| `🔴 404` | فایل ورک‌فلو روی آن برنچ نیست | برنچ را چک کن (`deploy-worker.yml` باید باشد) |
| پیامی نمی‌آید | Secrets ناقص | هر ۴ secret را چک کن |
| `⏳` طول کشید | — | تب Actions در گیت‌هاب را ببین |

## سؤالات رایج
- **مگه نباید توکن کلادفلر بدهم به پنل؟** خیر — طبق قانون همیشگی، پنل هرگز توکن کلادفلر نمی‌پذیرد. دیپلوی را گیت‌هاب انجام می‌دهد که توکن در Secrets خودش است.
- **ورک‌فلو کجاست؟** `.github/workflows/deploy-worker.yml` — با push کد ورکر، دستی، یا دستور تلگرام اجرا می‌شود.
- **اگر Secrets را نگذارم چه می‌شود؟** ورک‌فلو سبز رد می‌شود با پیام «Deploy skipped» — چیزی خراب نمی‌شود.
- **هزینه؟** گیت‌هاب Actions برای ریپوی خصوصی ۲۰۰۰ دقیقه/ماه رایگان دارد؛ هر دیپلوی ~۳۰ ثانیه است.
