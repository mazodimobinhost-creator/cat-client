# Cat Client 1.10.0-beta38 (versionCode 105)

## اسکنر ProxyIP هم دیگر پنل را حدس نمی‌زند 🎯

### 🐛 حفرهٔ باقی‌مانده از beta36 — بسته شد
در صفحهٔ اسکنر ProxyIP، دکمه‌های «⚡ ذخیرهٔ مستقیم» و «ارسال به پنل» هنوز پنل را **خودکار حدس** می‌زدند. الان اول دیالوگ **«کدام پنل؟»** باز می‌شود (همان که خودت انتخاب می‌کنی) و رمز پنل انتخابی هم از قبل با UUID همان پنل پُر است. هر سه مسیر ارسال به پنل (آی‌پی تمیز، SNI، ProxyIP) حالا از یک انتخاب‌گر صریح می‌روند.

### 🗺 نقشهٔ کامل «ProxyIP از اسکنر تا ساب» (مرجع)
| در اپ می‌بینی | چه می‌شود |
|---|---|
| ردیف `☑ 🇩🇪 104.17.x.x — DE · edge FRA · 320ms` | TLS با SNI پنل دست داده = قابل اطمینان |
| دکمهٔ «استفاده» روی ردیف | فقط اپ: همان IP آدرس ورود می‌شود (fronting) |
| «⚡ ذخیرهٔ مستقیم» | API: ادغام با لیست 🎭 پنل → کانفیگ‌های 🎯 |
| «ارسال به پنل» | مرورگر: `پنل/?proxyips=…` → فیلد 🎭 پُر → Save |
| «کپی» | کلیپ‌بورد، هر خط `host[:port]` |

در ساب: هر ProxyIP یک کانفیگ 🎯 مستقل (`path = /vl/<uuid>?ed=2560?proxyip=<IP>`) — ورود همان دامنهٔ پنل، خروجِ سایت‌های کلودفلری از آن رله.
