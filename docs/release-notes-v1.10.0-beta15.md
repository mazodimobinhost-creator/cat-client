# Cat Client v1.10.0-beta15

## پنل ۶.۱۰.۱ — کانفیگ امضایی BPB روی :8080 حالا تولید می‌شود 💦
- قبلاً ترتیب پورت‌ها 443→80→… بود و سقف تعداد کانفیگ پیش از رسیدن به ۸۰۸۰ پر می‌شد؛ یعنی کانفیگ `Clean IP : 8080` (همان که در نمونهٔ BPB دیدی) هرگز ساخته نمی‌شد
- حالا ترتیب عین BPB است: **443 اول، بعد ۸۰۸۰** — و ساب پیش‌فرض شامل:
  `💦 n. VLESS - Clean IP : 8080` روی `www.speedtest.net` با `security=none` (مثل نمونهٔ خودت، بایت‌به‌بایت)

## دربارهٔ «رمزنگاری» آن JSON
آن JSON رمزنگاری‌شده نیست — خروجی «Edit» خود v2rayNG است: بالایش (address/port/path/uuid) از لینک کانفیگ می‌آید و بقیه‌اش (FakeDNS، DNS، routing، policy) **تنظیمات خود v2rayNG** است که BPB هم از کلاینت می‌گیرد. کانفیگ‌های `:8080` اصلاً TLS ندارند (`security: none` — همان که در نمونه‌ات دیدی)؛ محافظت لایهٔ پروتکل (VLESS/Trojan) است.
