# Cat Client v1.9.25 — استخر ۲۵ SNI جهانی (همهٔ کشورها)

## چه چیزی اضافه شد

- **استخر چرخش SNI** 🌐 — ۲۵ دامنهٔ متنوع از خیلی کشورها و سرویس‌ها (cloudflare، time.is، doi.org، discord، gitlab، openai، chatgpt، signal، jsDelivr، ecosia، udemy، okx، coinbase، kraken، digitalocean، w3.org، iana و…) که **تک‌تک‌شان از نظر DNS تایید شد که واقعاً پشت کلادفلرند** — چون SNI غیرکلادفلری کانفیگ را بی‌صدا می‌کُشد.
- **اسکنر هوشمندتر** 🛰️ — اگر SNI انتخاب نکنی، هر اسکن به‌طور خودکار ۳ SNI تصادفی از استخر را روی هر IP هم تست می‌کند و برندهٔ هر IP (کم‌ترین پینگ) ذخیره می‌شود؛ با چند اسکن، هر IP بهترین SNI خودش را پیدا می‌کند.
- **چرخش خودکار در کانفیگ‌ها** ♻️ — اگر برای IP برندهٔ اندازه‌گیری‌شده نداشته باشیم، کانفیگ‌ها از کل استخر می‌چرخند؛ اگر یک ISP یکی را کند کرده، بقیه در همان ساب هست. اگر صریحاً SNI ست کرده باشی، همان قبلی حفظ می‌شود.
- **گیت SNI** هم استخر را قبول می‌کند — کانفیگ‌هایی که با IP تمیز و SNI استخر وصل می‌شوند دیگر 403 نمی‌خورند.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.25` آپدیت کن؛ ورکر را با «بروزرسانی پنل» به **۵.۱۸.۰** برسان (حالا از پشت فیلتر هم کار می‌کند).
2. کافیست ساب را رفرش کنی — کانفیگ‌های TLS با SNIهای متنوع می‌آیند. برای بهترین نتیجه یک اسکن «از مرورگر» بزن تا برندهٔ هر IP ثبت شود.
