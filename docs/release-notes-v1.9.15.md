# Cat Client v1.9.15 — دو دکمهٔ جدید زیر دکمهٔ اتصال: تست پینگ و بروزرسانی IP

## چه چیزی جدید است

- **دکمهٔ «تست پینگ»** ⏱ — دقیقاً مثل v2rayNG و V2Box: وصل که شدی روی دکمه بزن تا پینگ واقعی از داخل **همان کانفیگ متصل** (۳ نمونه، بهترین) نمایش داده شود. اگر وصل نباشی پیام می‌دهد که اول وصل شو.
- **دکمهٔ «بروزرسانی IP»** 🔄 — هر لحظه که خواستی با سایت‌های My IP مقایسه کنی، این دکمه IPهای هر دو خانواده (IPv4 و IPv6) را دوباره و اجباری می‌گیرد تا نمایش اپ هیچ‌وقت کهنه نباشد.
- منابع دریافت IP با دو سرویس پایدار دیگر (ident.me) بیشتر شد تا همیشه جواب بگیرد.
- یادآوری: وقتی وصل هستی، IP و کشورِ نمایش‌داده‌شده «خروجی تونل» است — همان چیزی که سایت‌ها موقع اتصال نشان می‌دهند؛ سطر «IP واقعی» هم اینترنت خام توست. با «بروزرسانی IP» هر دو لحظه‌ای تازه می‌شوند.

## مسیر استفاده

1. اپ را به `CatClient-V1.9.15` آپدیت کن.
2. وصل شو → «تست پینگ» برای پینگ همان کانفیگ؛ «بروزرسانی IP» برای مقایسه با whatismyipaddress.
