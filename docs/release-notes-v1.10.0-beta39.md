# Cat Client 1.10.0-beta39 (versionCode 106)

## سه‌تایی که خواستی — همه بسته شد 🔒

### ۱) «۲۰۰ تا ایپی قدیمی رو پاک کنم و جدید بذارم» — دکمه جایگزینی
- **در خود پنل** از قبل هست (تب «آی‌پی‌ها»): «🧹 پاک کردن همه» + «جایگزینی کل لیست» (بچسبان و جایگزین کن) + ✕ روی هر آی‌پی
- **حالا در اپ هم**: دکمهٔ «ارسال به Cat Panel» اسکنر آیپی تمیز، تیک **«🧹 جایگزینی کل لیست پنل (به‌جای افزودن)»** دارد → لیست پنل دقیقاً فقط سبزهای انتخابی می‌شود (ip.sb و آشغال‌های قدیمی یک‌جا پاک می‌شوند)

### ۲) پورتِ ProxyIP: «عوض نشه اصلا»
- اسکنر ProxyIP حالا **چیپ پورت** دارد: ۴۴۳ / ۲۰۵۳ / ۲۰۸۳ / ۲۰۸۷ / ۲۰۹۶ / ۸۴۴۳ — چندتایی
- نتیجه همیشه **با همان پورتی که جواب داد** ذخیره می‌شود: `104.17.x.x:2053` — دیگر هیچ‌وقت پورت نمی‌افتد (تا الان ۴۴۳ حذف می‌شد!)
- پنل سمت سرور هم `ip:port` را دقیقاً همان‌طور نگه می‌دارد (تست رگرسیون جدید) و کانفیگ 🎯 روی همان پورت رله می‌شود

### ۳) استفاده از آیپی تمیز و SNI مثل پنل قرمز/سفید
- SNI سبز اسکن‌شده حالا ۵ اکشن دارد: استفاده در کانفیگ‌ها / اسکنر / کپی / **افزودن به پنل** / **⚡ SNI اصلی پنل شود**
- «SNI اصلی پنل» = یک تپ، `sni` کل پنل عوض می‌شود → همهٔ 💦 و 🎯 و 🏠 با SNI تو ساخته می‌شوند — **پایانِ پیش‌فرض skk.moe**
