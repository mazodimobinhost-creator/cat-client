# Cat Client 1.10.0-beta44 (versionCode 111)

## 🎯 ریشهٔ واقعی «یسریا کانفیگ‌ها پینگ نمی‌دهند» — با سند

ساب زندهٔ خودت را باز کردم: ۱۱ تا از آی‌پی‌هایی که اسکنرت داده بود (96.44.184.33، 64.181.255.215، 107.175.194.31، 147.182.242.22، 47.77.210.148، 23.254.248.161، 192.9.157.76، 38.65.9.66، 117.55.231.178، 163.192.47.170، 104.168.87.130) **اصلاً کلادفلر نیستند** — VPS خام‌اند (DO/OVH/Choopa). کانفیگ 💦 یعنی «وصل شو و TLS با SNI پنل بزن»؛ سرور غیر-CF گواهی کلادفلر ندارد → handshake هرگز کامل نمی‌شود → بی‌پینگ. ۵ تای CF‌ـیِ واقعی (104.17.148.22، 104.16.132.229، 188.114.96.1، 162.159.192.1، 172.67.181.32) همان‌هایی بودند که کار می‌کردند.

### 🩹 منبع آلودگی بسته شد
کتابخانهٔ «آی‌پی‌های کامیونیتی» اپ (از لیست‌های عمومی 2026-09) ۱۲۵۸ IP داشت که **۱۸۳تایش خارج رنج CF بود** — همان رله‌های ProxyIP-مانند که اشتباهی کاندیدِ «آی‌پی تمیز» شده بودند. الان ورودی‌ها قبل از ورود به لیست اسکن **فیلتر رنج CF** می‌شوند (IPv4 با جدول رنج رسمی، IPv6 با پیشوند). دیگر IP غیر-CF داخل اسکنر تمیز نمی‌آید که بفرستی پنل و کانفیگ مرده بسازد.

### برای سابت (به‌ترتیب، ۳ دقیقه):
1. اپ → اسکنر آیپی تمیز → اسکن (الان دیگر همهٔ نتایج CF هستند) → فقط سبزها → ارسال با 🧹 جایگزینی
2. لیست پنل → «🩺 تست از ورکر» → worker✗ها را با ✕ حذف کن
3. یادت نرود: SNI هنوز skk.moe است — اسکنر SNI → ⚡ SNI اصلی پنل، وگرنه روی خیلی از خطوط همه می‌میرند
4. ساب را رفرش کن — آی‌پی‌های باقی‌مانده همگی CF-رنج + دوطرفه تأییدشده
