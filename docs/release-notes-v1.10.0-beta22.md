# نسخه v1.10.0-beta22 — کانفیگ‌های جداگانهٔ ProxyIP با اسم کشور — پنل 6.15.0

## کانفیگ‌های جدا برای هر ProxyIP (مثل BPB Normal)
حالا هر ProxyIP یک **کانفیگ جداگانهٔ 🎯** در ساب می‌گیرد — با شماره، پرچم و نام کشور، همان سبکی که در عکس‌ها بود:

```
🎯 1. 🇩🇪 آلمان · 172.67.181.122     (VLESS + TROJAN، مسیر ?proxyip=…)
🎯 2. 🇫🇷 فرانسه · 51.15.10.5
🎯 3. proxyip.cmliussss.net
```

- خروج از هر کانفیگ از طریق همان ProxyIP رله می‌شود (`?proxyip=` روی مسیر WS) — برای باز کردن سایت‌های پشت کلادفلر که روی آی‌پی خام ملتزم‌اند
- نام‌ها بسته به زبان پنل: فارسی («آلمان») یا انگلیسی («Germany»)
- در همهٔ خروجی‌ها: URI/Base64/Clash/sing-box/Xray
- **مخزن ProxyIP حالا پیش‌فرض روشن است** — ۶ ProxyIP تازهٔ استخر خودکار به ساب‌ها اضافه و برای هرکدام کانفیگ جدا ساخته می‌شود (خاموش‌کردن در تب 🎭 یا `?norepo=1` در لینک)
- فیدهای wanwushequ (فایل هر کشور) حالا تگ کشور پیش‌فرض می‌گیرند → پرچم روی کانفیگ‌ها
- نام‌گذاری آی‌پی‌های تمیز همان BPB قبلی می‌ماند (💦 n. VLESS - Clean IP : 443) — دست نخورد
