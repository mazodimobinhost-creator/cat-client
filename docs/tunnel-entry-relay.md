# تانل‌کردنِ IP ایران و IP خارجیِ کلودفلر — بخشِ تانل در اپ

پاسخِ کوتاه: **بله می‌شود** — و از این نسخه بخشش هم در اپ هست. دو سؤالِ طرح هم
جواب گرفت: سطح = **اپ**، و رفتارِ پیش‌فرض = **زنجیره دست‌نخورده بماند و IP وارد
تونل شود**.

---

## ۰) تصمیم‌هایی که گرفته شد (و چرا)

| سؤال | جوابِ تو | نتیجه در کد |
| --- | --- | --- |
| بخش کجا باشد؟ | **اپ** | صفحهٔ «زنجیرهٔ اتصال» (تنظیمات) + اسکنرِ ProxyIP؛ بدونِ وابستگی به پنل |
| با IP اسکن‌شده چه کنیم؟ | **زنجیره بماند، IP وارد تونل شود** | IP به‌عنوان **آدرسِ اولین پاِ** زنجیره pin می‌شود؛ خودِ زنجیره و انتخاب‌هایش دست‌نخورده می‌مانند |

---

## ۱) چه چیزی در همین نسخه ساخته شد

**الف) جایِ IP در زنجیره: «آدرسِ مسیر».** یک هُپ در این اپ = یک **کانفیگ**
(UUID، SNI، ترنسپورت). IP خالی نمی‌تواند هُپ باشد، ولی **آدرسی که کانفیگ از آن
دیال می‌شود** می‌تواند عوض شود. حالا هر هُپ یک فیلد دارد:

```kotlin
data class ConnectionChainHop(
    val mode: ConnectionChainHopMode,
    val profileRef: ConnectionChainProfileRef? = null,
    val serverOverride: String? = null,   // ip یا ip:port — همان‌جایی که IP وارد تونل می‌شود
)
```

**ب) pin فقط روی پای بیرونی.** در ساختِ YAML فقط `proxyIndex == 0` (اولین
پروکسیِ آن هُپ) آدرسش عوض می‌شود — چون فقط همان پا از بیرونِ هُپ دیال می‌شود:
دستگاه → اولین پروکسیِ هُپ ۱، و اولین پروکسیِ هر هُپ بعدی از طریقِ هُپِ قبلی.
اگر بقیهٔ پروکسی‌ها هم پچ می‌شدند، آدرسی که یک کانفیگ برای رسیدن به بالادستش لازم
دارد از بین می‌رفت.

**ج) اسلاتِ ورودی (Before) زنده شد.** تا قبل از این، `save()` عمداً `before = off`
می‌کرد و `read()` آن را نمی‌خواند؛ یعنی «ورودی» هرگز نمی‌توانست وجود داشته باشد.
حالا هر سه اسلات (ورودی/پایه/بعد) ذخیره و خوانده می‌شوند و در صفحه هم ردیفِ ورودی
دیده و قابلِ انتخاب است.

**د) دکمهٔ «استفاده به‌عنوان entry» در اسکنرِ ProxyIP:** اگر زنجیره فعال باشد، IP
روی **اولین مسیرِ پیکربندی‌شدهٔ زنجیره** pin می‌شود (defaultی که خودت انتخاب کردی:
زنجیره حفظ شود، IP وارد تونل شود) و توست می‌گوید کدام مسیر. اگر زنجیره خاموش
باشد، رفتارِ قبلی (fronting) عوض نشده است.

**ه) UI:** هر ردیفِ مسیر یک چیپِ «IP مسیر» دارد (۴۴px، RTL): با زدنش IP وارد
می‌شود (یا از مسیرهای fronting فعلی)، با دکمهٔ «پاک‌کردن» برمی‌گردد به آدرسِ خودِ
کانفیگ. IP نامعتبر همان‌جا رد می‌شود (`IP` یا `IP:port`، IPv6 با براکت) و IP
خرابِ ذخیره‌شده هنگام normalize حذف می‌شود تا اتصال را نشکند.

**و) تست:** `scripts/panels/chain-tunnel.test.mjs` (۷ تست) **شکلِ سیم‌کشیِ Kotlin**
را قفل می‌کند — از جمله «pin فقط روی `proxyIndex == 0`» و «انبارِ تنظیمات اسلاتِ
ورودی را دور نمی‌ریزد». برچسبِ صادقانه: این تست‌ها **source-level** هستند
(رفتارِ روی گوشی را ثابت نمی‌کنند)؛ آن را کامپایلِ CI و تستِ دستگاه نشان می‌دهد.

## ۲) چهار نوع IP که قاطی می‌شوند (همان‌طور که بود)

| نوع | نقش | در اپ |
| --- | --- | --- |
| ورودی (Before) | اولین پایِ تونل؛ آدرسش را می‌شود pin کرد | `ConnectionChainHop.serverOverride` |
| هوپ میانی (Base/After) | مسیر را دو-تکه می‌کند | همان + انتخابِ کانفیگ |
| ProxyIP | جای IP دامنهٔ **مقصد** می‌نشیند | اسکنر ProxyIP / اشتراک |
| خروجی/کشور | انتخاب مسیر و نمایشِ کشور | `RelayCountryLookup`، `ProxyEgressCountry` |

## ۳) چیزی که هنوز نیست (صادقانه)

1. **fronting روی مسیرِ زنجیره اعمال نمی‌شود.** در `SessionPlan.kt` مقدار
   `serverOverrideIp` از `topEndpoint` می‌آید و مسیرِ زنجیره `topEndpoint = null`
   پاس می‌دهد؛ یعنی لیستِ fronting به رانتایمِ زنجیره نمی‌رسد. به همین دلیل IP در
   زنجیره از راهِ **pin** وارد می‌شود (داخلِ خودِ YAML) نه از راهِ fronting. اگر
   بخواهی fronting برای همهٔ هُپ‌ها هم کار کند، کارِ بعدی همان است.
2. **انتخابِ IP از روی پینگ/کشور در همان دیالوگ** (الان IP دستی یا اسکنر).
3. **ProxyIP به‌عنوان نقشِ صریحِ «مقصد»** در همین صفحه (الان در اسکنر/اشتراک است).
4. **نسخهٔ ۳-هُپی** (ورودی+پایه+بعد) از UI حالا ممکن است ولی در گوشی تست نشده.

---

## ۴) خطرهایی که یادت باشد

1. **ProxyIP را وسطِ زنجیره نگذار** — آن IP برای «هاستِ مقصد» است.
2. **SNI/Host هم‌راستا** — وگرنه ۴۲۱.
3. **پینگِ نمایشی** با هر هوپ «مسیر واقعی» نیست؛ عدد را با لیبل بخوان.
4. **۱۱۰۱ در ورکر وسطِ زنجیره** به خطای قابلِ catch تبدیل می‌شود (service
   binding/dynamic dispatch) — یعنی زنجیره با ورکر بهتر از زنجیرهٔ خالصِ TCP خطا
   می‌دهد، نه بدتر.
5. **IP شخصی را کامیت نکن** — نه در سورس، نه در ریلیز.
