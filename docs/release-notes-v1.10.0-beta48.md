# Cat Client 1.10.0-beta48 (versionCode 115) — پنل 6.30.0

## 🎯 پورتِ خودِ ProxyIP — حالا در تست هم رعایت می‌شود

گرفتی بود: تستِ سلامتِ بتا۴۷ همهٔ 🎯ها را روی ۴۴۳ می‌زد، در حالی که هر ProxyIP پورت خودش را دارد. فیکس شد:

- **tst 🎯 حالا روی پورتِ خودِ هر ورودی** انجام می‌شود: `1.2.3.4:8443` → تست روی 8443؛ ورودی بدون پورت → 443 پیش‌فرض
- نتیجه‌ها با همان رشتهٔ اصلیِ ورودی نشانه‌گذاری می‌شوند (چیپ relay✓/✗ درست جواب می‌دهد)
- مسیرِ خودِ کانفیگ‌ها از اول درست بود و دست‌نخورده ماند: ورکر برای رله `splitHostPort(proxyip)` می‌زند یعنی **پورتِ داخل ?proxyip= همان dial می‌شود** — قانون «پورت هر پروکسی‌آی‌پی عوض نشه» در ساب هم برقرار است

## ❓ چرا داخل کانفیگ 🎯 هم IP و هم پورت 443 می‌بینی؟
دو پورتِ متفاوت با دو نقشِ متفاوت‌اند:
| پورت | نقش |
|---|---|
| `443` (کنار آدرسِ ورکر) | پورتِ **ورود** کلاینت به کلادفلر/ورکر — همیشه TLS |
| پورتِ داخل `?proxyip=1.2.3.4:8443` | پورتِ **رله** — ورکر از دلش به سایتِ پشتیِ CF وصل می‌شود؛ همین پورتِ خودِ ProxyIP است |

یعنی پورتِ ProxyIP گم نمی‌شود؛ داخل path سفر می‌کند و سمت ورکر مصرف می‌شود. این توضیح داخل خود پنل (کنار دکمهٔ تست) هم نوشته شد.
