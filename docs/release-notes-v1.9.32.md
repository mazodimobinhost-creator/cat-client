# Cat Client v1.9.32 — مخزن‌های تأییدشدهٔ IP، وصل به ورکر 📡

## چه شد؟

مخزن‌های IP تمیز کلادفلر را سراسر گیت‌هاب گشتم و هر کاندید را **با بایت‌های واقعی فایل‌هایش** تست کردم (نه فقط اسمش را). سه مخزن برتر که پوشِ خودِ امروز را داشتند وصل شدند:

- 🇮🇷 **ircfspace/cf2dns** (۲۰۳★، چند بار در روز اتوآپدیت) — IP های کلادفلر **اندازه‌گیری‌شده با کولو و تاخیر** (نسخهٔ v4 و v6)
- 🇨🇳 **ymyuuu/IPDB** (`bestcf`) — رپوی کلاسیک 优选؛ دستچین‌شده‌های برتر
- 🌐 **XIU2/CloudflareSpeedTest** — بذرهای خام v4 و v6 (قبلاً بود)

ردشده‌ها (بعد از تست): آریستا (فقط ۱ IP)، رادیواکتیو (رنج ورودی اسکنر بود نه نتیجه)، ماتیکس/cf2tg/خرده‌ریزها (فایل نداشتند).

## جزئیات فنی

- پارسر ورکر حالا JSON هم می‌فهمد (شکل دادهٔ cf2dns: `{colo, ip, latency}`) — با فایل واقعی دریافتی تست شد.
- همهٔ مخزن‌ها با زنجیرهٔ ۴مسیره (jsDelivr → fastly → ghproxy → raw) کشیده می‌شوند — از سمت کلادفلر، نه اینترنت تو.
- هر IP باز هم باید رنج رسمی کلادفلر باشد و از اسکن تو رد شود تا وارد کانفیگ شود.

## مسیر استفاده

1. ورکر → «بروزرسانی پنل» به **۵.۲۱.۲**.
2. اسکنر → «🔄 دریافت IP تازهٔ انجمن» — حالا ۵ مخزن را می‌کشد؛ بعد اسکن از مرورگر.
