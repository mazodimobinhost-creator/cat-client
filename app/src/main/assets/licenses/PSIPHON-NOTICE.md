# Psiphon carrier notice

Cat Client uses the pinned `ca.psiphon:psiphontunnel:2.0.41` tunnel-core artifact only for the optional, isolated Psiphon carrier. Psiphon is a project of Psiphon Inc.; Cat Client is not affiliated with or endorsed by Psiphon Inc.

The propagation and sponsor identifiers are Psiphon's documented unattributed placeholder values. Signature keys included in configuration are public verification keys, not credentials. The carrier is proxy-only and must run in a separate Android process; it does not own Cat Client's VPN interface.

Upstream project and corresponding source: https://github.com/Psiphon-Labs/psiphon-tunnel-core
